JavaScript ES6+

El lenguaje de la interactividad web: manipula el DOM, responde a eventos, consuma APIs y construye apps reales.

¿Qué es JavaScript?

JavaScript es el lenguaje de programación que se ejecuta en el navegador y convierte una página estática en una aplicación interactiva. Con ES6+ ganó arrow functions, clases, módulos, promesas y desestructuración.

DOM

Lee y modifica la estructura de la página en tiempo real.

Eventos

Clicks, scrolls, teclado y más: responde a la interacción del usuario.

APIs

fetch y promesas para traer datos de cualquier servicio externo.

Un vistazo ES6+

// Arrow function y desestructuración
const usuario = { nombre: "Alex", nivel: "Experto" };
const { nombre } = usuario;

// Template literals y flexibilidad
const saludo = `Hola, ${nombre}`;

// Async/await con fetch
async function cargarDatos() {
  const res = await fetch("/api/datos");
  const datos = await res.json();
  console.log(datos);
}
Tip: Dominar ES6+ es la base para entender React, Vue y cualquier framework moderno del ecosistema.
