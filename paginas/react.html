React

La librería de interfaces de usuario más popular: componentes reutilizables, props, estado y un DOM virtual ultrarrápido.

¿Qué es React?

React, creado por Meta, organiza la UI en componentes independientes que reciben props y mantienen su propio estado. Cuando el estado cambia, React actualiza solo lo necesario.

Componentes

Piezas de UI reutilizables y encapsuladas en todo el proyecto.

Props y estado

Los datos fluyen hacia abajo por props y el estado re-renderiza la UI.

Hooks

useState, useEffect y useContext para lógica limpia en funciones.

Un componente con estado

// Contador de votos con un hook
function Contador() {
  const [votos, setVotos] = useState(0);

  return (
    <button onClick={() => setVotos(votos + 1)}>
      Votos: {votos}
    </button>
  );
}
Tip: La base de React (props, estado, componentes) la aprendes en esta guía; luego puedes pasar a Next.js y ecosistemas profesionales.
