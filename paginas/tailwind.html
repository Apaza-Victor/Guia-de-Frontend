Tailwind Recurso Utilidades

Tailwind CSS

El enfoque "utility-first": diseña interfaces completas combinando clases atómicas directamente en el HTML, sin escribir CSS separado.

¿Qué es Tailwind?

Tailwind no te da componentes, te da bloques de construcción: clases para márgenes, flexbox, colores, tipografía y responsive. Así compones el diseño sin dejar el HTML y evitas nombres de clases arbitrarios.

Utility-first

flex, p-4, text-white: estilos de una sola responsabilidad.

Responsive

Prefijos sm:, lg:, xl: aplican estilos por breakpoint.

Purga de CSS

Solo se compilan las clases que realmente usas: CSS mínimo.

Componer con utilidades

<div class="flex items-center justify-between
            p-4 rounded-lg bg-slate-800">
  <h1 class="text-white text-xl font-bold">Hola</h1>
  <button class="px-4 py-2 rounded bg-blue-500
          hover:bg-blue-600">Click</button>
</div>
Tip: Nota cómo las clases de utilidad (bg-, p-, flex-) ya las conoces de tu base en Bootstrap y CSS: Tailwind lleva esa idea al extremo.
