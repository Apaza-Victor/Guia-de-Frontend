CSS3

Cascading Style Sheets: los estilos que dan vida al HTML. Selectores, layouts modernos, variables y animaciones.

¿Qué es CSS3?

CSS separa el contenido del presentación. Con CSS3 puedes controlar colores, fuentes, layouts, transiciones, animaciones y efectos sin tocar el HTML.

Flexbox y Grid

Dos sistemas de layout modernos para maquetar cualquier interfaz responsive.

Custom properties

Variables CSS para mantener un tema consistente en todo el proyecto.

Animaciones

Transiciones, keyframes y transformaciones para micro-interacciones fluidas.

Flexbox en acción

Centrar contenido y crear layouts flexibles nunca fue tan fácil:

.contenedor {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 1rem;
}

.tarjeta {
  flex: 1 1 300px;
  transition: transform 0.3s ease;
}

.tarjeta:hover {
  transform: translateY(-4px);
}
Tip: Combina display: grid para layouts bidimensionales y flex para distribuir contenido en una sola dirección.
