Roadmap 20 semanas 4 fases

Ruta de aprendizaje

Un plan paso a paso de 20 semanas: de novato absoluto a frontend profesional, integrando toda la guía de Frontend Pro.

Las 4 fases del roadmap

Cada fase agrupa varios temas de la guía y termina con un hito concreto. Estable 💪: no saltes fases: cada una construye sobre la anterior.

Fase 1 Semanas 1-4

Fundamentos

HTML semántico + CSS básico e intermedio. Entiendes la caja, los selectores, Flexbox y Grid para maquetar cualquier interfaz.

HTML · 10 lecciones CSS Básico · 7 lecciones CSS Intermedio · 7 lecciones
Hito: Maquetar una landing responsive completa solo con HTML y CSS.
Fase 2 Semanas 5-10

JavaScript

Dominas el lenguaje de la web: variables, funciones, arrays, DOM, eventos, fetch, promesas y ES6+. La base de todo framework.

JS Básico · 9 lecciones JS Intermedio · 5 lecciones JS Avanzado · 5 lecciones
Hito: Aplicación web que consume una API real con fetch y renderiza datos dinámicos.
Fase 3 Semanas 11-14

Producción

Bootstrap 5 a nivel experto, versionado con Git, dependencias con npm, preprocesado con Sass y animaciones AOS + GSAP.

Bootstrap 5 · 5 lecciones Git y npm · 2 lecciones Sass · 1 lección
Hito: Sitio con Bootstrap personalizado, animado, versionado en GitHub y con scripts npm.
Fase 4 Semanas 15-20

Frameworks

React y Vue con fundamentos sólidos: componentes, estado y reactividad desde cero, listo para el trabajo profesional.

React · 1 lección Vue 3 · 1 lección
Hito: Un portafolio con tus proyectos y una SPA con componente React o Vue.

Consejos para no abandonar

Estudia a diario, aunque sea 30 minutos

La constancia gana a los maratones. Haz de una lección tu rutina del día.

Escribe TODO el código a mano

Copiar pega no entrena músculo mental. Teclear cada ejemplo consolida el aprendizaje.

Prueba romper las demos

Cambia valores, colores y unidades. Entender el error es medio camino al experto.

Construye y comparte

Pública tus hitos en GitHub o redes. El feedback acelera tu curva de aprendizaje.
