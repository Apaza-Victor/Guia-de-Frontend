Bootstrap 5

El framework CSS más usado del mundo: prototipa interfaces responsive con su grid system y componentes listos.

¿Qué es Bootstrap 5?

Bootstrap es un framework de CSS y JavaScript que incluye un grid system de 12 columnas, componentes (botones, navbar, cards, modales) y utilidades que aceleran enormemente el desarrollo.

Grid

11 columnas + breakpoints para diseños responsive sin CSS manual.

Componentes

Navbars, cards, modales, carouseles: listos para copiar y pegar.

Personalización

Variables CSS y Sass para adaptar el tema a tu marca.

Grid en 3 líneas

<div class="container">
  <div class="row">
    <div class="col-md-4">Columna 1</div>
    <div class="col-md-4">Columna 2</div>
    <div class="col-md-4">Columna 3</div>
  </div>
</div>
Tip: El sufijo -md aplica el ancho desde el breakpoint de tablet en adelante; en móvil las columnas se apilan solas.
