Git & GitHub

El control de versiones estándar de la industria más la plataforma de colaboración más grande del mundo.

¿Qué son Git y GitHub?

Git es un sistema de control de versiones distribuido: registra cada cambio, permite volver atrás y trabajar en paralelo. GitHub es la plataforma en la nube que aloja esos repositorios.

Historial

Cada commit es una fotografía recuperable de tu proyecto.

Branches

Desarrolla features en paralelo sin romper la rama principal.

Colaboración

Pull requests y code review para equipos de cualquier tamaño.

Comandos esenciales

# Guardar cambios
git add .
git commit -m "mensaje descriptivo"

# Subir y traer cambios
git push
git pull
Tip: Escribe commits claros en presente: "añade formulario de contacto", nunca "cambios finales 2".
