Sass

Un preprocesador CSS que añade variables, anidamiento, mixins y funciones para escribir estilos profesionales y mantenibles.

¿Qué es Sass?

Sass compila a CSS puro pero te deja programar tus estilos: variables, anidamiento de selectores, mixins reutilizables y operaciones aritméticas con colores y medidas.

Variables

Define colores y medidas una vez y reutilízalos en todo el proyecto.

Anidamiento

Estructura selectores padre-hijo de forma jerárquica y legible.

Mixins

Bloques de estilo reutilizables con parámetros, como funciones.

Variables y mixins

$primary: #2563eb;
$radius: 12px;

@mixin boton($bg) {
  background: $bg;
  border-radius: $radius;
  padding: 0.6rem 1.2rem;
}

.btn-primario {
  @include boton($primary);
}
Tip: Bootstrap 5 se construye con Sass: sobrescribir sus variables te permite tener un tema propio sin pelear contra el framework.
