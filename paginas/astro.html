Astro

Un meta-framework que construye sitios rápidos por defecto: componentes .astro, rutas basadas en archivos e islas de interacción con client:load.

¿Qué es Astro?

Astro es un meta-framework: agrupa varios frameworks bajo un solo proyecto pero envía al navegador la mínima cantidad de JavaScript posible. Gracias a su modelo de islas (island architecture), cada componente interactivo se hidrata de forma independiente y el resto de la página llega estático y rapidísimo.

Islas de interacción

Solo los componentes con client:load llevan JavaScript al navegador.

Cero JS por defecto

HTML, CSS y Markdown se renderizan como texto estático sin frameworks.

Contenido Markdown

Escribe contenido en Markdown y Astro genera las páginas por ti.
