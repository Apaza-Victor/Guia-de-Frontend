Vue 1 lección Framework

Vue

El framework progresivo: fácil de adoptar poco a poco y con una reactividad tan elegante que empiezas a usarlo en minutos.

¿Qué es Vue?

Vue se integra de forma incremental en tu HTML existente o escala a SPA completas. Su sistema reactivo actualiza la vista automáticamente cuando los datos cambian, con una curva de aprendizaje muy suave.

Directivas

v-if, v-for y v-model conectan el HTML con los datos.

Reactividad

Cambia el estado y la interfaz se actualiza sola.

Progresivo

Úsalo en un botón hoy o en toda la app mañana.

Reactividad básica

<div id="app">
  <p>{{ mensaje }}</p>
  <button @click="cambiar">Cambiar</button>
</div>

<script>
  const app = createApp({
    data() {
      return { mensaje: "Hola Vue" };
    },
    methods {
      cambiar() { this.mensaje = "¡Reactivo!"; }
    }
  });
</script>
Tip: Vue es ideal como segundo framework: su enfoque progresivo te permite sumarlo a proyectos existentes sin reescribir nada.
