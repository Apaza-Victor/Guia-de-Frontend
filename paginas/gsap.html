GSAP 1 lección Animación

GSAP

GreenSock Animation Platform: el estándar de facto para animaciones web de alto rendimiento en producción.

¿Qué es GSAP?

GSAP permite animar casi cualquier propiedad CSS con un rendimiento superior al de CSS puro, y ofrece control total sobre la línea de tiempo: pausar, retroceder, repetir o encadenar animaciones.

Tweens

Anima cualquier propiedad de cualquier elemento con una línea.

Timelines

Orquesta secuencias complejas ordenadas con precisión milimétrica.

ScrollTrigger

Activa animaciones según el scroll del usuario de forma fluida.

Un tween sencillo

// Funde entrada + desplazamiento
gsap.from("#tarjeta", {
  opacity: 0,
  y: 40,
  duration: 0.8,
  ease: "power3.out"
});
Tip: GSAP trabaja en la landing de práctica de Bootstrap. Aprende AOS para animaciones al scroll simples y GSAP para control fino avanzado.
