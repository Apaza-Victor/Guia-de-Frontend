Objetos y JSON

Modela datos con objetos, dales comportamiento con métodos y transpórtalos con JSON.

Objetos literales

Un objeto agrupa propiedades (datos) y métodos (funciones) bajo un mismo nombre. Se declara con llaves {} y sus propiedades van separadas por comas, en formato clave: valor. 

const usuario = {
  nombre: 'Lucía',          // propiedad
  edad: 28,
  activo: true,
  saludar() {              // método (shorthand)
    console.log(`Hola, soy ${this.nombre}`);
  }
};

usuario.saludar();   // "Hola, soy Lucía"
usuario.nombre = 'Marta'; // modificar propiedad
console.log(usuario.nombre); // "Marta"
SintaxisAccesoEjemplo
Puntoobj.propiedadusuario.nombre
Corchetesobj['propiedad']usuario['nombre']
Dinámicaobj[variable]usuario[key]

this: el objeto actual

Dentro de un método, this apunta al objeto que lo contiene. Nos permite leer y modificar las demás propiedades desde dentro del propio objeto. 

const contador = {
  valor: 0,
  incrementar() {
    this.valor++;   // this = contador
  },
  obtener() {
    return this.valor;
  }
};
contador.incrementar();
console.log(contador.obtener());  // 1
Ojo: En las funciones flecha this no se ata al objeto: hereda el contexto donde se definió. Si usas flechas para métodos, perderás el acceso a this.propiedad.

JSON: el idioma de la web

JSON (JavaScript Object Notation) es un formato de texto ligero para intercambiar datos entre el navegador y el servidor. Se parece a un objeto JS pero es solo texto: las claves van entre comillas dobles y no admite funciones ni comentarios. 

// Objeto → texto (para enviar al servidor)
const json = JSON.stringify(usuario);
console.log(json);  // {"nombre":"Marta","edad":28,"activo":true}

// Texto → objeto (para usar en el código)
const texto = '{"nombre":"Iván","edad":30}';
const obj = JSON.parse(texto);
console.log(obj.nombre);  // "Iván"
MétodoDirecciónResultado
JSON.stringify(obj)Objeto → JSON stringtexto listo para enviar
JSON.parse(str)JSON string → Objetoobjeto JS usable
Tip: JSON.stringify(obj, null, 2) añade 2 espacios de indentación: perfecto para mostrar JSON "bonito" y para depurar (justo lo que hace la demo de abajo).

Claves dinámicas y Object.keys/values

Puedes crear propiedades cuyo nombre viene de una variable usando corchetes. Y puedes recorrer las claves o valores de un objeto con Object.keys y Object.values.

const campo = 'email';
const dato = { [campo]: 'a@b.com' };   // { email: 'a@b.com' }

console.log(Object.keys(usuario));    // ["nombre", "edad", "activo"]
console.log(Object.values(usuario));  // ["Marta", 28, true]

Object.entries(usuario).forEach(([k, v]) => {
  console.log(`${k}: ${v}`);   // recorre todo el objeto
});

Repaso rápido

  • Los objetos agrupan propiedades (datos) y métodos (funciones).
  • Dentro de un método, this es el objeto que lo contiene.
  • JSON.stringify serializa a texto; JSON.parse lo reconstruye.
  • Usa corchetes para claves dinámicas y Object.keys/values/entries para recorrer.
