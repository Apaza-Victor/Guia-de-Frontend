Temporizadores

Retarda, repite y anima con precisión en el tiempo.

setTimeout: ejecutar una vez

setTimeout(fn, ms) ejecuta una función una sola vez después de un retardo en milisegundos. No detiene el código que sigue: es asíncrono. 

const miRetardo = setTimeout(() => {
  console.log('Han pasado 3 segundos');
}, 3000);

Si después cambiamos de idea y queremos cancelar antes de que se dispare:

clearTimeout(miRetardo); // se cancela; el log nunca llega

Tooltip que se cierra solo1500 msal dejar de hacer hover
feedback temporal2000–3000 ms"guardado" que desaparece solo
redirecciónsegún UX"serás redirigido…"

setInterval: repetir

setInterval(fn, ms) ejecuta la función una y otra vez cada intervalo. Guarda siempre el id que devuelve para poder pararlo con clearInterval: 

let segundos = 0;
const reloj = setInterval(() => {
  segundos++;
  console.log(segundos);
}, 1000);

// En algún momento (botón, condición…):
clearInterval(reloj); // para el bucle
Ojo: Un setInterval que nunca se limpia es una fuga de recursos. Si el elemento desaparece del DOM o la cadena que lo lanzó terminó, detenlo con clearInterval.

requestAnimationFrame: animar bien

Para animaciones continuas (mover, rotar, progresos), setInterval es tosco: el navegador suspende las pestañas en segundo plano y el intervalo se acumula. La alternativa moderna es requestAnimationFrame: pide al navegador ejecutar tu función antes del próximo repintado (≈60 veces por segundo, y se pausa sola si la pestaña no se ve). 

function mover(timestamp) {
  // ...actualiza la posición...
  requestAnimationFrame(mover); // la próxima vez
}
requestAnimationFrame(mover); // primera llamada
Tip: Regla práctica: una vez → setTimeout; repetido → setInterval; animación visible → requestAnimationFrame.

Repaso rápido

  • setTimeout ejecuta una vez; setInterval repite.
  • Guarda el id que devuelven y cancela con clearTimeout / clearInterval.
  • requestAnimationFrame pausa en pestañas ocultas y sincroniza con el refresco.
  • Nunca dejes setInterval corriendo sin limpiarlo.
