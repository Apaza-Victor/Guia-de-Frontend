APIs del navegador

Haz que tu app hable con el dispositivo: portapapeles, ubicación y conexión.

Detectar capacidades primero

Las APIs modernas no están en todos los navegadores. Antes de usarlas, comprueba que existen con un simple if. Es lo que se llama feature detection: 

if ('clipboard' in navigator) {
  // usa navigator.clipboard
} else {
  // fallback con document.execCommand
}
Tip: La mayoría de estas APIs requieren HTTPS (o localhost). En file:// pueden fallar o pedir permisos.

Clipboard API: copiar con estilo

El clásico "copiar al portapapeles" ya no necesita textareas ocultos. La API moderna es promesa pura: 

async function copiarTexto(texto) {
  try {
    await navigator.clipboard.writeText(texto);
    console.log('Copiado ✓');
  } catch (err) {
    console.error('No se pudo copiar', err);
  }
}
Ojo: Debe llamarse dentro de un gesto del usuario (clic) para que los permisos se concedan. No funciona si lo lanzas al cargar la página.

Geolocalización

Pide la posición (con permiso del usuario) mediante navigator.geolocation.getCurrentPosition. El callback recibe un objeto con coords.latitude y coords.longitude: 

navigator.geolocation.getCurrentPosition(
  (pos) => {
    console.log('Lat:', pos.coords.latitude);
    console.log('Lng:', pos.coords.longitude);
  },
  (error) => console.error(error.message)
);
Código de errorSignificado
1 PERMISSION_DENIEDel usuario denegó el permiso
2 POSITION_UNAVAILABLEno se pudo obtener posición
3 TIMEOUTtardó demasiado
Tip: Siempre muestra un fallback ("no pudimos obtener tu ubicación") en el callback de error: los permisos se deniegan más a menudo de lo que crees.

Estado de conexión

Detectar si hay red se hace con navigator.onLine y los eventos online/offline (se disparan automáticamente): puedes avisar al usuario en tiempo real: 

window.addEventListener('offline', () => {
  console.log('Sin conexión');
});
window.addEventListener('online', () => {
  console.log('De vuelta a internet');
});

Repaso rápido

  • Comprueba la API con 'clipboard' in navigator antes de usarla: feature detection.
  • Clipboard, geolocalización y notificaciones necesitan un gesto del usuario y permisos.
  • Usa navigator.onLine + online/offline para UI reactiva a la red.
  • Siempre define un fallback claro cuando fallan estas APIs.
