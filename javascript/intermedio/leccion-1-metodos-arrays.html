Arrays y métodos avanzados

Aprende a manipular colecciones de datos con map, filter, reduce y compañía.

¿Qué es un array?

Un array (arreglo) es una colección ordenada de valores. Puedes mezclar tipos, aunque lo habitual es que todos los elementos sean del mismo tipo. Se declara con corchetes [] y cada posición tiene un índice que empieza en 0. 

// Declaración e índices
const frutas = ['manzana', 'pera', 'uva'];
console.log(frutas[0]);  // 'manzana' (primer elemento)
console.log(frutas[2]);  // 'uva'
console.log(frutas.length); // 3 (número de elementos)
Tip: Cuando el array es vacío, su length es 0, y acceder a un índice inexistente devuelve undefined, no un error.

Añadir y quitar: push, pop, shift y unshift

Estos cuatro métodos modifican el array directamente (métodos mutadores).

const cola = ['a', 'b'];
cola.push('c');      // añade al final    → [a, b, c]
cola.pop();          // quita del final   → [a, b]
cola.unshift('x');   // añade al inicio   → [x, a, b]
cola.shift();        // quita del inicio  → [a, b]
MétodoAcciónDevuelve
push(elem)Añade al finalla nueva longitud
pop()Elimina el últimoel elemento eliminado
unshift(elem)Añade al iniciola nueva longitud
shift()Elimina el primeroel elemento eliminado
Tip: Para saber si un valor existe usa indexOf: frutas.indexOf('pera') devuelve el índice o -1 si no existe. La versión moderna es includes(), que devuelve true/false.

Recortar y copiar: slice y splice

slice() no modifica el array original: devuelve una copia parcial. splice() sí lo modifica: inserta o elimina elementos en cualquier posición. 

const nums = [10, 20, 30, 40, 50];

// slice(inicio, fin) — sin modificar el original
const copia = nums.slice(1, 3);    // → [20, 30]

// splice(posición, cuántos eliminar, ...nuevos)
nums.splice(2, 1, 99);     // reemplaza el 30 por 99
// nums ahora es [10, 20, 99, 40, 50]

Los reyes del array: map, filter, reduce, find y sort

Estos métodos recorren el array y devuelven un resultado sin mutar el original. El corazón de la programación funcional en JavaScript.

const precios = [100, 50, 200, 75];

// map: transforma cada elemento
const conIva = precios.map(p => p * 1.16);   // → [116, 58, 232, 87]

// filter: conserva los que cumplen la condición
const baratos = precios.filter(p => p < 100);  // → [50, 75]

// find: devuelve el PRIMERO que cumpla (o undefined)
const cincuenta = precios.find(p => p === 50);  // → 50

// sort: ordena (copia primero con slice para no mutar)
const ordenados = [...precios].sort((a, b) => a - b); // → [50, 75, 100, 200]

// reduce: acumula hasta reducir a un solo valor
const total = precios.reduce((acc, p) => acc + p, 0); // → 425
Ojo: sort() ordena como texto por defecto (27 va antes que 5). Siempre pasa una función comparadora (a, b) => a - b para números, y usa [...arr].sort() si no quieres modificar el original.

forEach e iterables

forEach() recorre el array solo para ejecutar un efecto (sin construir un resultado nuevo). Un array es un iterable: puedes recorrerlo también con for ... of. 

nombres.forEach((nombre, i) => {
  console.log(`${i}: ${nombre}`);
});

// Otra forma: for...of sobre iterables
for (const nombre of nombres) {
  console.log(nombre);
}

Demo: lista de tareas

Una lista de tareas real que vive en un array. Añade, completa cuando marcas el checkbox, filtra por estado y reorganiza con sort. Observa cómo map + filter actualizan la vista sin tocar el array original.

    Tip: Combina filter (qué mostrar) y map (cómo pintarlo). El array original se mantiene intacto: el estado de la app está en tareas; el resto es solo representación.
    Ojo: pop()/shift() sirven para pilas y colas. Para "eliminar" un elemento del medio se usa filter creando un array nuevo, como hace la demo con tareas = tareas.filter(...).

    Repaso rápido

    • push/pop/shift/unshift añaden o quitan y mutan el array.
    • slice copia; splice modifica.
    • map transforma, filter selecciona, find localiza y reduce acumula.
    • Para sort numérico pasa siempre (a, b) => a - b.
