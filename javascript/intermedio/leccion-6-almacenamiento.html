Almacenamiento local

Guarda datos en el navegador para que sobrevivan a recargas, cierres y visitas.

¿Qué es el almacenamiento web?

Cuando recargas una página o la cierras, todas las variables de JavaScript se pierden. Para recordar preferencias, sesiones o borradores entre visitas, el navegador ofrece espacios de almacenamiento persistentes.

Los dos más usados son:

localStorage

Persiste sin fecha de caducidad: sobrevive a recargas y cierres del navegador.

sessionStorage

Vive solo durante la pestaña actual: se borra al cerrarla.

Tip: Solo se guardan texto. Para guardar objetos o arrays usamos JSON, como viste en la lección 2.

La API de localStorage

Funciona con pares clave → valor. Cuatro métodos cubren el 99% de los casos:

localStorage.setItem('nombre', 'Ana');      // guarda
localStorage.getItem('nombre');      // lee como string
localStorage.removeItem('nombre');   // borra una clave
localStorage.clear();               // borra todo
MétodoHaceDevuelve
setItem(clave, valor)guarda (o sobreescribe)undefined
getItem(clave)lee un valorstring o null
removeItem(clave)elimina una claveundefined
clear()vacía todoundefined
Ojo: Todo se guarda como texto. localStorage.setItem('edad', 25) guarda el string "25", no el número. No obtienes null con getItem si la clave existe; devuelve null solo cuando NO existe.

Guardar objetos con JSON

Para persistir un objeto o un array usamos la misma serialización que viste con JSON en la lección 2: 

const usuario = { nombre: 'Ana', nivel: 3 };

// Guardar: conviértelo a texto JSON
localStorage.setItem('usuario', JSON.stringify(usuario));

// Leer: parsea el texto de vuelta a objeto
const recuperado = JSON.parse(localStorage.getItem('usuario'));
console.log(recuperado.nombre); // 'Ana'
Tip: Antes de hacer JSON.parse comprueba que la clave exista: getItem devuelve null si no está, y JSON.parse(null) lanza error. Sé tolerante: envuelve la lectura en un try/catch.

sessionStorage y el evento storage

sessionStorage usa la misma API exacta, pero su vida se limita a la pestaña. ¿Dónde usar cada uno?

  • localStorage: preferencias, tema, carrito persistente, borradores a largo plazo.
  • sessionStorage: datos temporales de la sesión (p. ej., "estás viendo el tutorial", tokens de sesión breve).

Además, el evento storage se dispara en otras pestañas cuando una guarda o borra valores. Es ideal para sincronizar tu interfaz en tiempo real: 

window.addEventListener('storage', (e) => {
  console.log(e.key);    // clave que cambió
  console.log(e.newValue); // nuevo valor (string o null)
});
Ojo: El evento storage no se dispara en la misma pestaña que hace el cambio: solo en las demás. Para reaccionar al instante en la pestaña actual, actualiza tú mismo el DOM.

Repaso rápido

  • localStorage persiste para siempre; sessionStorage muere con la pestaña.
  • Solo guarda texto: usa JSON.stringify al guardar y JSON.parse al leer.
  • Comprueba siempre getItem(clave) !== null antes de parsear.
  • El evento storage sincroniza otras pestañas, no la actual.
  • No guardes contraseñas ni datos sensibles: cualquiera puede leerlo desde consola.
