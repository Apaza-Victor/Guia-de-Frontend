Manipulación del DOM

Selecciona, crea y modifica elementos para pintar interfaces en tiempo real.

Seleccionar elementos

El DOM (Document Object Model) es la representación en memoria de tu HTML. Con JavaScript puedes seleccionar cualquier nodo y luego leerlo o modificarlo. 

// Selectores modernos (CSS)
const titulo = document.querySelector('.card h2');   // el primero que coincida
const todos  = document.querySelectorAll('.card');  // NodeList (iterable)

// Selector clásico por id
const boton = document.getElementById('btnGuardar');

todos.forEach(card => console.log(card));

Tip: Prefiere querySelector a secas: acepta cualquier selector CSS y es idéntico al que ya conoces de los <style>.

textContent vs innerHTML y el XSS

textContent asigna texto puro; innerHTML interpreta etiquetas HTML. Esta diferencia es crítica por seguridad: un usuario malintencionado podría inyectar <script> a través de un campo de texto (ataque XSS). 

// ✅ Seguro: trata el contenido como texto simple
elemento.textContent = userInput;

// ⚠️ Peligroso: interpreta el contenido como HTML
elemento.innerHTML = `<b>${userInput}</b>`;  // XSS si viene del usuario
Regla de oro: Para mostrar datos de usuarios usa SIEMPRE textContent. Solo usa innerHTML con HTML que tú controlas al 100%, nunca con entradas externas sin sanitizar.

Crear y montar elementos

createElement crea la etiqueta, y appendChild / append la insertan en el árbol. La clase y los estilos se controlan con classList y style. 

const tarjeta = document.createElement('div');
tarjeta.classList.add('card', 'mb-2');
tarjeta.classList.toggle('activa', esActiva);
tarjeta.style.marginTop = '1rem';
tarjeta.dataset.tipo = 'nota';

const parrafo = document.createElement('p');
parrafo.textContent = 'Contenido seguro';
tarjeta.appendChild(parrafo);

contenedor.append(tarjeta);   // monta la tarjeta en el DOM

Tip: Los atributos data-nombre del HTML se leen con elemento.dataset.nombre (camelCase). Son ideales para guardar información en los elementos, como en la demo de la siguiente lección.

Demo: constructor de tarjetas

Crea tantas tarjetas como quieras. Todo se construye con createElement, appendChild, classList, style y dataset. Marca una tarjeta como favorita y observa el toggle de clase.

Ojo: Es tentador construir HTML como cadena con innerHTML +=. Además de re-renderizar todo, es la puerta de entrada al XSS. La demo construye nodos con createElement y textContent: siempre la opción segura.

Repaso rápido

  • querySelector / getElementById para seleccionar.
  • textContent para texto seguro; innerHTML solo con HTML de confianza.
  • createElement + append = construir interfaces dinámicas.
  • classList, style y dataset para control fino del elemento.
