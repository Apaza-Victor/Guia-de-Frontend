Fetch API y AJAX

Carga datos de servidores sin recargar la página y píntalos al instante.

¿Qué es AJAX?

AJAX (Asynchronous JavaScript And XML) es la técnica que permite comunicar el navegador con un servidor sin recargar la página. Cuando envías un formulario, haces clic en "me gusta" o ves actualizarse un panel en vivo, estás usando AJAX.

El flujo típico es:

  • 1. El navegador solicita datos a una URL (una API).
  • 2. El servidor responde con una respuesta, normalmente en JSON.
  • 3. JavaScript procesa los datos y actualiza el DOM.
Tip: El nombre conserva "XML" por historia, pero hoy el formato estándar de intercambio es el JSON que aprendiste en la lección 2.

fetch() y las Promesas

fetch(url) lanza una petición y devuelve una Promesa. Con .then() encadenamos lo que ocurre cuando la promesa se cumple, y con .catch() qué hacemos si falla. 

fetch('https://jsonplaceholder.typicode.com/users')
  .then((respuesta) => respuesta.json())  // convierte la respuesta en JSON
  .then((datos) => {                     // datos ya es un array real
    console.log(datos.length);           // 10 usuarios
  })
  .catch((error) => {
    console.error('No se pudo cargar', error);
  });

Ojo: fetch NO lanza error con HTTP 404/500. Eso solo hace fallar la red o la URL. Por eso se comprueba respuesta.ok: para detectar respuestas "de fallo" del servidor, como hace la demo siguiente.

response.ok y manejo de errores

respuesta.ok es true si el código HTTP está entre 200 y 299. Es la comprobación estándar antes de parsear el JSON. 

fetch(url)
  .then((respuesta) => {
    if (!respuesta.ok) throw new Error(`HTTP ${respuesta.status}`);
    return respuesta.json();
  })
  .catch((error) => {
    console.error('Error al cargar:', error.message);
  });
Tip: La demo de abajo usa esta misma versión con throw new Error, así el catch se encarga de TODO fallo: red, servidor o JSON inválido.

Estados de carga: UX real

Toda petición pasa por tres estados. Mostrarlos al usuario es buena práctica: nada de pantallas congeladas.

Cargando

spinner / "Espera…" mientras el fetch viaja

Éxito

pintamos los datos recibidos

Error

mensaje claro y amable para el usuario

Repaso rápido

  • AJAX = pedir datos al servidor sin recargar; JSON es el formato de intercambio.
  • fetch(url).then(r => r.json()).then(...).catch(...) es la cadena básica.
  • Comprueba respuesta.ok: 404/500 no lanzan error por sí solos.
  • Muestra siempre los tres estados: cargando → éxito / error.
