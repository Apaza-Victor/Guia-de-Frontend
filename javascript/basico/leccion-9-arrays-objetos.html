Arrays y objetos

Guarda colecciones con arrays, modela entidades con objetos clave:valor y combínalos para construir tu primera mini agenda.

Crear arrays, indexado y length

Un array es una lista ordenada de valores. Se crea con corchetes [] y cada elemento ocupa una posición (índice) que empieza en 0. La propiedad length guarda cuántos elementos tiene.

// Crear un array (puede mezclar tipos)
const dias = ["lunes", "martes", "miércoles"];
const mixto = [1, "hola", true, null];

// Acceder por índice
console.log(dias[0]);              // "lunes"
console.log(dias[dias.length - 1]); // "miércoles" ← último

// Cambiar un valor y añadir al final sin métodos
dias[1] = "martes (editado)";
dias[dias.length] = "jueves";

Añadir y quitar: push, pop, shift y unshift

Estos cuatro métodos mutan el array (lo modifican directamente) y son la base de listas dinámicas, colas y pilas.

const cola = ["Ana", "Luis"];

cola.push("Marta");        // agrega al final   → ["Ana","Luis","Marta"]
cola.pop();              // quita el último    → ["Ana","Luis"]

cola.unshift("Sofía");     // agrega al inicio  → ["Sofía","Ana","Luis"]
cola.shift();            // quita el primero   → ["Ana","Luis"]

console.log(cola);          // ["Ana", "Luis"]
MétodoAcciónPosiciónDevuelve
push(x)AñadeFinalNueva longitud

Tip: Acuérdate del orden: p en push (para atrás) / pop (para atrás); unshift / shift (una posición al frente).

Recorrer un array con for

La pareja for + length es la forma clásica de recorrer arrays, ideal cuando necesitas el índice o recorrer una parte.

const frutas = ["manzana", "pera", "uva"];

// for clásico con índice
for (let i = 0; i < frutas.length; i++) {
  console.log(`${i + 1}. ${frutas[i]}`);
}
// "1. manzana", "2. pera", "3. uva"

// for...of: solo los valores (más limpio)
for (const fruta of frutas) {
  console.log(fruta);
}
Cuidado: No recorras con i <= frutas.length: como los índices van de 0 a length - 1, eso leería undefined en la última vuelta.

Objetos: clave:valor y acceso con . o []

Un objeto agrupa datos relacionados en pares clave: valor. Se crea con llaves {} y se lee con notación de punto o de corchete.

const usuario = {
  nombre: "Ana",
  edad: 28,
  activo: true
};

// Acceso con punto (estático, fácil de leer)
console.log(usuario.nombre); // "Ana"

// Acceso con corchete (dinámico, útil con variables)
const clave = "edad";
console.log(usuario[clave]);        // 28
console.log(usuario["nombre"]);   // "Ana"

// Modificar y añadir propiedades
usuario.edad = 29;
usuario.email = "ana@frontend.pro";

Tip: Usa punto cuando la clave sea fija y conocida; usa corchete cuando la clave llegue en una variable (objeto[variable]).

Array de objetos: la estructura favorita

Combinar arrays y objetos es la manera más natural de modelar colecciones del mundo real: un array donde cada elemento es un objeto.

const contactos = [
  { nombre: "Ana",  telefono: "555-0101" },
  { nombre: "Luis", telefono: "555-0102" },
  { nombre: "Marta", telefono: "555-0103" }
];

// Añadir un contacto nuevo
contactos.push({ nombre: "Sofía", telefono: "555-0104" });

// Recorrer y acceder a cada propiedad
for (let i = 0; i < contactos.length; i++) {
  console.log(contactos[i].nombre + " → " + contactos[i].telefono);
}

    Repaso rápido

    • Los arrays guardan listas: [], índices desde 0 y propiedad length.
    • push/pop trabajan el final; unshift/shift el inicio. Mutan el array.
    • Recorre con for (let i = 0; i < a.length; i++) o con for...of.
    • Los objetos modelan entidades: { clave: valor }, acceso con . o [].
    • Un array de objetos es la base de cualquier lista de datos real (agenda, catálogo, usuarios…).
