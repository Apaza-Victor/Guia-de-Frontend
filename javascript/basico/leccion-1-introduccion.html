Introducción a JavaScript

Qué es JavaScript, dónde vive y cómo darle vida a tus páginas web con tu primer script.

¿Qué es JavaScript?

JavaScript (JS) es el lenguaje de programación de la web. Mientras HTML estructura el contenido y CSS lo estiliza, JavaScript es el cerebro: controla el comportamiento, la interacción y la lógica de cada página. Es el único lenguaje que ejecutan nativamente todos los navegadores modernos.

Crearás desde animaciones fluidas hasta aplicaciones completas con bases de datos y servidores.

Navegador

El entorno nativo de JS: DOM, eventos, fetch API, localStorage…

Node.js

Ejecuta JS fuera del navegador: servidores, CLIs, automatización.

Móvil & Desktop

React Native, Electron, Tauri… JS va a todas partes.

Primeras interacciones: console, alert y comentarios

Las tres formas más simples de interactuar con JS son: escribir en la consola, mostrar una alerta y dejar comentarios para otros desarrolladores.

// Un comentario de una línea

/*
  Un comentario
  de varias líneas
*/

// Mostrar mensaje en la consola del navegador (F12 → Console)
console.log("¡Hola desde JavaScript!");

// Mostrar una alerta emergente
alert("¡Bienvenido a tu primera lección de JS!");

// Advertencia en la consola (amarilla)
console.warn("Esto es una advertencia");

// Mensaje de error (rojo)
console.error("Esto es un error");

Tip: console.log() es tu mejor amigo para depurar. Puedes pasarle variables, objetos y hasta expresiones enteras.

Cómo insertar JavaScript en una página

Existen varias formas de incluir JS, pero las más comunes son el script interno y el script externo.

Script al final del body (recomendado para scripts sin defer)

<body>
  <!-- Todo el HTML carga primero -->
  <h1>Mi página</h1>

  <script>
    console.log("Carga al final, el DOM ya existe");
  </script>
</body>

Script con defer en el head (también recomendado)

<head>
  <script src="app.js" defer></script>
</head>
<!-- defer ejecuta el script después de parsear el HTML completo -->
MétodoVentajaCuándo usarlo
<script> al final del <body>El DOM ya está listo al ejecutarsePáginas con pocos scripts
defer en el <head>Descarga en paralelo, ejecuta después del DOMLa mayoría de proyectos modernos
async en el <head>Ejecuta tan pronto descarga (sin esperar DOM)Scripts independientes (analytics, etc.)
Importante: Evita el atributo type="module" hasta que conozcas módulos ES6. Por ahora, usa defer o coloca el script al final del body.

Repaso rápido

  • JavaScript es el lenguaje de programación de la web: estructura + estilo + comportamiento.
  • Vive en el navegador (DOM, eventos) y fuera de él con Node.js.
  • console.log(), alert() y los comentarios son tus primeras herramientas.
  • Usa defer o coloca el script al final del <body> para que el DOM esté listo antes de ejecutar.
