Funciones

Organiza tu código en bloques reutilizables: declaraciones, expresiones, arrow functions y el alcance de las variables.

¿Qué es una función?

Una función es un bloque de código reutilizable que realiza una tarea específica. Las funciones son el pilar de la programación: permiten organizar, reutilizar y simplificar el código.

// Declaración de función (function declaration)
function saludar(nombre) {
  return `¡Hola, ${nombre}!`;
}

// Llamada a la función
const mensaje = saludar("Ana");
console.log(mensaje); // "¡Hola, Ana!"

Expresión de función

Una expresión de función asigna una función anónima a una variable. A diferencia de la declaración, no se eleva (hoisting): no puedes llamarla antes de definirla.

// Expresión de función (function expression)
const sumar = function(a, b) {
  return a + b;
};

console.log(sumar(3, 5)); // 8

// Hoisting: la declaración SÍ se eleva, la expresión NO
multiplicar(2, 4); // ✅ Funciona (declaración)

function multiplicar(a, b) {
  return a * b;
}

// sumar(2, 4); // ❌ ReferenceError: Cannot access 'sumar' before initialization

Arrow functions (=>)

Las arrow functions (ES6) son una forma abreviada de escribir funciones. Son más concisas y tienen una sintaxis limpia, especialmente para funciones cortas.

// Función flecha con parámetros
const sumar = (a, b) => a + b;

// Función flecha sin parámetros
const decirHola = () => "¡Hola!";

// Con un solo parámetro (paréntesis opcionales)
const duplicar = n => n * 2;

// Con cuerpo de bloque (requiere return explícito)
const calcularEdad = (anioNacimiento) => {
  const anioActual = new Date().getFullYear();
  return anioActual - anioNacimiento;
};

// Parámetros por defecto
const saludar = (nombre = "mundo") => `¡Hola, ${nombre}!`;

console.log(saludar());          // "¡Hola, mundo!"
console.log(saludar("Ana"));    // "¡Hola, Ana!"
console.log(sumar(10, 5));     // 15
console.log(duplicar(7));      // 14
SintaxisCuándo usarla
() => valorFunciones cortas con retorno implícito

param => valorSolo un parámetro: paréntesis opcionales

Precaución: Las arrow functions no tienen su propio this. Para constructores de clases o métodos que necesiten this, usa la función tradicional. Los detalles de this se cubren en la sección intermedia.

Scope global vs. local

El scope (alcance) determina dónde es accesible una variable. Comprender el scope evita bugs difíciles de rastrear.

// Scope global: accesible en toda la página
let globalVar = "Soy global";

function miFuncion() {
  // Scope local: solo accesible DENTRO de la función
  let localVar = "Soy local";

  console.log(globalVar);  // ✅ Puede acceder a global
  console.log(localVar);   // ✅ Puede acceder a local
}

miFuncion();

// console.log(localVar); // ❌ ReferenceError: localVar is not defined
console.log(globalVar);     // ✅ "Soy global"
ScopeDeclarado conAccesible desde
GlobalFuera de toda función/bloqueCualquier lugar del script
Local (función)Dentro de una funciónSolo dentro de esa función
Local (bloque)Dentro de {} con let/constSolo dentro de ese bloque
Regla de oro: Minimiza las variables globales. Usa const y let dentro de funciones o bloques para mantener el scope controlado y el código predecible.

Repaso rápido

  • Las funciones son bloques reutilizables: declaración, expresión y arrow function.
  • const f = () => valor es la forma más concisa para funciones cortas.
  • Los parámetros por defecto (param = valor) evitan undefined.
  • return devuelve un valor; sin return, la función devuelve undefined.
  • Scope global = accesible en todas partes; scope local = solo dentro de la función/bloque.
  • Las declaraciones se elevan (hoisting); las expresiones y arrow functions no.
