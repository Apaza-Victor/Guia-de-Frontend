Tipos de datos

Conoce los 7 tipos primitivos, los valores por referencia, casos especiales como NaN e Infinity y cómo inspeccionarlos con typeof e instanceof.

Primitivos y tipos por referencia

Toda la información que maneja JavaScript se clasifica en dos grandes grupos: los tipos primitivos (valores simples e inmutables) y los tipos por referencia (objetos y colecciones). Conocer esta distinción explica muchos comportamientos aparentemente extraños.

// Primitivos: se copian por VALOR
let a = 10;
let b = a;         // b recibe una copia del valor
b = 99;
console.log(a);   // 10 ← a no cambió

// Por referencia: se copia la REFERENCIA (ambos apuntan al mismo objeto)
const obj1 = { nombre: "Ana" };
const obj2 = obj1;
obj2.nombre = "Luis";
console.log(obj1.nombre); // "Luis" ← ambos señalan el mismo objeto

Los 7 tipos primitivos

JavaScript tiene 7 tipos primitivos. Todos se escriben directamente en el código y son valores simples.

let texto = "Hola";        // string: texto
let numero = 42;          // number: enteros y decimales
let activo = true;        // boolean: true o false
let vacio = null;          // null: ausencia intencional de valor
let indefinido;            // undefined: sin valor asignado
let grande = 123n;       // bigint: enteros de precisión arbitraria
let unico = Symbol("id"); // symbol: identificador único

NaN e Infinity

El tipo number incluye tres "valores especiales" que debes reconocer: NaN (Not a Number), Infinity y -Infinity.

// NaN aparece cuando una operación numérica falla
console.log(0 / 0);              // NaN
console.log("abc" * 2);      // NaN

// Infinity aparece al desbordar o dividir entre valores límite
console.log(1 / 0);              // Infinity
console.log(-1 / 0);             // -Infinity

// Cuidado: NaN NO es igual a sí mismo
console.log(NaN === NaN);     // false ← único valor que no se compara a sí mismo
console.log(Number.isNaN(NaN)); // true  ← así se comprueba de forma segura
Importante: No confundas isNaN() global (fuerza conversión a número) con Number.isNaN() (solo detecta NaN de verdad). Para comprobar valores numéricos reales usa Number.isNaN() y Number.isFinite().

typeof: ¿qué tipo es este valor?

El operador typeof devuelve una cadena con el tipo de un valor, útil para depurar y validar datos.

console.log(typeof 42);            // "number"
console.log(typeof "Hola");      // "string"
console.log(typeof true);        // "boolean"
console.log(typeof null);        // "object" ← bug histórico
console.log(typeof undefined);    // "undefined"
console.log(typeof Symbol("x")); // "symbol"
console.log(typeof 123n);        // "bigint"
console.log(typeof [1, 2]);     // "object" ← los arrays son objetos
console.log(typeof function () {}); // "function"

instanceof: comprobar un tipo por referencia

Si typeof te dice "object" pero quieres saber si es un array, una fecha o una clase concreta, usa el operador instanceof.

const lista = [1, 2, 3];
const fecha = new Date();

console.log(lista instanceof Array);   // true
console.log(lista instanceof Object);   // true ← todo objeto es Object
console.log(fecha instanceof Date);    // true
console.log(Array.isArray(lista));     // true ← alternativa específica para arrays
Regla rápida: primitivos → typeof; arrays/objetos/instancias → instanceof (o Array.isArray() para arrays).

Repaso rápido

  • Los 7 primitivos son: string, number, boolean, null, undefined, symbol y bigint.
  • Los objetos y arrays se copian por referencia; los primitivos, por valor.
  • NaN e Infinity son valores numéricos especiales; compruébalos con Number.isNaN() y Number.isFinite().
  • typeof dice el tipo de un valor; instanceof distingue qué tipo de objeto es.
  • El typeof null devuelve "object": es un bug histórico conocido.
