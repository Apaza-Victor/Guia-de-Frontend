Bucles y iteración

Repite tareas eficientemente con for, while, do-while, for...of y controla el flujo con break/continue.

¿Qué es un bucle?

Un bucle es una estructura de control que repite un bloque de código mientras se cumpla una condición. Los bucles son fundamentales: sin ellos, tendrías que escribir código repetido para cada elemento o iteración.

BucleCuándo usarloParticularidad
forCuando sabes cuántas veces iterarInicialización, condición e incremento en una línea
whileCuando la condición puede cambiar externamenteSe ejecuta 0 o más veces
do...whileSiempre ejecutar al menos una vezCondición al final
for...ofIterar arrays (valores directamente)Limpio, sin índices manuales

El bucle clásico: for

El bucle for es el más versátil. Tiene tres partes: inicialización, condición y actualización.

// Sintaxis: for (inicio; condición; incremento) { ... }
for (let i = 0; i < 5; i++) {
  console.log(`Iteración ${i}`);
}
// Salida: Iteración 0, 1, 2, 3, 4

// Recorrer un array por índice
const frutas = ["manzana", "plátano", "naranja"];
for (let i = 0; i < frutas.length; i++) {
  console.log(`Fruta ${i + 1}: ${frutas[i]}`);
}
Tip: Usa let (no var) para la variable del bucle. Así el scope es limitado al bloque del bucle y no se filtra.

while y do...while

Los bucles while y do...while son ideales cuando no conoces de antemano cuántas iteraciones necesitas.

while

let contador = 0;

while (contador < 5) {
  console.log(`Contador: ${contador}`);
  contador++;
}
// Se ejecuta mientras la condición sea true.
// Si la condición es false desde el inicio, NO se ejecuta.

do...while

let intentos = 0;

do {
  intentos++;
  console.log(`Intento #${intentos}`);
} while (intentos < 3);

// Siempre se ejecuta AL MENOS UNA vez antes de evaluar la condición.
Característicawhiledo...while
Ejecución mínima0 veces1 vez
Posición de la condiciónAntes del bloqueDespués del bloque
Uso típicoCuando el estado inicial puede ya satisfacer la condiciónFormularios, menús, entrada de usuario
¡Cuidado con los bucles infinitos! Si la condición nunca se vuelve false, el navegador se congelará. Siempre asegúrate de que la variable de control cambie dentro del bucle.

break y continue

Estas dos palabras clave controlan el flujo dentro de cualquier bucle.

// break: sale del bucle completamente
for (let i = 0; i < 100; i++) {
  if (i === 5) break;
  console.log(i); // 0, 1, 2, 3, 4
}

// continue: salta a la siguiente iteración
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) continue; // salta pares
  console.log(i); // 1, 3, 5, 7, 9
}
Palabra claveEfectoEjemplo práctico
breakTermina el bucle inmediatamenteBuscar un elemento y salir al encontrarlo
continueSalta a la siguiente iteraciónIgnorar elementos que no cumplen condición

for...of: iteración moderna sobre arrays

El bucle for...of (ES6) recorre los valores de un iterable (array, string, Map, Set) de forma limpia, sin manejar índices.

const colores = ["rojo", "verde", "azul"];

// for...of: directamente sobre los valores
for (const color of colores) {
  console.log(color); // "rojo", "verde", "azul"
}

// También funciona con strings
for (const letra of "Hola") {
  console.log(letra); // "H", "o", "l", "a"
}
Bucle¿Qué itera?Acceso a índiceLegibilidad
for (let i...)Por índice manualSí (i)Verbosa
for...ofValores del iterableNo directamenteLimpia y moderna
forEach()Valores + índice (callback)Como argumentoFuncional
¿Por qué no forEach aquí? forEach() es un método de array que requiere funciones como callback. Se estudia detalladamente en la sección de Arrays y métodos de array. Por ahora, domina for y for...of como base sólida.

    Repaso rápido

    • for es ideal cuando conoces el número de iteraciones de antemano.
    • while evalúa la condición antes; do...while ejecuta al menos una vez.
    • break sale del bucle; continue salta a la siguiente iteración.
