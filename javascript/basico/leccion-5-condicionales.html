Condicionales

Toma decisiones en tu código con if/else, switch, el operador ternario y domina los valores truthy/falsy.

if / else if / else

La estructura condicional más usada: ejecuta un bloque según el resultado de una expresión booleana. Evalúa ramas en orden y se detiene en la primera que sea true.

const edad = 22;

if (edad < 13) {
  console.log("Eres un niño");
} else if (edad < 18) {
  console.log("Eres un adolescente");
} else if (edad < 65) {
  console.log("Eres un adulto");
} else {
  console.log("Eres un adulto mayor");
}
// Resultado: "Eres un adulto"
ParteCuándo se ejecuta
if (condición)Siempre se evalúa primero
else if (condición)Solo si las anteriores fueron false
elseSi ninguna condición se cumplió

switch: comparar contra valores exactos

Cuando comparas una misma variable contra muchos valores concretos, switch es más limpio que una cadena de if. Ojo: sin break el código se desliza a la siguiente rama.

const dia = "lunes";

switch (dia) {
  case "lunes":
  case "martes":
  case "miércoles":
  case "jueves":
  case "viernes":
    console.log("Día laborable");
    break;
  case "sábado":
  case "domingo":
    console.log("¡Fin de semana!");
    break;
  default:
    console.log("Día no válido");
}
Recuerda: sin break (o return), el switch continúa ejecutando las siguientes ramas. Es una fuente clásica de bugs.

El operador ternario

El operador ternario condición ? valorSiTrue : valorSiFalse es un if/else en una sola línea. Perfecto para asignaciones cortas.

const edad = 20;
const mensaje = edad >= 18 ? "Mayor de edad" : "Menor de edad";
console.log(mensaje); // "Mayor de edad"

// Equivalente con if/else
let otroMensaje;
if (edad >= 18) {
  otroMensaje = "Mayor de edad";
} else {
  otroMensaje = "Menor de edad";
}
Tip: El ternario es ideal para asignaciones rápidas. Para lógica compleja con 3+ ramas, usa if/else o switch para mantener la legibilidad.

Valores truthy y falsy

En JavaScript, toda condición se convierte a booleano. Los valores que se evalúan como false se llaman falsy; todos los demás son truthy. Solo hay 6 falsy.

// Los 6 valores FALSY:
if (false)   {} // false
if (0)       {} // cero
if ("")      {} // string vacío
if (null)    {} // null
if (undefined) {} // undefined
if (NaN)     {} // NaN

// Todo lo demás es TRUTHY, incluso valores que "parecen vacíos":
if ("0")    {} // ✅ string "0" es truthy
if ([0])    {} // ✅ array con elementos
if (" ")    {} // ✅ hasta un espacio es truthy
if ([])      {} // ✅ un array vacío también es truthy
FalsyTruthy (ejemplos)
false, 0, "", null, undefined, NaNtrue, 1, "hola", "0", [], {}, Infinity
Bug clásico: validar "si hay elementos" con if (array.length) está bien, pero if (array) siempre es true para cualquier array. Verifica la longitud.

Comparaciones estrictas con ===

Para que una condición sea fiable, compara siempre con === y !==. La igualdad débil == convierte tipos y produce resultados sorprendentes.

const entrada = "5";  // viene de un formulario

// Débil: convierte tipos → puede "falsear" la realidad
console.log(entrada == 5);   // true
console.log(0 == false);   // true

// Estricta: compara valor Y tipo
console.log(entrada === 5);  // false ← string !== number

// Si esperas un número, conviértelo antes
const numero = Number(entrada);
console.log(numero === 5); // true ✅
Regla de oro: usa siempre ===/!==. Si el dato llega como string desde un formulario, conviértelo con Number() antes de comparar.
