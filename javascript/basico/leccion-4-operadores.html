Operadores

Calcula con aritméticos, compara valores con precisión y combina condiciones con los operadores lógicos.

Operadores aritméticos

Los operadores aritméticos básicos funcionan como en matemáticas, pero con algunas particularidades en JavaScript.

const a = 10;
const b = 3;

console.log(a + b);   // 13   → Suma
console.log(a - b);   // 7    → Resta
console.log(a * b);   // 30   → Multiplicación
console.log(a / b);   // 3.33 → División
console.log(a % b);   // 1    → Módulo (resto)
console.log(a ** b);  // 1000 → Potencia
console.log(7 / 2);   // 3.5  → JS no trunca, devuelve decimal
console.log("5" + 3); // "53" → ⚠️ Concatena strings con números
OperadorNombreEjemploResultado
+Suma10 + 313
-Resta10 - 37
*Multiplicación10 * 330
/División10 / 33.333…
%Módulo (resto)10 % 31

Cuidado: "5" + 3 devuelve "53" (concatenación), mientras que "5" - 3 devuelve 2 (conversión implícita). JavaScript puede ser inesperado con operadores mixtos.

Operadores de comparación

La diferencia más importante para principiantes: == compara valores con coerción de tipo, mientras que === compara valor y tipo.

// Igualdad débil (==): convierte tipos antes de comparar
console.log(5 == "5");    // true  ← convierte el string a número
console.log(0 == false);  // true  ← false se convierte a 0
console.log(null == undefined); // true ← ambigüedad de JS

// Igualdad estricta (===): compara valor Y tipo, sin conversión
console.log(5 === "5");   // false ← number !== string
console.log(0 === false); // false ← number !== boolean

// Desigualdad: !== es la versión estricta de !=
console.log(5 !== "5");   // true ← estricta
console.log(5 != "5");    // false ← débil

// Comparaciones mayores/menores
console.log(10 > 5);   // true
console.log(10 <= 10); // true
console.log(10 >= 11); // false

===Igualdad estrictaSin conversión✅ Siempre usar
!=Desigualdad débilConvierte tipos❌ No usar

Operadores lógicos

Permiten combinar múltiples condiciones en una sola expresión booleana.

const edad = 20;
const tienePermiso = true;

// AND (&&): ambas condiciones deben ser true
console.log(edad >= 18 && tienePermiso);  // true

// OR (||): al menos una condición debe ser true
console.log(edad >= 65 || tienePermiso);  // true

// NOT (!): invierte el valor booleano
console.log(!tienePermiso);              // false
console.log(!(!false));                // true

// Nullish coalescing (??): usa el valor de la derecha si izquierda es null/undefined
const nombre = null;
console.log(nombre ?? "Anónimo");        // "Anónimo"
OperadorResultadoRegla
A && Btrue solo si ambos son trueAmbos deben cumplir
A || Btrue si al menos uno es trueCualquiera cumple
!AInvierte el valor booleanoNiega la condición
A ?? BUsa B si A es null o undefinedValor por defecto seguro
Tip: && y || no devuelven siempre true/false: devuelven el último valor evaluado. Por eso también se usan como atajos para valores por defecto.

Repaso rápido

  • Siempre usa === y !== en lugar de == y !=.
  • && exige ambas verdades; || acepta que una sea verdadera; ! invierte el valor.
  • ?? ofrece un valor alternativo solo ante null/undefined.
  • Cuidado con la coerción de tipos en operaciones mixtas entre strings y números.
