Clases y herencia

Organiza tu código con clases, herencia, métodos estáticos y campos privados.

Clases: azúcar sintáctica sobre prototipos

Las clases (ES6) son una forma clara de crear objetos y compartir comportamiento. En el fondo, JavaScript sigue usando su sistema de prototipos, pero la sintaxis class es mucho más legible y familiar. 

class Usuario {
  constructor(nombre, email) {
    this.nombre = nombre;      // propiedad creada en el constructor
    this.email  = email;
    this.logueado = false;
  }

  // Método: se ejecuta en el contexto de "this"
  saludar() {
    return `Hola, soy ${this.nombre}`;
  }

  loguear() {
    this.logueado = true;
  }
}

const ana = new Usuario("Ana", "ana@mail.com");
ana.loguear();
console.log(ana.saludar());   // "Hola, soy Ana"
Tip: Convendía usar new cuando instancie. Los nombres de las clases se escriben en UpperCamelCase (Usuario, PedidoDetalle) para distinguir la "plantilla" de las variables.

Getters y setters

Los getters y setters permiten leer y modificar un valor con la sintaxis de una propiedad normal, pero ejecutando lógica por debajo (validar, formatear, calcular). 

class Producto {
  constructor(precio) {
    this._precio = precio;
  }

  // GETTER: se lee como propiedad "producto.precio"
  get precio() {
    return `$${this._precio.toFixed(2)}`;
  }

  // SETTER: valida antes de asignar
  set precio(nuevoValor) {
    if (nuevoValor < 0) throw new Error("Precio no puede ser negativo");
    this._precio = nuevoValor;
  }
}

const camisa = new Producto(19.5);
camisa.precio = 25;       // usa el setter
console.log(camisa.precio); // usa el getter → "$25.00"

Herencia: extends y super

Con extends una clase hereda la funcionalidad de otra, y con super llamas al constructor o a métodos de la clase padre. 

class Administrador extends Usuario {
  constructor(nombre, email, permisos) {
    super(nombre, email);      // ejecuta el constructor de Usuario
    this.permisos = permisos;
  }
// Continúa la clase…
  // Sobre-escribe el método del padre
  saludar() {
    return super.saludar() + " (admin)";
  }

  banear(usuario) {
    console.log(`${usuario} fue baneado`);
  }
}

const jefe = new Administrador("Bruno", "b@mail.com", ["borrar", "editar"]);
jefe.saludar();   // "Hola, soy Bruno (admin)"
  • Reutilizas lógica del padre en vez de copiarla.
  • Polimorfismo: el método del hijo gana cuando existe uno con el mismo nombre.
  • Siempre llama a super(...) ANTES de usar this en el constructor hijo.

Métodos estáticos y campos privados

class Cuenta {
  // Campo privado: NO accesible desde fuera (#)
  #saldo = 0;

  depositar(monto) {
    this.#saldo += monto;
  }

  verSaldo() {
    return this.#saldo;
  }

  // Método ESTÁTICO: se usa sobre la clase, no sobre la instancia
  static formatear(monto, moneda = "USD") {
    return new Intl.NumberFormat("es-ES", { style: "currency", currency: moneda }).format(monto);
  }
}

const mia = new Cuenta();
mia.depositar(100);
console.log(Cuenta.formatear(mia.verSaldo())); // "100,00 $US"
console.log(mia.#saldo); // SyntaxError: campo privado inaccesible

    class CuentaBancaria {
  #saldo;
  #historial = [];

  constructor(titular, saldoInicial = 0) {
    this.titular = titular;
    this.#saldo = saldoInicial;
  }

  get saldo() {
    return this.#saldo;
  }

  depositar(monto) {
    if (monto <= 0) return false;
    this.#saldo += monto;
    this.#historial.push(`+ ${CuentaBancaria.formatear(monto)}`);
    return true;
  }

  retirar(monto) {
    if (monto <= 0 || monto > this.#saldo) return false;
    this.#saldo -= monto;
    this.#historial.push(`- ${CuentaBancaria.formatear(monto)}`);
    return true;
  }

  static formatear(monto) {
    return new Intl.NumberFormat("es-ES",
      { style: "currency", currency: "EUR" }).format(monto);
  }
}

    Repaso rápido

    • class + constructor definen la plantilla; los métodos viven en el prototipo.
    • Getters/setters controlan lectura y escritura; static vive en la clase.
    • extends hereda y super(...) llama a la clase padre. Llama super antes de usar this.
    • Los campos #privados encapsulan el estado y evitan bugs difíciles de rastrear.
