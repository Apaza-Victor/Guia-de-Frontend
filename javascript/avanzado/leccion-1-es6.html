ES6+: destructuring y spread

Extrae datos de objetos y arrays con destructuring, combina valores con spread y escribe código más limpio.

Destructuring de objetos

El destructuring (desestructuración) te permite extraer valores de un objeto o un array y asignarlos a variables en una sola línea, sin repeticiones innecesarias. Es de las características de ES6 que más código eliminan en el día a día. 

// Sin destructuring: mucha repetición
const nombre = usuario.nombre;
const edad   = usuario.edad;

// Con destructuring: una sola línea
const { nombre, edad } = usuario;

// Se puede hacer en los parámetros de una función
function saludar({ nombre, edad }) {
  return `Hola ${nombre}, tienes ${edad} años.`;
}
Tip: El destructuring solo crea una copia del valor en la variable. Para objetos anidados usa la misma sintaxis dentro: { perfil: { avatar } }. El nombre de la variable NO se inventa: debe coincidir con la propiedad del objeto. 
// Objetos anidados y rest
const pedido = {
  id: 104,
  cliente: { nombre: "Ana", mail: "ana@mail.com" },
  productos: ["Teclado", "Mouse"]
};

const { id, cliente: { nombre } } = pedido;
console.log(id, nombre); // 104 "Ana"

Destructuring de arrays

Con los arrays el orden importa: cada posición de la izquierda toma el valor de la misma posición a la derecha.

const colores = ["rojo", "verde", "azul"];

const [primero, segundo] = colores;
console.log(primero, segundo); // "rojo" "verde"

// Puedes saltar posiciones con comas vacías
const [, , tercero] = colores;
console.log(tercero); // "azul"

// Truco clásico: intercambiar valores sin variable temporal
let a = 1, b = 2;
[a, b] = [b, a]; // a = 2, b = 1
// React y destructuring de arrays: los hooks
const [estado, setEstado] = useState("inicial");

Rest y spread: el poder de ...

El operador ... tiene dos personalidades: rest (recolecta el resto en una variable, "empuja hacia adentro") y spread (expande valores, "dispersa hacia afuera"). 

// REST: agrupar el "resto" de los valores
const [primero, ...resto] = [1, 2, 3, 4];
console.log(resto); // [2, 3, 4]

const { nombre, ...datosExtra } = persona;

// Parámetros rest en funciones
function sumar(...numeros) {
  return numeros.reduce((acum, n) => acum + n, 0);
}
sumar(1, 2, 3); // 6

// SPREAD: expandir un array en argumentos
const nums = [4, 5];
Math.max(...nums, 9); // 9

// Copiar y combinar (copia superficial)
const copia      = [...nums];
const combinado  = [...nums, 6, 7];
const fondoNuevo = { ...config, tema: "oscuro" };

Alias, valores por defecto y shorthand

Tres pequeños superpoderes que hacen el destructuring aún más flexible:

// ALIAS: renombrar la variable extraída
const { nombre: nombreCompleto } = usuario;

// VALORES POR DEFECTO: si no existe, usa el fallback
const { ciudad = "Desconocida" } = usuario;
const [x = 0, y = 0] = punto;

// SHORTHAND PROPERTIES: si clave === variable, omite la repetición
const nombre = "Lía";
const edad   = 30;
const obj    = { nombre, edad }; // { nombre: "Lía", edad: 30 }

// Shorthand también funciona en MÉTODOS (shorthand methods)
const perro = {
  nombre: "Tino",
  ladrar() { return "¡Guau!"; }  // antes: ladrar: function() {...}
};

Optional chaining (?.) y nullish (??)

Acceder a propiedades anidadas solía romper el código cuando faltaba un dato. Con optional chaining la expresión "se detiene" y devuelve undefined si el antecesor es null o undefined. Con nullish coalescing eliges un valor por defecto solo cuando hay null o undefined. 

// Antes (peligroso):
const ciudad = usuario.direccion.ciudad; // TypeError si direccion es undefined

// Con optional chaining:
const ciudad = usuario?.direccion?.ciudad; // undefined si falta, sin fallo

// Nullish coalescing:
const contexto = datos ?? "Sin datos";

// Cuidado: 0, "" y false NO son "nullish", usar || los reemplazaría
const precio = descuento ?? 0; // si descuento es 0, mantiene 0 con ??
Ojo: ?? y || NO son intercambiables. || reemplaza cualquier valor "falso" (0, "", false, NaN); ?? solo reemplaza null y undefined. Además no puedes mezclar ?? con && o || sin paréntesis.

Métodos modernos de objetos

ES6+ añadió helpers que recorren objetos sin bucles manuales:

const inventario = { manzanas: 4, peras: 2 };

Object.keys(inventario);   // ["manzanas", "peras"]
Object.values(inventario); // [4, 2]
Object.entries(inventario); // [["manzanas", 4], ["peras", 2]]

// Recorrer con for...of + destructuring
for (const [fruta, cantidad] of Object.entries(inventario)) {
  console.log(`${fruta}: ${cantidad}`);
}

// Combinar objetos (copia superficial de cada fuente)
const unido = Object.assign({}, inventario, { uvas: 6 });

Demo interactiva

Desestructuramos cada usuario de un array y creamos una tarjeta con spread (así cada nueva tarjeta parte de un estado base). El botón agrega un usuario nuevo creado con { ...base, ...datos }.

También hay un usuario anidado: se accede con usuario.perfil.rol sin fallos gracias a ?. 

const base = { online: true, plan: "básico" };

const crearTarjeta = grupo =>
  grupo.map(({ nombre, edad, ciudad, perfil }) => `
    Carta de ${nombre} · ${edad} años
    Vive en ${ciudad ?? "—"} · Rol: ${perfil?.rol ?? "default"}
  `).join("");

Repaso rápido

  • Destructuring de objetos usa las claves como nombres; el de arrays usa el orden.
  • Rest (en declaración) agrupa; spread (en llamadas/literales) expande.
  • Usa alias (prop: nombre), valores por defecto (prop = val) y shorthand properties.
  • ?. protege el acceso anidado y ?? pone fallback solo ante null/undefined.
