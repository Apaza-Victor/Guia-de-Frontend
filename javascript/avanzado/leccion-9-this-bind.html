this, call, apply y bind

Controla el contexto de tus funciones en cada llamada.

¿Qué es this y cómo se determina?

this es un valor dinámico: no depende de dónde se declara la función, sino de cómo se llama. Las reglas principales:

Llamada normal

fn() → this es undefined (estricto) o window.

Método de objeto

obj.fn() → this es obj.

new / arrow

new F() → el nuevo objeto; las flechas heredan el de fuera.

Ojo: El error más clásico: pasar un método sin contexto (addEventListener('click', obj.metodo)) hace que this sea el elemento clickeado. Para eso existen bind y las flechas.

call y apply: invocar con contexto

fn.call(contexto, a, b) y fn.apply(contexto, [a, b]) invocan la función de inmediato forzando el this. La única diferencia: apply recibe los argumentos en array. 

function presentar(ciudad, anio) {
  return `${this.nombre} vive en ${ciudad} desde ${anio}`;
}

const persona = { nombre: 'Ana' };

presentar.call(persona, 'Lima', 2018);   // "Ana vive en Lima desde 2018"
presentar.apply(persona, ['Lima', 2018]); // igual

// "Préstamo" clásico:
Array.prototype.slice.call(arguments);
Tip: apply brilla cuando el número de argumentos es variable: por ejemplo Math.max.apply(null, [3, 9, 4]) (hoy prefieres Math.max(...arr), pero el patrón vive en librerías antiguas).

bind: fijar para siempre

fn.bind(contexto) NO ejecuta: devuelve una copia con el this fijado. Perfecto para pasar métodos a eventos o timers sin perder el contexto: 

const contador = {
  valor: 0,
  incrementar() {
    this.valor++;
    console.log(this.valor);
  }
};

// ¡this se pierde! boton → elemento
boton.addEventListener('click', contador.incrementar);

// Correcto: enlazamos el contexto
boton.addEventListener('click', contador.incrementar.bind(contador));

bind también puede prefijar argumentos (parámetros parciales):

const sumar = (a, b) => a + b;
const sumar5 = sumar.bind(null, 5); // el 5 queda fijo
sumar5(3); // 8

Arrow functions: el this léxico

Las funciones flecha no tienen su propio this: lo toman del ámbito donde se crearon. Esto elimina la pérdida de contexto dentro de callbacks: 

const reloj = {
  hora: 0,
  arrancar() {
    // flecha → this = reloj, no el setTimeout
    setInterval(() => { this.hora++; }, 1000);
  }
};
Tip: Regla de oro: flecha para callbacks cortos (heredan contexto), function + bind cuando necesitas tu propio this (clases, métodos reusables).

Repaso rápido

  • this se decide en la llamada, no en la declaración.
  • call y apply invocan con contexto dado (apply con array).
  • bind devuelve una copia con contexto (y args) fijo.
  • Las flechas toman el this del ámbito exterior: adiós rest pérdida de contexto.
