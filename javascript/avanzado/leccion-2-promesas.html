Promesas y async/await

Domina el código asíncrono: promesas, estados, cadenas de .then y la elegancia de async/await.

¿Qué es una promesa?

Una promesa es un objeto que representa un valor que estará disponible ahora, en el futuro, o que nunca estará. Es el mecanismo de JavaScript para manejar operaciones que tardan: peticiones a una API, lecturas de archivos, setTimeout…

Antes de las promesas solo existían los callbacks (funciones que se pasaban como argumento). El problema: anidar demasiados callbacks crea el famoso "callback hell". Las promesas traen una cadena plana y legible.

EstadoSignificadoCómo se llega a él
pendingEn espera; no ha terminadoEstado inicial
fulfilledTodo salió bienSe llama resolve(valor)
rejectedHubo un errorSe llama reject(motivo)

Una promesa queda inmutable: una vez fulfilled o rejected, ya no cambia.

Crear una promesa: new Promise

const promesa = new Promise((resolve, reject) => {
  // Trabajo asíncrono… cuando termina:
  if (exito) {
    resolve(datos);        // → fulfilled con "datos"
  } else {
    reject(new Error("Algo falló")); // → rejected
  }
});
Tip: Rara vez escribirás new Promise a mano. Casi siempre la recibirás de una función (fetch, axios…) o la devolverás desde una función propia que envuelve APIs que aún no soportan promesas. 
// Envolver una API antigua basada en callbacks en una promesa
function leerArchivo(ruta) {
  return new Promise((resolve, reject) => {
    lector.readAsText(ruta, (error, texto) => {
      if (error) reject(error);
      else resolve(texto);
    });
  });
}

Consumir: .then / .catch / .finally

cargarUsuarios()
  .then(usuarios => {        // se ejecuta solo si fulfilled
    renderizar(usuarios);
    return cargarPosts(usuarios[0]);   // encadena la siguiente promesa
  })
  .then(posts => renderizarPosts(posts))
  .catch(error => {          // se ejecuta si cualquier paso anterior rechazó
    mostrarError(error.message);
  })
  .finally(() => {           // siempre, triunfe o falle
    ocultarSpinner();         // ideal para "limpieza"
  });
  • .then() recibe el valor resuelto y devuelve una nueva promesa (permite encadenar).
  • .catch() captura cualquier rechazo de la cadena y evita que "salte" el error global.
  • .finally() se ejecuta siempre, sin importar el resultado: temporizadores, spinners, conexiones.
// Promise.all: espera a que TODAS terminen y devuelve un array de resultados
Promise.all([cargarUsuarios(), cargarProductos(), cargarPedidos()])
  .then(([usuarios, productos, pedidos]) => { // destructuring de arrays
    inicializarApp({ usuarios, productos, pedidos });
  })
  .catch(error => console.error("Alguna petición falló", error));

// Promise.allSettled: no interrumpe si una falla, devuelve el estado de todas
Promise.allSettled([p1, p2, p3])
  .then(resultados => resultados.map(r => r.status));
Cuidado con Promise.all: Si una sola de las promesas se rechaza, Promise.all se rechaza completa (todo o nada). Si necesitas tolerancia a errores individuales, usa Promise.allSettled.

async / await

async marca a una función como "que devuelve una promesa" y habilita la palabra await dentro de ella. await pausa la ejecución hasta que la promesa se resuelve o rechaza, como si el código fuera síncrono, pero sin bloquear el hilo del navegador. 

async function cargarTodo() {
  try {
    const usuarios  = await cargarUsuarios();   // espera a que se cumpla
    const productos = await cargarProductos();
    // Equivalente a Promise.all:
    const [pedidos, reviews] = await Promise.all([cargarPedidos(), cargarReviews()]);
    renderizar({ usuarios, productos, pedidos, reviews });
  } catch (error) {
    mostrarError("No se pudo cargar: " + error.message);
  } finally {
    ocultarSpinner();
  }
}

cargarTodo(); // una función async siempre devuelve una promesa
SituaciónRecomendado
Flujo secuencial dependienteasync/await (línea a línea es más claro)
Varias peticiones independientesPromise.all (más rápido: en paralelo)
Tomar decisiones según el resultadoawait junto a try/catch

Simulamos una petición a un servidor con setTimeout. La promesa tarda 2 segundos; mientras tanto se muestra un spinner. Al terminar, según el botón que pulses, se resuelve con unos datos de ejemplo o se rechaza con un error. El finally siempre oculta el spinner.

function simularCarga(exito) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      exito
        ? resolve({ usuario: "ana_dev", posts: 12 })
        : reject(new Error("500: el servidor no responde"));
    }, 2000);
  });
}

Repaso rápido

  • Los tres estados de una promesa: pending, fulfilled, rejected.
  • Encadena con .then(), captura errores con .catch() y limpia con .finally().
  • Promise.all lanza en paralelo; Promise.allSettled tolera fallos individuales.
  • async/await lee como código síncrono; envuelve siempre en try/catch.
