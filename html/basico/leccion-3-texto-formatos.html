Texto y Formatos

Aprende a escribir contenido claro y bien estructurado: jerarquía de encabezados, énfasis, citas, código y entidades HTML.

Fundamentos de la lección

El 80% del contenido de internet es texto, y HTML tiene una etiqueta para cada intención: títulos, párrafos, negritas semánticas, citas o fragmentos de código. Usar la etiqueta correcta no solo mejora la lectura, también le da significado a los buscadores y a los lectores de pantalla.

Jerarquía de títulos <strong> vs <b> Entidades HTML

Encabezados y párrafos

Los encabezados <h1> a <h6> organizan el contenido por importancia y los párrafos <p> agrupan ideas. Solo debe existir un <h1> por página.

<h1>El título principal</h1>
<p>Primer párrafo de introducción al tema.</p>

<h2>Una sección</h2>
<p>Contenido de la sección...</p>

<h3>Un subapartado</h3>
<p>Detalle más específico.</p>
Tip: no elijas el número del encabezado por su tamaño visual sino por su jerarquía. Si quieres texto grande sin jerarquía, usa CSS, no <h1>.

Énfasis semántico: strong y em

<strong> marca importancia (por defecto se ve en negrita) y <em> marca énfasis en la pronunciación (se ve en cursiva). Los lectores de pantalla cambian su entonación con ellos.

<p>Siempre haz una <strong>copia de seguridad</strong>
antes de actualizar y <em>nunca</em> trabajes en producción.</p>
ElementoSignificadoUso correcto
<strong>Importancia fuerte"Lee esto primero" / alertas
<em>Énfasis prosódico"Ahora, no mañana"
<b> / <i>Solo estilo visualPalabras clave, nombres técnicos
Cuidado: no marques texto solo para que "salga en negrita". Si no hay importancia real, usa <b> o CSS.

Citas: blockquote y q

<blockquote> para citas en bloque (con un cita como <footer> opcional) y <q> para citas cortas dentro de una línea.

<blockquote>
  <p>La simplicidad es la sofisticación máxima.</p>
  <footer>— Leonardo da Vinci</footer>
</blockquote>

<p>Como dijo Ada: <q>la creatividad es felicidad.</q></p>

Código en línea: code, kbd y pre

  • <code> — fragmentos de código dentro de una línea.
  • <kbd> — teclas que el usuario debe pulsar (p. ej. Ctrl + C).
  • <pre> — bloque de código conservando espacios y saltos de línea.
<p>Para copiar usa <kbd>Ctrl</kbd> + <kbd>C</kbd>.</p>
<pre><code>
<h1>Hola</h1>
</code></pre>
La combinación ganadora: usa <pre><code> juntos para bloques de código. El <pre> respeta el formato y el <code> añade el significado técnico.

Entidades HTML

Para mostrar caracteres que el navegador interpreta como código (como < o &) se usan las entidades: empiezan con & y terminan con ;.

ResultadoEntidadDescripción
<&lt;Menor que (etiqueta de apertura)
>&gt;Mayor que (etiqueta de cierre)
&&amp;E comercial / Ampersand
 &nbsp;Espacio sin salto de línea
©&copy;Símbolo de copyright
 
<p>Aprende <strong>&amp;lt;h1&amp;gt;</strong> y usa &amp;amp; con cuidado.</p>

Saltos y separadores: br y hr

<br> fuerza un salto de línea dentro de un párrafo (direcciones o poemas) y <hr> dibuja una línea separadora temática entre bloques. Este mismo contenido usa <hr> entre secciones.

<p>Calle Mayor 10,<br>
28013 Madrid</p>

<hr>

<p>Nueva sección del artículo.</p>
No abuses: no uses <br> para maquetar espaciados verticales. Para eso existen margin y padding en CSS.

Repaso rápido

  • Jerarquía de títulos <h1> a <h6>: un solo <h1> por página.
  • <strong> = importancia; <em> = énfasis. Elige la etiqueta por significado, no por apariencia.
  • <blockquote> para citas largas, <q> para citas en línea.
  • <pre> + <code> para bloques de código y <kbd> para teclas.
  • Caracteres reservados se escriben con entidades: &lt;, &gt;, &amp;.
  • <br> para saltos puntuales y <hr> para separar temas.
