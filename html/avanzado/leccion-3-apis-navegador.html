APIs del navegador

Geolocalización, almacenamiento local, historial y Canvas: el navegador completo como plataforma.

El navegador como plataforma

JavaScript + HTML abren APIs que otros lenguajes no tienen: ubicación, batería, notificaciones y almacenamiento. Aprende las tres imprescindibles.

Geolocation API

navigator.geolocation.getCurrentPosition((pos) => {
  const { latitude, longitude } = pos.coords;
  console.log(latitude, longitude); // Usa una API de mapas para mostrar
});
  • El navegador pide permiso al usuario automáticamente.
  • Siempre funciona sobre HTTPS o localhost.
  • Maneja el error de "denegado" con PositionError.

LocalStorage y SessionStorage

El localStorage guarda datos de forma persistente en el dispositivo:

// Guardar (siempre en texto)
localStorage.setItem('tema', 'oscuro');

// Leer
const tema = localStorage.getItem('tema');

// Para objetos hay que serializar a JSON
localStorage.setItem('usuario', JSON.stringify({ nombre: 'Victor' }));
Tip: sessionStorage se borra al cerrar la pestaña; localStorage persiste. Nunca guardes datos sensibles aquí.

History API y estado del navegador

Forma parte de las single-page apps (SPA) sin recargar la página:

// Cambia la URL sin recargar
history.pushState({ page: 'contacto' }, '', '/contacto');

// Reacciona al botón "atrás"
window.addEventListener('popstate', () => { /* renderizar */ });

Repaso rápido

  • Geolocation necesita HTTPS y maneja el permiso del usuario.
  • localStorage persiste en el dispositivo; sessionStorage dura una pestaña.
  • History API permite construir SPAs sin recargar.
