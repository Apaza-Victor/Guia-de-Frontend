Canvas y SVG en HTML

Dos poderosas formas de dibujar en la web: <canvas> para píxeles y gráficos dinámicos, y SVG para vectores accesibles.

¿Cuándo usar cada uno?

CanvasSVG
ModeloPíxeles (raster)Formas vectoriales
Ideal paraJuegos, animaciones, fotosIconos, diagramas, logos, escalado
AccesibleNo (solo un área plana)Sí (elementos y texto indexables)
EscalaPierde nitidez al agrandarNítido a cualquier tamaño

<canvas> básico

El <canvas> es un lienzo que se dibuja con JavaScript vía su contexto 2D:

<canvas id="lienzo" width="400" height="200">
  <!-- Texto alternativo para navegadores sin soporte -->
  Tu navegador no soporta canvas.
</canvas>
const ctx = document.getElementById('lienzo').getContext('2d');
ctx.fillStyle = '#0ea5e9';      // color del relleno
ctx.fillRect(20, 20, 150, 100); // rectángulo x,y,w,h
  • fillRect, arc, beginPath y stroke son las herramientas base.
  • Se redibuja cada frame; perfecto para animaciones con requestAnimationFrame.

SVG inline

SVG se escribe directamente como XML dentro del HTML. Escala sin perder calidad y es accesible:

<svg width="100" height="100" viewBox="0 0 100 100" role="img"
     aria-labelledby="tituloCirculo">
  <title id="tituloCirculo">Círculo azul</title>
  <circle cx="50" cy="50" r="40" fill="#06b6d4"/>
</svg>
Tip: En SVG los elementos son DOM: se animan con CSS o GSAP y se estilizan con clases normales.

Tip: Solo stroke y fill no bastan: añade siempre role e aria-label a tus SVG decorativos con significado.

Repaso rápido

  • Canvas: píxeles dinámicos dibujados con JS (mejor animaciones complejas).
  • SVG: vectores en el DOM, accesibles y escalables (mejor iconos y diagramas).
  • Decide según necesites nitidez, accesibilidad o dinamismo.
