Web Components

Custom elements, Shadow DOM, templates y slots: crea tus propias etiquetas HTML reutilizables y encapsuladas.

¿Qué es un Web Component?

Un Web Component es tu propia etiqueta HTML personalizada (<mi-boton>) hecha con estándares del navegador. Obtienes reutilización y encapsulación sin frameworks.

Custom Elements

Tus propias etiquetas

Shadow DOM

Estilos y DOM aislados del exterior

Definiendo un custom element

Se define con JavaScript y customElements.define(); el nombre siempre con guion:

class MiBoton extends HTMLElement {
  connectedCallback() {
    // Se llama al insertarse en el DOM
    const root = this.attachShadow({ mode: 'open' });
    root.innerHTML = '<button><slot>Botón</slot></button>';
  }
}
customElements.define('mi-boton', MiBoton);
<mi-boton>Guardar cambios</mi-boton>
MétodoCuándo se ejecuta
connectedCallbackEl elemento entra al documento
disconnectedCallbackEl elemento se quita del documento
attributeChangedCallbackCambia un atributo observado

Shadow DOM y slots

El Shadow DOM aísla el interior del componente: sus estilos no salen ni entran. Los slots son "agujeros" por donde se inyecta el contenido del usuario:

<template id="tarjeta-tpl">
  <div class="card">
    <h3><slot name="titulo">Título</slot></h3>
    <slot>Contenido por defecto</slot>
  </div>
</template>
<mi-tarjeta>
  <span slot="titulo">Mi proyecto</span>
  Aprende a usar Web Components.
</mi-tarjeta>
Ojo: El shadowRoot con mode: 'open' es inspeccionable desde JS. Úsalo en closed solo si de verdad lo necesitas.
