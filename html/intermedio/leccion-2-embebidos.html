Contenido embebido: iframes y más

Videos, mapas, calendarios y aplicaciones externas dentro de tu página sin perder control ni seguridad.

¿Qué es un iframe?

El <iframe> inserta un documento HTML completo dentro de otro. Es la tecnología detrás de videos de YouTube, mapas de Google o widgets de Calendly.

<iframe
  src="https://www.youtube.com/embed/dQw4w9WgXcQ"
  title="Video de ejemplo"
  width="560" height="315"
  loading="lazy" allowfullscreen>
</iframe>
  • title describe el contenido para lectores de pantalla (obligatorio para accesibilidad).
  • loading="lazy" no carga el iframe hasta que se ve.
  • allowfullscreen habilita el modo a pantalla completa del video.

seguridad con sandbox y allow

Un iframe trae código ajeno a tu web. Los atributos sandbox y allow limitan lo que ese contenido puede hacer:

<iframe
  src="https://app.tercero.com/widget"
  sandbox="allow-scripts allow-forms allow-same-origin">
</iframe>
RestricciónQué permite
allow-scriptsEjecutar JavaScript dentro del iframe
allow-formsEnviar formularios desde el iframe
allow-same-originAcceder a cookies y almacenamiento. Peligroso combinado con scripts
Ojo: Nunca combines allow-scripts con allow-same-origin salvo que confíes al 100% en el contenido embebido: puede leer todo tu dominio.

Embeds típicos: YouTube y Google Maps

  • YouTube: en "Compartir → Insertar" te dan el iframe; usa la URL /embed/ID y respeta siempre su title.
  • Google Maps: "Compartir → Insertar un mapa" genera el iframe con la API output=embed.
  • Responsive: envuelve el iframe en un contenedor con padding-top para mantener la proporción 16:9.
<div style="position:relative; padding-top:56.25%;">
  <iframe style="position:absolute; inset:0; width:100%; height:100%;"
    src="https://www.youtube.com/embed/XXXX" title="Demo 16:9"></iframe>
</div>
