Introducción a HTML

Qué es HTML, por qué es el esqueleto de la web y cómo crear tu primera página.

¿Qué es HTML?

HTML (HyperText Markup Language — Lenguaje de Marcado de Hipertexto) es el lenguaje estándar que se usa para estructurar el contenido de una página web. No es un lenguaje de programación: es un lenguaje de marcado que describe el significado y la organización de cada elemento.

Una analogía útil: si una página web fuera una casa,

HTML

Los cimientos y las paredes (estructura)

CSS

La pintura y decoración (estilo)

JavaScript

La electricidad y la fontanería (comportamiento)

¿Cómo funciona una etiqueta?

HTML se compone de etiquetas (tags). La mayoría vienen en pares: una de apertura y una de cierre.

<nombre-etiqueta>Contenido</nombre-etiqueta>
  • Etiqueta de apertura: <p> — inicia el elemento.
  • Contenido: todo lo que va dentro.
  • Etiqueta de cierre: </p> — finaliza el elemento (incluye la barra /).

Propiedades clave: las etiquetas van generalmente en minúsculas y pueden llevar atributos:

<a href="https://developer.mozilla.org" target="_blank">

</a>

Tu primera página web

Todo documento HTML parte de esta estructura mínima:

<!-- 01-estructura.html -->
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi primera página</title>
  </head>
  <body>
    <h1>¡Hola, mundo!</h1>
    <p>Esto es un párrafo en mi página.</p>
  </body>
</html>
ElementoFunción
<!DOCTYPE html>Le dice al navegador que use HTML5 moderno
<html>Raíz del documento
<head>Metadatos invisibles (título, charset, estilos…)
<body>Todo el contenido visible
<h1>Encabezado de nivel 1 (el más importante)
<p>Párrafo de texto

Repaso rápido

  • HTML estructura; CSS estiliza; JS da vida.
  • Las etiquetas definen elementos y sus atributos extienden su comportamiento.
  • Siempre cierra tus etiquetas y respeta el orden de anidamiento.
