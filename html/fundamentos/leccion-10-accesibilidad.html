Accesibilidad e Inclusión

Haz que tu web funcione para todos: ARIA, foco, contraste, lectores de pantalla y una buena tarjeta de redes sociales.

Fundamentos de la lección

La accesibilidad (a11y) garantiza que tu web sea usable por personas con discapacidad visual, motora o cognitiva, y que las máquinas la entiendan. No es un extra: es una práctica profesional de frontend amparada por estándares como las WCAG. Además, una web accesible suele ser una web mejor rankeada.

ARIA tabindex Open Graph

ARIA: roles y atributos

ARIA (Accessible Rich Internet Applications) complementa HTML cuando el significado nativo no basta (p. ej. en componentes hechos a medida) mediante roles y atributos aria-*.

<nav aria-label="Navegación principal">…</nav>

<div role="tablist">
  <button role="tab" aria-selected="true">HTML</button>
</div>

<div aria-live="polite">Resultado del envío…</div>
Atributo / rolPara qué sirve
aria-labelNombre audible alternativo para un elemento
aria-selectedIndica el elemento activo de un grupo con pestañas
aria-expandedAnuncia si un menú o acordeón está abierto
aria-liveRegión que el lector de pantalla debe anunciar al cambiar
roleDefine el comportamiento que no existe como etiqueta nativa
Regla de oro: "No uses ARIA si existe una etiqueta HTML que haga lo mismo". Un <button> nativo siempre es mejor que un <div role="button">.

alt, lang e idioma

El atributo lang en <html> informa al lector de pantalla cómo pronunciar y al navegador cómo corregir ortografía. El alt describe imágenes para quien no puede verlas.

<!-- Inicio del documento -->
<html lang="es">

<!-- Imagen informativa -->
<img src="mapa-tienda.png"
     alt="Mapa de acceso a la tienda, entrada por la calle Mayor">

<!-- Cambio de idioma puntual -->
<p>El término <span lang="en">web design</span> es inglés.</p>
Resumen del alt: informativo → descripción; decorativo → alt=""; dentro de un enlace → describe el destino del enlace.

Orden de foco: tabindex

La tecla Tab navega por elementos interactivos en el orden del documento. tabindex="0" hace enfocable un elemento que no lo era y tabindex="-1" permite enfocarlo por código pero no por Tab.

<a href="#contenido" class="skip-link">Saltar al contenido</a>

<div tabindex="0" class="card-demo">Tarjeta enfocable</div>
Anti-patrón: evitar tabindex con valores positivos (1, 2, 3…). Sufren de mantenimiento, rompen el orden natural del documento y provocan una experiencia caótica de teclado.

Contraste y tamaño de texto

El texto debe mantener un mínimo de contraste respecto a su fondo (WCAG AA: 4.5:1 para texto normal). Además, evita que el tamaño de fuente bloqueo el zoom del usuario: nunca pongas font-size fija cuando se pueda usar rem.

Lectores de pantalla y sr-only

Los lectores de pantalla anuncian títulos, enlaces y elementos interactivos en orden. La clase .visually-hidden de Bootstrap (equivalente a .sr-only) oculta texto visualmente, pero lo deja disponible para el lector de pantalla.

<a href="ruta.pdf">Descargar informe
  <span class="visually-hidden">(PDF, 2 MB)</span>
</a>

<button class="btn btn-gradient">
  <i class="bi bi-search" aria-hidden="true"></i>
  <span class="visually-hidden">Buscar</span>
</button>
Practica de verdad: instala una extensión de "texto a voz" y navega tu propia web solo con teclado. Es la prueba más rápida de accesibilidad.

Open Graph: tu web en redes

Open Graph (protocolo de Facebook/Meta) define cómo se ve tu enlace al compartirlo en WhatsApp, Twitter/X o LinkedIn: título, descripción e imagen de previsualización.

<meta property="og:title" content="Frontend Pro">
<meta property="og:description"
      content="Aprende HTML, CSS y JavaScript desde cero">
<meta property="og:image" content="https://…/portada.png">
<meta property="og:type" content="website">
EtiquetaContenido recomendado
og:title60-90 caracteres, atractivo
og:descriptionResumen que invite al clic
og:imageURL absoluta, 1200×630 px aprox.
og:typewebsite para páginas normales

Repaso rápido

  • ARIA complementa, nunca sustituye, a las etiquetas HTML nativas.
  • Usa lang, alt descriptivo y .visually-hidden para información extra.
  • Mantén el orden natural del foco; evita tabindex positivo.
  • Contraste mínimo 4.5:1 y tamaño con unidades relativas (rem).
  • Open Graph prepara una previsualización profesional para tus enlaces compartidos.
