Tablas

Presenta datos comparativos con tablas semánticas, accesibles y que no se rompan en el móvil.

Fundamentos de la lección

Las tablas organizan información tabular: precios, horarios, comparativas, resultados. Un buen uso de <thead>, <tbody>, <tfoot> y scope hace que esa información sea legible para lectores de pantalla y entendible para buscadores.

thead / tbody / tfoot th con scope colspan / rowspan

Estructura base: table, tr, th, td

Una tabla se compone de filas (<tr>) con celdas: <th> para encabezados y <td> para datos.

<table>
  <tr>
    <th scope="col">Nombre</th>
    <th scope="col">Edad</th>
  </tr>
  <tr>
    <td>Mario</td>
    <td>32</td>
  </tr>
</table>
Tip: el atributo scope en los <th> indica si encabezan columnas (col) o filas (row). Es invisible en pantalla pero crucial para lectores de pantalla.

thead, tbody y tfoot

Dividir la tabla en cabecera, cuerpo y pie le da estructura al navegador: el tfoot puede mostrarse aunque la tabla sea muy larga.

<table>
  <caption>Ventas 2025</caption>
  <thead>
    <tr>
      <th scope="col">Trimestre</th>
      <th scope="col">Importe</th>
    </tr>
  </thead>
  <tbody>
    <tr><td>Q1</td><td>12.400 €</td></tr>
    <tr><td>Q2</td><td>15.200 €</td></tr>
  </tbody>
  <tfoot>
    <tr><th scope="row">Total</th>
        <td>27.600 €</td></tr>
  </tfoot>
</table>

<thead>Filas de encabezadoSe repite al imprimir en varias páginas
<tbody>Los datosPuede haber varios bloques lógicos

Combinar celdas: colspan y rowspan

colspan hace que una celda ocupe varias columnas; rowspan, varias filas. Perfecto para celdas de total y paneles de opciones.

<table>
  <tr>
    <th scope="col" colspan="2">Plan Pro</th>
  </tr>
  <tr>
    <th scope="row" rowspan="2">Incluye</th>
    <td>Dominio propio</td>
  </tr>
  <tr>
    <td>Certificado SSL</td>
  </tr>
</table>
Cuidado: con colspan/rowspan es fácil desequilibrar el número de celdas por fila. Verifica siempre que cada fila "sume" el mismo total de columnas.

Tablas responsivas: scroll horizontal

En pantallas pequeñas una tabla ancha puede desbordar el layout. La solución estándar de Bootstrap es envolverla en .table-responsive, que activa el scroll horizontal sin romper el diseño.

<div class="table-responsive">
  <table class="table">…</table>
</div>

Repaso rápido

  • Estructura semántica: <table> con thead, tbody, tfoot y caption.
  • <th scope="col"> / scope="row" declaran encabezados accesibles.
  • colspan unifica columnas; rowspan unifica filas.
  • Envuelve las tablas anchas en .table-responsive para scroll horizontal en móvil.
  • No uses tablas para maquetar el layout: usa CSS Grid o Flexbox.
