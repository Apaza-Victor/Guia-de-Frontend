Listas y Enlaces

Domina los tres tipos de listas y convierte tu página en una red navegable con enlaces internos, llamadas, correos y descargas.

Fundamentos de la lección

Las listas organizan pasos, menús y definiciones; los enlaces <a> son el corazón de la web: unen páginas, permiten navegar dentro de un mismo documento y abren correos, llamadas o descargas. Aquí verás cuándo usar cada lista y cómo apuntar un enlace a cualquier destino.

ul / ol / dl Anclas #id mailto / tel / download

Listas: ul, ol y dl

Cada tipo tiene un propósito claro: <ul> para conjuntos sin orden, <ol> para secuencias y <dl> para términos con su definición.

<ul>
  <li>Leche</li>
  <li>Pan</li>
</ul>

<ol>
  <li>Instala el editor</li>
  <li>Crea tu primer archivo</li>
</ol>

<dl>
  <dt>HTML</dt>
  <dd>Lenguaje de marcado de la web</dd>
</dl>
ElementoCuándo usarloAparienciaHijo directo
<ul>Varios elementos sin ordenVíñetas<li>
<ol>Pasos o ranking ordenado1., 2., 3.<li>
<dl>Término + definiciónLista de definición<dt> y <dd>

Anidamiento y atributos de número

Las listas pueden anidarse para crear subniveles, y <ol> acepta type, start y reversed.

<ul>
  <li>Frontend
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
</ul>

<ol type="a" start="3">
  <li>c. Tercer punto</li>
</ol>
AtributoValoresEfecto
type1, a, A, i, ICambia numeración: decimal, letras o romanas
startNúmero enteroDesde qué valor empieza el conteo
reversedBooleanoCuenta hacia atrás
Tip: si una lista solo sirve para "pintar puntos", reconsidera su uso. La lista debe aportar significado real al contenido.

El enlace básico y las anclas internas

La etiqueta <a> crea enlaces con href. Un href que empieza por # apunta a un elemento con ese id dentro de la página.

<a href="../index.html">Volver al tema HTML</a>

<a href="#seccion-2">Ir a la sección 2</a>
<h2 id="seccion-2">Sección 2</h2>
Buen hábito: usa siempre texto descriptivo en el enlace ("Ver precios de los planes") en lugar de "clic aquí". Ayuda al SEO y a los lectores de pantalla.

mailto, tel, download y target

Los protocolos mailto: y tel: abren el cliente de correo o el marcador del móvil. Con download el navegador baja el archivo en lugar de abrirlo, y target="_blank" abre en una pestaña nueva.

<a href="mailto:hola@misitio.com">Escríbenos</a>

<a href="tel:+34910000000">Llamar ahora</a>

<a href="cv-final.pdf" download>Descargar CV</a>

<a href="https://developer.mozilla.org"
   target="_blank" rel="noopener">MDN</a>
Seguridad: cuando uses target="_blank", añade siempre rel="noopener" para que la pestaña nueva no acceda a la página original.

Repaso rápido

  • <ul> sin orden, <ol> ordenada (con type/start), <dl> para definiciones.
  • Anida listas escribiendo un <ul>/<ol> dentro de un <li>.
  • Las anclas usan href="#id" y el destino debe tener ese id.
  • mailto: y tel: abren correo/teléfono; download obliga a descargar el archivo.
  • Con target="_blank" añade rel="noopener".
