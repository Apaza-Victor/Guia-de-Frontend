Resolver problemas y depurar

Piensa como programador: divide, aísla, depura con console.log y cierra el módulo con un reto.

La mentalidad del programador

Programar es resolver problemas. El método de 4 pasos que usan los profesionales:

  1. Entender el problema. Escribe el objetivo en una frase.
  2. Dividir en partes pequeñas (entradas → proceso → salida).
  3. Resolver cada parte con lo que ya sabes (variables, condicionales, bucles, funciones).
  4. Probar y refinar. Ejecuta, observa, corrige.
Ejemplo: ¿es par o impar?
  1. Objetivo: decir si un número es par o impar.
  2. Entrada: n. Proceso: n % 2 === 0. Salida: mensaje.
  3. Escribo la función con if/else.
  4. Pruebo con 4 (par), 7 (impar) y 0 (par).

Depurar con console.log

El 90% de las veces console.log basta para encontrar el error. Imprime los valores clave en cada paso:

function promedio(lista) {
  console.log("Entrada:", lista);
  let suma = 0;
  for (const n of lista) suma += n;
  console.log("Suma:", suma);
  const resultado = suma / lista.length;
  console.log("Promedio:", resultado);
  return resultado;
}
Método: 1) reproduce el error, 2) pon console.log justo antes de que falle, 3) compara con lo esperado, 4) corrige una sola cosa a la vez.
