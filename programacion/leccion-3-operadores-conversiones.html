Operadores y conversiones

Aritmética, parseInt y compañía: aprende a transformar números y texto para que tus cálculos sean correctos.

Operadores aritméticos

Son los que hacen matemática sobre números:

const a = 10;
const b = 3;

a + b   // 13   suma
a - b   // 7    resta
a * b   // 30   multiplicación
a / b   // 3.33 división
a % b   // 1    módulo (resto)
a ** b  // 1000 potencia
Tip: El módulo % es ideal para saber si un número es par (n % 2 === 0) o hacer lógica circular.

parseInt y la conversión de texto a número

El error clásico de principiante: "2" + "2" da "22", porque ambos son texto. parseInt convierte un string a un entero:

parseInt("25");        // 25
parseInt("25px");      // 25 (ignora lo que no es número)
parseInt("3.99");      // 3  (trunca a entero)
parseInt("hola");      // NaN (no es un número)

La conversión antes de sumar lo arregla todo:

const num1 = parseInt("10");    // 10
const num2 = parseInt("5");     // 5
const total = num1 + num2;        // 15 ✓ (y no "105")

NaN: NaN significa "Not a Number". Cualquier operación rota con él se propaga; siempre valida antes de calcular.

Comparación y lógica

Sirven para tomar decisiones (las verás en la lección 4), pero conviene conocerlas ya:

6 > 3           // true
6 === "6"        // false (tipos distintos e igualdad estricta)
6 == "6"         // true  (igualdad suelta — evítala)
!(true)             // false (negación)
Regla: usa siempre === y !== (comparación estricta). El doble == genera bugs silenciosos.

Repaso rápido

  • + suma números pero concatena texto.
  • parseInt/Number convierten texto a número antes de calcular.
  • parseFloat conserva decimales; === compara sin sorpresas.
