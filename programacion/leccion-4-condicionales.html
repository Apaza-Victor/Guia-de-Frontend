Condicionales

Haz que tu programa decida: if/else, else if, switch y el operador ternario.

Decisiones con if / else

Las computadoras estarían vacías sin condiciones. El bloque if ejecuta código solo si la condición da true:

const edad = 17;

if (edad >= 18) {
  console.log("Eres mayor de edad");
} else {
  console.log("Aún eres menor");
}

Con varias condiciones usa else if:

if (nota >= 90) {
  "Excelente";
} else if (nota >= 70) {
  "Buen trabajo";
} else {
  "A seguir practicando";
}

switch: muchas opciones iguales

Cuando comparas un mismo valor contra muchas opciones, switch es más limpio:

const dia = "lun";

switch (dia) {
  case "lun":
    console.log("A trabajar");
    break;
  case "sab":
  case "dom":
    console.log("Fin de semana");
    break;
  default:
    console.log("Día normal");
}
Ojo: Sin break los casos "caen" hacia abajo. Úsalo siempre o agrupa casos a propósito (como "sab"/"dom").

El operador ternario

Para decisiones simples en una línea, el ternario es tu atajo:

condición ? "valor si true" : "valor si false";

const mensaje = edad >= 18 ? "Adulto" : "Menor";
Consejo: Si la lógica supera una línea o complica la lectura, vuelve al if/else. El código legible gana siempre.

Valores truthy y falsy

JavaScript convierte cualquier valor a verdadero o falso en una condición. Te conviene memorizar los 6 falsos:

Repaso rápido

  • if/else y else if ramifican el flujo.
  • switch es ideal con muchas opciones del mismo valor.
  • El ternario simplifica si/else de una línea; recuerda los 6 falsy.
