Roadmap

Ruta de aprendizaje

Cuatro fases progresivas: de novato absoluto a frontend profesional listo para el mercado laboral.

Fase 1 — Fundamentos Semanas 1-4

HTML semántico, CSS básico e intermedio con Flexbox y Grid. Al final sabrás maquetar cualquier layout responsive.

Fase 2 — JavaScript Semanas 5-10

JS de cero a avanzado: variables, DOM, eventos, fetch, promesas y ES6+. La base de todo framework moderno.

Fase 3 — Producción Semanas 11-14

Bootstrap 5 a nivel experto, Git/GitHub, npm, Sass y animaciones profesionales (AOS, GSAP).

Fase 4 — Frameworks Semanas 15-20

React y Vue con fundamentos sólidos, listo para tu portafolio y el mercado laboral.
