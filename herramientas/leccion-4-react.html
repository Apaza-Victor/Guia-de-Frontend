React: introducción práctica

Construye interfaces declarativas con componentes, JSX, props y estado, y ejecuta React directo en tu navegador con Babel standalone.

¿Qué es React y qué es JSX?

React es una librería de JavaScript para construir interfaces de usuario. Su ideología: describes cómo debe verse la UI para cada estado y React se encarga de actualizar el DOM de forma eficiente cuando ese estado cambia. Todo gira alrededor de componentes.

JSX es una extensión de sintaxis que mezcla HTML y JavaScript (técnicamente parecido a "HTML dentro de JS"). Lo que escribes con JSX se transforma en llamadas de React antes de ejecutarse. 

// JSX: markup dentro de JavaScript
const titulo = <h1>Hola, Frontend Pro</h1>;

const conDatos = <p>{autor}</p>;  // {} interpola expresiones
Tip: En JSX, las llaves { } abren el "modo JavaScript": puedes interpolar variables, llamar funciones o ejecutar condicionales.
Ojo: JSX no es HTML. No existe el atributo class (usa className) ni for (usa htmlFor), y los atributos se escriben en camelCase (onClick, tabIndex).

Componentes funcionales

Un componente funcional es una función que devuelve JSX. Su nombre empieza en mayúscula (así React lo distingue de las etiquetas HTML) y una vez definido se usa como una etiqueta más. 

function Saludo() {
  return (
    <div className="saludo">
      <h2>Hola, visitante!</h2>
      <p>Bienvenido a tu primera app React</p>
    </div>
  );
}

// Usarlo como etiqueta propia
ReactDOM.createRoot(document.getElementById('root'))
  .render(<Saludo />);
Tip: Las funciones flecha también sirven: const Tarjeta = () => <article />;. Lo importante es la primera letra mayúscula.

Props: los datos de entrada

Las props son los datos que un padre le pasa a un componente hijo. Llegan como un objeto y el componente los trata como de solo lectura. 

function Tarjeta({ titulo, autor }) {        // destructuring de props
  return (
    <article className="card-learning">
      <h3>{titulo}</h3>
      <small>por {autor}</small>
    </article>
  );
}

function Blog() {
  return <Tarjeta titulo="Sass" autor="Maria" />;
}
ConceptoDescripción
PropsEntrada de datos; viajan de padre a hijo
InmutabilidadUn componente nunca debe modificar sus props
Re-renderSi cambian las props, el componente se vuelve a renderizar

Estado con useState

El estado es la memoria del componente: datos que pueden cambiar y que, al cambiar, provocan un re-render automático de la UI. El hook useState devuelve una pareja [valor, actualizador]. 

import { useState } from 'react';

function Contador() {
  const [cuenta, setCuenta] = useState(0);

  return (
    <div>
      <button onClick={() => setCuenta(cuenta + 1)}>+1</button>
      <strong>{cuenta}</strong>
    </div>
  );
}
Regla de oro: Nunca mutiles el estado con asignaciones directas. Usa siempre el actualizador (setCuenta) para que React cree el nuevo render.

Eventos y handlers

React normaliza los eventos del navegador con prefijo on* en camelCase, y reciben el evento como argumento. Puedes pasar funciones definidas o flechas inline. 

function Formulario() {
  const [texto, setTexto] = useState('');

  function alEnviar(e) {
    e.preventDefault();                       // evitar recarga de la página
    alert('Enviaste: ' + texto);
  }

  return (
    <form onSubmit={alEnviar}>
      <input value={texto}
             onChange={(e) => setTexto(e.target.value)} />
      <button type="submit">Enviar</button>
    </form>
  );
}
Tip: El patrón de "input controlado" (value + onChange) es la forma estándar de leer formularios en React.

Demo: React en vivo con Babel

Para aprender trabajamos con Babel standalone: Babel compila JSX directamente en el navegador. En producción usaríamos un bundler (Vite), pero esta demo es 100% funcional ahora mismo: 

<script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
<div id="root"></div>
<script type="text/babel">
  // ... tu componente React con JSX ...
</script>

Repaso rápido

  • React construye UIs desde componentes reutilizables que devuelven JSX.
  • Los componentes funcionales reciben props (solo lectura) y devuelven markup.
  • useState da estado local: [valor, setValor] y el re-render es automático.
  • Los eventos van en camelCase (onClick, onSubmit, onChange).
  • Para aprender basta Babel standalone; para producción usa Vite.
