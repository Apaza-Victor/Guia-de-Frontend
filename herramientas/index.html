Herramientas y Frameworks

El cinturón de herramientas del frontend real: control de versiones, automatización, preprocesadores CSS y los frameworks modernos que aceleran el desarrollo.

¿Qué aprenderás?

Qué aprenderás

Control de versiones con Git y GitHub, automatización con npm, preprocesado de CSS con Sass e introducciones prácticas a React y Vue 3 con demos en vivo.

Nivel

Progresivo: Git y npm parten desde cero, y Sass, React y Vue asumen HTML, CSS y JavaScript básico. Ideal para dar el salto a proyectos reales.

Duración estimada

5 lecciones · ≈ 3-4 horas con demos interactivas y componentes reales renderizados en vivo. Cada lección es autónoma y navegable.
