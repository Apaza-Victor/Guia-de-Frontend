Vue 3: introducción práctica

Reactividad declarativa, directivas v-bind/v-if/v-for/v-model, eventos y composición con setup(), todo en vivo con el CDN global de Vue.

¿Qué es Vue 3?

Vue 3 es un framework progresivo de JavaScript: puedes empezar con un solo archivo que carga el CDN global y escalar hasta una app completa con componentes. Su corazón es la reactividad: declaras qué datos dibuja tu plantilla y Vue actualiza el DOM automáticamente cuando cambian.

La forma más rápida de probarlo es el build global, que expone Vue en el navegador:

<script src="https://unpkg.com/vue@3/dist/vue.global.prod.js"></script>

<div id="app">{{ mensaje }}</div>

<script>
Vue.createApp({
  data() {
    return { mensaje: '¡Hola Vue 3!' };
  }
}).mount('#app');
</script>
Tip: createApp + mount es el punto de entrada: se crea la app y se "monta" sobre un elemento del DOM.

Reactividad: la UI habla sola

La reactividad es la magia de Vue: cuando el dato cambia, la vista se vuelve a renderizar sola. Con el Composition API usamos ref() para crear variables reactivas y accedemos a su valor con .value. 

const app = Vue.createApp({
  setup() {
    const contador = Vue.ref(0);
    const sumar = () => { contador.value++; };
    return { contador, sumar };
  }
});

// En la plantilla: {{ contador }} y @click="sumar"
Detalle: Dentro de setup() se lee/escribe ref con .value; en la plantilla, Vue lo desenvuelve automáticamente y basta {{ contador }}.

Directivas: v-bind, v-if y v-for

Las directivas son atributos especiales con prefijo v- que agregan lógica a la plantilla.

// v-bind enlaza atributos (atajo: ":")
<img :src="usuario.avatar" :alt="usuario.nombre">

// v-if / v-else eligen qué renderizar
<p v-if="sesionActiva">Bienvenido de nuevo</p>
<p v-else>Por favor, inicia sesión</p>

// v-for repite elementos; :key es obligatorio
<li v-for="tarea in tareas" :key="tarea.id">{{ tarea.nombre }}</li>
DirectivaAtajoPara qué sirve
v-bind:Enlaza un atributo con un dato (reactivo)
v-if / v-else—Renderizado condicional
v-for—Itera listas generando elementos
v-model—Doble vía: input ⇄ dato
@click (v-on)@Escucha eventos del DOM
Tip: Memoriza los atajos: : para bind y @ para eventos. Escribirás el 90% de las plantillas así.

v-model y eventos

v-model implementa el binding de doble vía: lo que escribes en el input actualiza el dato, y si el dato cambia por otro lado, el input también se actualiza. Los métodos se declaran como funciones de la app. 

<input v-model="nombre" placeholder="Tu nombre">
<p>Hola, {{ nombre }}!</p>

<button @click="enviar">Enviar</button>

<script>
Vue.createApp({
  data() { return { nombre: '' }; },
  methods: {
    enviar() { alert('Hola, ' + this.nombre); }
  }
}).mount('#app');
</script>
Cuidado: En methods el contexto es el de la instancia: usa this.nombre. En setup() esa sintaxis desaparece y trabajas con variables directas.

Composable setup()

El Composition API (la función setup()) agrupa la lógica por feature en lugar de por opciones (data, methods, separados). Todo lo que retornes queda disponible en la plantilla. 

const app = Vue.createApp({
  setup() {
    const tareas = Vue.ref([
      { id: 1, nombre: 'Aprender v-for' },
      { id: 2, nombre: 'Practicar useState' }
    ]);

    const agregar = () => {
      tareas.value.push({ id: Date.now(), nombre: 'Nueva tarea' });
    };

    function animar() {
      console.log('setup() permite lógica reutilizable');
    }

    return { tareas, agregar, animar };
  }
});

// Plantilla: <li v-for="t in tareas" :key="t.id">{{ t.nombre }}</li>
Tip: En componentes reales se extrae lógica a funciones composables (como useContador()) que reutilizas en varios componentes, similar a los hooks de React.

Repaso rápido

  • Vue 3 es un framework progresivo: del CDN global a apps de componentes.
  • La reactividad actualiza el DOM automáticamente con ref() y {{ }}.
  • Las directivas añaden lógica al HTML: :bind, v-if, v-for, v-model.
  • Los eventos se escuchan con @click y la lógica va en methods o en la función setup().
  • createApp(...).mount('#app') arranca cualquier aplicación.
