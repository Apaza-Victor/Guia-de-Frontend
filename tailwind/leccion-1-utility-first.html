Introducción y utility-first

Entiende la filosofía que cambió la forma de escribir CSS y ponla en marcha con el CDN de Tailwind.

¿Qué es Tailwind CSS?

Tailwind es un framework utility-first: en vez de escribir reglas CSS aparte, compones el diseño directamente en el HTML combinando clases atómicas.

<!-- CSS tradicional -->
<style>
  .boton { background: #0ea5e9; padding: 12px 24px; border-radius: 8px; }
</style>
<button class="boton">Ver más</button>
<!-- Con Tailwind: misma apariencia sin CSS propio -->
<button class="bg-sky-500 px-6 py-3 rounded-lg">Ver más</button>
Filosofía: clases pequeñas y reutilizables. No hay nombres de clases que inventar: solo utilidades predefinidas y consistentes.

Instalación con CDN

Para practicar en 10 segundos, usa el CDN oficial como esta misma guía usa Bootstrap:

<head>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
Proyecto real en producción

Para sitios serios se instala con npm y su CLI genera solo las clases usadas al compilar (npx tailwindcss init). El CDN es perfecto para aprender y prototipar; la CLI es lo recomendado para desplegar.

Primeras utilidades

Cada utilidad traduce directamente a una propiedad. Lee la clase y sabrás qué hace:

<div class="bg-indigo-500 text-white p-6 rounded-2xl">
  ¡Esto ya se ve bonito!
</div>

Repaso rápido

  • Tailwind compone estilos con clases atómicas (utility-first).
  • El CDN permite empezar al instante; la CLI es para producción.
  • Cada utilidad = una propiedad aprendida al leer el nombre.
