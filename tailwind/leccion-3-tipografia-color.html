Tipografía, color y fondos

Dale personalidad a tus interfaces con escalas de color, familias tipográficas, redondeos y sombras.

Las escalas de color

Todos los colores siguen el patrón color-intensidad, con intensidades de 50 a 950:

indigo-500
sky-500
emerald-500
red-500
amber-500
violet-500
<p class="text-sky-600">Texto azul cielo</p>
<div class="bg-emerald-100 text-emerald-800">Alerta de éxito</div>

Tipografía

Tailwind trae font-sans, font-serif y font-mono, además de tamaños en escala tipográfica:

<h1 class="text-4xl font-extrabold">Gran titular</h1>
<p class="text-base text-slate-600 leading-relaxed">
  Párrafo legible con interlineado relajado.
</p>
<code class="font-mono text-sm">function(){}</code>
ClaseEquivale a
text-xs / sm / base / lgtamaños de texto
text-2xl / 4xl / 6xltitulares grandes
font-bold / extraboldpesos de fuente
leading-relaxedinterlineado

Redondeo, bordes y sombras

<div class="rounded-xl border border-slate-200 shadow-lg">...</div>
<button class="rounded-full bg-indigo-600 text-white px-6 py-3 shadow-md">Comprar</button>
ClaseUso
rounded-sm / md / lg / xlesquinas suaves
rounded-fullpíldoras y círculos
border border-slate-200bordes sutiles
shadow-sm / md / lg / 2xlprofundidad discreta o marcada

Cambia el color del botón desde JavaScript para verlo reaccionar:

Tip: En producción estas clases se escriben en el HTML (bg-indigo-600, hover:bg-indigo-700). La demo solo cambia el color en vivo para que sientas la paleta.

Repaso rápido

  • Colores: color-intensidad (de 50 a 950).
  • Tipografía: text-4xl, font-bold, leading-*.
  • Acabados: rounded-*, border, shadow-*.
