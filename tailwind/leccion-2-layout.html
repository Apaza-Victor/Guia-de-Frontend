Layout: flex, grid y espaciado

Coloca elementos donde quieras con utilidades de flex, grid, paddings y márgenes.

Flex en una línea

flex activa flexbox; items-center y justify-between alinean vertical y horizontalmente:

<div class="flex items-center justify-between gap-4">
  <h3 class="text-xl font-bold">Mi tienda</h3>
  <a class="bg-sky-500 px-4 py-2 rounded-lg">Comprar</a>
</div>
ClaseEquivale a
flexdisplay: flex
flex-colflex-direction: column
items-centeralign-items: center
justify-betweenjustify-content: space-between
gap-4gap: 1rem

Grid de columnas

Con grid + grid-cols-N creas columnas equilibradas al instante:

<div class="grid grid-cols-3 gap-4">
  <div class="bg-slate-200 p-4 rounded">1</div>
  <div class="bg-slate-200 p-4 rounded">2</div>
  <div class="bg-slate-200 p-4 rounded">3</div>
</div>

Para distribuciones asimétricas, col-span-N hace que un elemento ocupe más:

<div class="grid grid-cols-3 gap-4">
  <div class="col-span-2 bg-indigo-400 p-4 rounded">Contenido principal</div>
  <div class="bg-indigo-200 p-4 rounded">Barra lateral</div>
</div>

Espaciado: la escala

Tailwind usa una escala fija: cada unidad equivale a 0.25rem (4px). p-4 = 1rem, m-2 = 0.5rem, y puedes apuntar a un lado:

ClaseValorHacia
px-61.5remizquierda y derecha
py-41remarriba y abajo
pt-2, mb-30.5rem / 0.75remlados individuales
mx-autoautocentra horizontalmente
Tip: Memoriza los básicos: p-4, px-6, py-3, gap-4, mx-auto. Cubren el 90% de los casos.

Repaso rápido

  • flex + items-center + justify-between = layout horizontal perfecto.
  • grid grid-cols-3 crea columnas; col-span-2 da asimetría.
  • La escala de espaciado: p-4 = 1rem, y x/y apuntan a ejes.
