Interfaces y clases

Define contratos con interfaces y construye objetos con clases, herencia y modificadores de acceso.

interface Persona

Una interfaz describe la forma de un objeto: qué propiedades tiene y de qué tipo. No genera código; solo se usa en compilación.

interface Persona {
  nombre: string;
  edad: number;
}

let ana: Persona = {
  nombre: "Ana",
  edad: 28,
};

// ana.edad = "joven"  Error: edad debe ser number
Nota: las interfaces son la herramienta estrella para modelar respuestas de APIs, configuraciones y props de componentes. Un objeto que coincida con la interfaz es aceptado al instante (duck typing).

Propiedades opcionales

Igual que en las funciones, el ? marca propiedades que pueden faltar:

interface Producto {
  nombre: string;
  precio: number;
  descuento?: number;  // puede o no existir
}

const p1: Producto = { nombre: "Teclado", precio: 89.5 };
const p2: Producto = { nombre: "Mouse", precio: 25, descuento: 10 };
Cuidado: al leer una propiedad opcional el valor puede ser undefined. Verifícala antes de usarla o usa el operador ? de acceso: producto.descuento?.toFixed(2).

Interfaces que extienden

Con extends una interfaz hereda todas las propiedades de otra y añade las suyas. Así evitas repetir campos comunes:

interface Persona {
  nombre: string;
  edad: number;
}

interface Empleado extends Persona {
  cargo: string;
  salario: number;
}

const luis: Empleado = {
  nombre: "Luis",
  edad: 32,
  cargo: "Desarrollador",
  salario: 2500,
};

Puedes encadenar varios niveles (A extends B, B extends C) e incluso extender más de una interfaz separando con comas.

Clases con constructor

Una clase agrupa datos (propiedades) y comportamiento (métodos). El constructor se ejecuta al crear instancias con new:

class Cuenta {
  titular: string;
  saldo: number;

  constructor(titular: string, saldo: number) {
    this.titular = titular;
    this.saldo = saldo;
  }

  depositar(monto: number): void {
    this.saldo += monto;
  }
}

const cuenta = new Cuenta("Ana", 500);
cuenta.depositar(100);
console.log(cuenta.saldo);  // 600

Modificadores de acceso

Controla quién puede leer o escribir cada propiedad:

ModificadorEfecto
publicAccesible desde cualquier lugar. Es el valor por defecto.
privateSolo accesible dentro de la propia clase.
readonlySe asigna una vez y no se puede reescribir.
 
class Cuenta {
  readonly numero: string;    // no cambia tras crearse
  private saldo: number;     // solo la clase lo modifica

  constructor(numero: string, saldo: number) {
    this.numero = numero;
    this.saldo = saldo;
  }

  verSaldo(): number {
    return this.saldo;
  }
}

// cuenta.saldo = 0         Error: saldo es private
// cuenta.numero = "x"     Error: numero es readonly
Práctica: expón lo mínimo. Sigue usando propiedades normales para datos compartidos y reserva private para el estado interno y readonly para valores de identidad.

Implementar una interfaz

Una clase puede prometer cumplir una interfaz con la palabra implements: el compilador verifica que la clase tenga todo lo prometido.

interface Describible {
  describir(): string;
}

class Auto implements Describible {
  constructor(public marca: string) {}

  describir(): string {
    return "Auto " + this.marca;
  }
}

class Moto implements Describible {
  describir(): string {
    return "Soy una moto";
  }
}
Contrato garantizado

Si una clase declarada con implements Describible olvidara el método describir(), TypeScript lo señalaría al instante. Cualquier clase que cumpla el contrato se puede usar donde se espere Describible.

Repaso rápido

  • interface Persona describe la forma de un objeto sin generar código.
  • ? hace opcional una propiedad; extends hereda campos entre interfaces.
  • Las clases usan constructor y permiten instancias con new.
  • public, private y readonly controlan el acceso; implements garantiza un contrato.
