Funciones tipadas

Dale contrato a tus funciones: parámetros, retorno, opcionales, valores por defecto y generics.

Parámetros y retorno

Cada parámetro lleva su tipo y, después de los paréntesis, declaras el tipo que devuelve la función:

function sumar(a: number, b: number): number {
  return a + b;
}

function saludar(nombre: string): string {
  return "Hola " + nombre;
}

// sumar("a", 2)  Error: el primer argumento debe ser number

Cuando una función no devuelve nada, se anota con void:

function registrarLog(mensaje: string): void {
  console.log(mensaje);
}
Nota: si no anotas el retorno, TypeScript lo infiere. Anotarlo explícito documenta la intención y evita que por error devuelvas algo distinto.

Parámetros opcionales

El signo ? marca un parámetro que no es obligatorio. Si llega, vale undefined; tu código debe contemplarlo:

function presentar(nombre: string, apellido?: string): string {
  if (apellido) {
    return nombre + " " + apellido;
  }
  return nombre;
}

presentar("Ana");            // "Ana"
presentar("Ana", "Perez");   // "Ana Perez"
Orden: los parámetros opcionales siempre van después de los obligatorios. function f(opcional?: string, obligatorio: string) provoca un error de compilación.

Valores por defecto

Asigna un valor que se usa cuando la función se llama sin ese argumento. Es más cómodo que ? porque el parámetro siempre tendrá un valor:

function calcularPrecio(precio: number, descuento: number = 0): number {
  return precio - (precio * descuento) / 100;
}

calcularPrecio(100);        // 100, sin descuento
calcularPrecio(100, 10);   // 90
Tip: usa valores por defecto cuando exista un comportamiento estándar (descuento 0, página 1, idioma "es") y reserva ? para datos realmente ausentes.

Arrow functions tipadas

Las funciones flecha se tipan igual: parámetros a la izquierda y retorno tras el =>. Son ideales para callbacks y arrays:

const duplicar = (n: number): number => n * 2;

const notas = [18, 14, 17];
const aprobadas = notas.filter((nota: number) => nota >= 15);

// En la práctica TS infiere el tipo de "nota" a partir del array
const total = notas.reduce((acc, nota) => acc + nota, 0);

También puedes tener un tipo de función reutilizable con un alias:

type Calculadora = (a: number, b: number) => number;

const restar: Calculadora = (a, b) => a - b;
const multiplicar: Calculadora = (a, b) => a * b;

Generics simples

Los generics permiten que una función trabaje con muchos tipos manteniendo la relación entre ellos. Se declaran con <T>:

function identidad<T>(valor: T): T {
  return valor;
}

const texto = identidad<string>("hola");
const num = identidad<number>(42);

// El retorno siempre coincide con el argumento:
function primera<T>(lista: T[]): T | undefined {
  return lista[0];
}
Por qué importan

primera con string[] devuelve string | undefined y con number[] devuelve number | undefined. Sin generics tendrías que repetir la función por cada tipo o perder el tipado con any.

Repaso rápido

  • Parámetros y retorno se anotan: function f(a: number): number.
  • ? hace un parámetro opcional; los valores por defecto evitan el undefined.
  • Las arrow functions se tipan como las funciones normales: (n: number) => number.
  • <T> crea funciones reutilizables que conservan el tipo entre entrada y salida.
