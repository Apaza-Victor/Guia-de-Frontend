Personalización con variables CSS

Overrides de las variables Sass y CSS, custom properties via :root, colores de marca y temas con data-bs-theme.

Fundamentos de la lección

Bootstrap 5 está construido sobre Sass y expone sus variables de dos formas: las variables Sass ($primary, $border-radius…) que se sustituyen en tiempo de compilación, y las variables CSS (--bs-primary, --bs-body-bg…) que viven en tiempo de ejecución en el navegador. Personalizar con CSS es más fácil y no requiere build; los overrides Sass son la vía definitiva de los proyectos en producción.

Variables Sass :root y --bs-* Colores de marca

Variables CSS: el override en :root

Al cargar Bootstrap por CDN puedes sobrescribir sus variables CSS en tu propio :root después del link de Bootstrap. Todos los componentes que usan var(--bs-primary) cambiarán automáticamente: 

:root {
  --bs-primary: #2563eb;
  --bs-primary-rgb: 37, 99, 235;
  --bs-body-bg: #0f172a;
  --bs-body-color: #cbd5e1;
  --bs-border-radius: .75rem;
}

Fíjate en --bs-primary-rgb: muchas utilidades (como bg-opacity-* o las sombras de los botones) usan la versión rgb en rgba(). Si cambias solo --bs-primary y no su par rgb, algunos estilos seguirán con el color antiguo.

VariableQué controlaEjemplo
--bs-primaryColor principal (botones, enlaces, focus)#2563eb
--bs-primary-rgbPar rgb del primary para transparencias37, 99, 235
--bs-body-bgFondo por defecto del documento#0f172a
--bs-body-colorColor de texto por defecto#cbd5e1
--bs-border-radiusRadio de las esquinas en .btn, .card….75rem
Tip: Inspecciona cualquier elemento con F12 y verás decenas de --bs-* en :root. Cambiar su valor en la pestaña Styles te da una vista previa instantánea sin tocar tu código.

Overrides Sass: la vía de producción

Si compilas Bootstrap con npm puedes sobrescribir las variables $ antes de importar el framework. Es el método recomendado para aplicaciones reales porque genera un CSS limpio con exactamente tus valores: 

// variables.css / main.scss
$primary: #2563eb;
$border-radius: .75rem;
$enable-shadows: true;
$font-family-sans-serif: "Poppins", system-ui, sans-serif;

@import "bootstrap/scss/functions.css";
@import "bootstrap/scss/variables.css";
@import "bootstrap/scss/bootstrap";
MétodoCuándo usarloVentaja
CSS en :rootPrototipos, temas dinámicos, CDNSin build, cambia en caliente con data-bs-theme
Sass ($vars)Proyectos con bundler en producciónEl CSS final no lleva variables muertas
Aviso: Un override Sass solo funciona si se declara antes del @import bootstrap. Si lo pones después, las reglas compiladas ya usan los valores por defecto y tu variable no tendrá efecto.

Colores de marca y temas con data-bs-theme

Para colores de marca define tus propios custom properties en :root y asígnalos a las variables Bootstrap. Así toda la interfaz (botones, cards, focus, badges) adopta tu identidad con una sola declaración: 

:root {
  --marca-indigo: #2563eb;
  --marca-rosa: #0ea5e9;

  --bs-primary: var(--marca-indigo);
  --bs-primary-rgb: 37, 99, 235;
  --bs-link-color: var(--marca-indigo);
}

El atributo data-bs-theme permite renombrar temas: cada valor (light, dark o uno propio como marca) es un conjunto de variables CSS que Bootstrap aplica al subárbol. Puedes definir tu propio tema "marca" sobrescribiendo sus variables: 

[data-bs-theme="marca"] {
  --bs-body-bg: #0b1220;
  --bs-body-color: #e2e8f0;
  --bs-primary: #22d3ee;
  --bs-primary-rgb: 34, 211, 238;
}
Temas integrados

data-bs-theme="light|dark" vienen incluidos en Bootstrap 5.3 y solo necesitan el atributo sobre el contenedor (o documentElement) para activarse.

Temas propios

Cualquier nombre custom (marca, nocturno…) funciona: sobrescribe las variables CSS del selector y úsalo igual que los integrados.

Repaso rápido

  • Bootstrap expone variables Sass ($primary) y variables CSS (--bs-primary).
  • El override CSS se declara en :root después del link de Bootstrap y cambia en caliente.
  • Actualiza siempre el par --bs-primary-rgb junto a --bs-primary para las transparencias.
  • Los overrides Sass deben ir antes del @import bootstrap.
  • data-bs-theme activa temas integrados o propios por subárbol, sin recompilar nada.
