Sección: Bootstrap 5 lecciones

Bootstrap 5: de cero a experto

El framework CSS más usado del mundo: grid, componentes, utilidades, personalización por variables CSS y una práctica completa con animaciones AOS y GSAP.

¿Qué aprenderás?

Qué aprenderás

Grid responsive de 12 columnas, componentes listos para usar (navbar, cards, modales, carousels), utilidades de espaciado y color, personalización con variables CSS y animaciones con AOS y GSAP.

Nivel

Progresivo: empieza en cero con la instalación y el grid, y termina construyendo una landing animada completa. Ideal para cualquier punto de partida.

Duración estimada

5 lecciones · ≈ 3.5 horas con demos interactivas reales y una práctica final de landing con animaciones.
