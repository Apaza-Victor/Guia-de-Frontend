Práctica: landing con AOS + GSAP

Construye una mini landing real: navbar, hero, cards y CTA con componentes Bootstrap, animaciones AOS al scroll y micro-animaciones GSAP.

Fundamentos de la lección

Vamos a ensamblar todo lo aprendido en una mini landing con tres bloques de construcción: componentes Bootstrap para la estructura (navbar, hero, cards, CTA), AOS para las animaciones que se disparan al hacer scroll y GSAP para las micro-animaciones de entrada y de interacción. La demo de abajo es esa landing: revísala con F12 y copia los fragmentos que necesites.

Componentes AOS scroll GSAP micro-animaciones

Estructura: navbar + hero

Toda landing empieza por una navbar fija con anclas a las secciones y un hero que captura la atención en el primer segundo. Con Bootstrap esto es solo markup: 

<nav class="navbar navbar-expand-lg fixed-top navbar-dark bg-dark">
  <div class="container">
    <a class="navbar-brand fw-bold" href="#">
      <i class="bi bi-rocket-takeoff me-2"></i>Nova</a>
    <button class="navbar-toggler" data-bs-toggle="collapse"
            data-bs-target="#navDemo">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="navDemo">
      <ul class="navbar-nav ms-auto mb-2 mb-lg-0 gap-lg-2">
        <li class="nav-item"><a class="nav-link active" href="#inicio">Inicio</a></li>
        <li class="nav-item"><a class="nav-link" href="#ventajas">Ventajas</a></li>
        <li class="nav-item"><a class="nav-link" href="#cta">Empezar</a></li>
      </ul>
    </div>
  </div>
</nav>

<header class="px-4 py-5 text-center">
  <h1 class="display-5 fw-bold">Construye tu span class="text-gradient":con estilo/span>
  <p class="lead mx-auto">Rápido, responsivo y con personalidad.</p>
  <div class="d-flex gap-3 justify-content-center flex-wrap">
    <a class="btn btn-gradient" href="#cta">Empezar gratis</a>
    <a class="btn btn-outline-light" href="#ventajas">Ver ventajas</a>
  </div>
</header>
Tip: Usa scroll-margin-top en las secciones objetivo (#ventajas, #cta) para que la navbar fija no tape el título al saltar con el ancla: section { scroll-margin-top: 4.5rem; }.

Cards con animaciones AOS

Las secciones de contenido suelen ser una row de card. Añade el atributo data-aos a cada card y AOS las animará conforme entran al viewport. Puedes combinar data-aos, data-aos-delay y data-aos-duration para escalonar la entrada: 

<div class="row g-4">
  <div class="col-md-4" data-aos="fade-up">
    <div class="card h-100">
      <div class="card-body text-center">
        <i class="bi bi-lightning-charge-fill fs-3"></i>
        <h5 class="mt-3">Rapidez</h5>
        <p class="card-text">Carga en milisegundos.</p>
      </div>
    </div>
  </div>
  <!-- repite con data-aos-delay="100" y "200" -->
</div>

Recuerda inicializar AOS una sola vez en tu script (esta guía ya lo hace en assets/js/main.js): 

AOS.init({
  duration: 800,
  easing: "ease-out-cubic",
  once: true,
  offset: 80
});
AtributoEfectoValores típicos
data-aosAnimación al entrar al viewportfade-up, zoom-in, flip-left
data-aos-delayEspera en ms antes de animar100, 200
data-aos-durationDuración de la transición600–1200
data-aos-onceAnimar solo la primera veztrue / false

CTA y micro-animaciones GSAP

El CTA (call to action) es la franja que empuja al clic. Los badges, iconos y botones se benefician de micro-animaciones GSAP: entradas con gsap.from, rebotes con gsap.fromTo y reacciones al hover con gsap.to. 

// Entrada escalonada del hero
gsap.from('#heroTitulo', { y: 30, opacity: 0, duration: 0.8 });
gsap.from('.hero-cta',    { y: 16, opacity: 0, stagger: 0.15, delay: 0.3 });

// Micro-interacción hover sobre botones
document.querySelectorAll('.btn-cta').forEach(btn => {
  btn.addEventListener('mouseenter', () =>
    gsap.to(btn, { scale: 1.06, duration: 0.25 }));
  btn.addEventListener('mouseleave', () =>
    gsap.to(btn, { scale: 1, duration: 0.25 }));
});
Aviso: GSAP anima propiedades, no estados. No dejes opacidad 0 permanente: si tu selector no existe al cargar, gsap.from falla silenciosamente. Usa siempre selectores que existan en el documento.

Repaso rápido

  • La estructura base de una landing son navbar + hero + cards + CTA, todos componentes Bootstrap.
  • Añade data-aos (+ delay/duration) para animar las secciones al hacer scroll.
  • GSAP da micro-animaciones: gsap.from para entradas escalonadas y gsap.to para hover y rebotes.
  • Combina lo mejor de cada herramienta: Bootstrap de estructura, AOS de scroll, GSAP de interacción.
