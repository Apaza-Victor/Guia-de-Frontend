Componentes: navbar, cards y más

El catálogo de piezas listas que te ahorra horas: desde la barra de navegación hasta el carousel.

La navbar y el collapse

La navbar es el componente de navegación por excelencia. Combina el flexbox de Bootstrap con el plugin collapse: en pantallas pequeñas el menú se pliega tras un botón de hamburguesa y se despliega al pulsarlo.

Los puntos clave del patrón hamburguesa:

  • navbar-expand-lg — el menú se muestra horizontal desde lg y colapsa por debajo.
  • navbar-toggler — el botón hamburguesa que lanza el despliegue.
  • data-bs-toggle="collapse" + data-bs-target="#id" — conectan el botón con el bloque que se pliega.
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <div class="container">
    <a class="navbar-brand" href="#">MiApp</a>
    <button class="navbar-toggler"
            data-bs-toggle="collapse"
            data-bs-target="#menu">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="menu">
      <ul class="navbar-nav ms-auto">
        <li class="nav-item"><a class="nav-link" href="#">Inicio</a></li>
      </ul>
    </div>
  </div>
</nav>
Tip: El id del colapsable debe coincidir exactamente con el data-bs-target. Si no colapsa, revisa que ambos estén escritos igual.

Cards, buttons, badges y alerts

Las cards son contenedores flexibles con header, body y footer. Los buttons aportan estilo mediante variables de color, los badges marcan cantidades o estados y las alerts comunican mensajes temporales al usuario. 

<div class="card">
  <div class="card-body">
    <h5 class="card-title">Card básica</h5>
    <p class="card-text">Texto de ejemplo</p>
    <button class="btn btn-primary">
      Guardar <span class="badge text-bg-light">3</span>
    </button>
  </div>
</div>

<div class="alert alert-warning">Cuidado con esto</div>

Accordion, modal y carousel

El accordion agrupa secciones plegables que se abren y cierran de forma exclusiva (solo una a la vez). El modal superpone un diálogo sobre la página y el carousel reproduce imágenes deslizándose. Los tres funcionan con atributos data-bs-* y el bundle de Bootstrap, sin escribir una línea de JavaScript. 

<!-- Botón que abre el modal -->
<button data-bs-toggle="modal" data-bs-target="#miModal" class="btn btn-primary">Abrir</button>

<div class="modal fade" id="miModal" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">...</div>
      <div class="modal-body">Contenido</div>
    </div>
  </div>
</div>

Funciona Sin jQuery
Ojo: Los modales y carousels requieren el bundle JS cargado al final del body. Sin él, los data-bs-* se quedan inertes.

Repaso rápido

  • La navbar se vuelve hamburguesa con navbar-expand-lg + collapse.
  • Cards, buttons, badges y alerts comparten la lógica de clases por color.
  • Modal, carousel, accordion y dropdown usan data-bs-* y el bundle, sin JS manual.
  • Los tooltips necesitan una línea de JavaScript para inicializarse.
