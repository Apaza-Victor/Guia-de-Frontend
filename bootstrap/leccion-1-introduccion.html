Introducción y grid system

Qué es Bootstrap, su historia, cómo instalarlo y el sistema de grid de 12 columnas.

¿Qué es Bootstrap?

Bootstrap es el framework CSS más usado del mundo: un conjunto de HTML, CSS y JavaScript listo para usar con el que construyes interfaces responsivas de forma rápida y consistente. En vez de escribir media queries a mano, defines clases como col-md-6 y Bootstrap se encarga del resto.

Historia breve:

AñoHito
2011Nace como Twitter Blueprint, la guía de estilos interna de Twitter.
2013Bootstrap 3 se vuelve mobile-first y adopta el grid fluido por defecto.
2018Bootstrap 4 abandona Less por Sass y añade Flexbox.
2021Bootstrap 5 elimina jQuery, usa variables CSS e incluye iconos y utilidades flexbox completas.
Aviso: Bootstrap estiliza rápido, pero si dependes solo de él tus páginas se parecerán entre sí. Úsalo como base y personalízalo con tus propias variables (lo verás en la lección 4).

Instalación: CDN vs npm

Tienes dos caminos principales para incluir Bootstrap en un proyecto.

Opción 1 — CDN (recomendada para practicar): solo añades el link de CSS en el <head> y el script del bundle al final del body.

<!-- CSS en el head -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- JS (bundle) antes de cerrar el body -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

Opción 2 — npm (proyectos reales): instalas el paquete y lo compilas con tu bundler favorito (Vite, Webpack…).

npm install bootstrap 
# luego importas el Sass:  @import "bootstrap/scss/bootstrap";
CriterioCDNnpm
Velocidad de setupSegundos, sin instalaciónRequiere Node y build

Uso idealPrototipos y leccionesAplicaciones en producción
Tip: El bootstrap.bundle.min.js ya incluye Popper, que necesita el tooltip, las dropdowns y los popovers. Cárgalo siempre al final del body.

El grid: container, row y col

El grid de Bootstrap tiene tres capas que siempre se anidan en este orden:

  • .container — centra el contenido y aplica un ancho máximo según el breakpoint.
  • .row — crea una fila horizontal y activa los gutters (márgenes entre columnas).
  • .col-* — cada columna. La fila se divide siempre en 12 unidades.
<div class="container">
  <div class="row">
    <div class="col-6 col-md-4"></div> <!-- 6 col. en móvil, 4 en md -->
    <div class="col-6 col-md-4"></div>
    <div class="col-12 col-md-4"></div>
  </div>
</div>

La lógica: la columna coge el ancho equivalente a su número de unidades sobre 12. col-md-6 = la mitad de la fila desde el breakpoint md en adelante.

ClaseBreakpointAncho mínimo
col-*Sin prefijoSiempre (móvil)
col-sm-*≥ sm576px
col-md-*≥ md768px
col-lg-*≥ lg992px
col-xl-*≥ xl1200px
col-xxl-*≥ xxl1400px
Tip: Reduce el ancho de la ventana del navegador mientras miras la demo. Verás la misma fila reorganizarse sola: eso es la responsividad del grid.

Offset, order y gutters

Tres utilidades que refinan el grid:

  • offset-md-2 — empuja la columna n unidades hacia la derecha (crea espacios en blanco).
  • order-first / order-last / order-2 — reordena visualmente las columnas sin tocar el HTML.
  • g-3 / gx-4 / gy-2 — controla los gutters: la distancia entre columnas (g total, gx horizontal, gy vertical).
<div class="row g-4">
  <div class="col-md-4 order-md-2">Contenido B</div>
  <div class="col-md-4 offset-md-2 order-md-1">Contenido A</div>
</div>

Repaso rápido

  • Bootstrap se instala por CDN (rápido) o npm (personalizable).
  • El grid se compone de container → row → col y suma 12 columnas.
  • Los prefijos sm / md / lg / xl / xxl activan el ancho solo desde ese breakpoint.
  • offset empuja, order reordena y g-* controla los gutters.
