Fetch avanzado

Envía datos, sube archivos y corta peticiones; mucho más allá del GET.

POST con JSON

fetch siempre admite un segundo parámetro para configurar la petición. Para enviar JSON: 

fetch('/api/usuarios', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Accept': 'application/json'
  },
  body: JSON.stringify({ nombre: 'Ana', edad: 30 })
})
  .then((r) => { if (!r.ok) throw new Error('HTTP ' + r.status); return r.json(); })
  .catch(console.error);
OpciónPara quéValor típico
methodel verbo HTTPGET, POST, PUT, DELETE…
headersmetadatos de la peticiónContent-Type: application/json
bodylo que enviamosstring JSON, FormData, Blob…
credentialscookies cross-site'omit' | 'same-origin' | 'include'
Ojo: El body de un POST se envía como texto: no pases un objeto directo, usa JSON.stringify. Olvidar el header Content-Type es la causa #1 de errores "payload no válido" en APIs.

FormData y subida de archivos

Para formularios (con o sin archivos) FormData evita armar strings a mano y respeta la codificación correcta automáticamente: 

const form = document.querySelector('#mi-form');
const datos = new FormData(form);
datos.append('descripcion', 'foto de portada');

fetch('/api/upload', { method: 'POST', body: datos });
// ¡no pongas headers manuales! fetch pone el boundary solo
Tip: Para ver el progreso de un upload real usas XMLHttpRequest con upload.onprogress; fetch no expone el porcentaje. O, con streams (avanzado), se puede medir el cuerpo enviado.

AbortController: cancelar y timeouts

Hasta hace poco era imposible cancelar un fetch. Con AbortController puedes: cancelar por el usuario, implementar un timeout y evitar que una petición colgada se quede para siempre: 

const controlador = new AbortController();
const senal = controlador.signal;

// timeout de 5 s
setTimeout(() => controlador.abort(), 5000);

fetch(url, { signal: senal })
  .then((r) => r.json())
  .catch((err) => {
    if (err.name === 'AbortError') {
      console.log('Petición cancelada (timeout o usuario)');
    }
  });
Tip: Abortar también dispara AbortSignal.timeout(ms) en navegadores modernos (fetch(url, { signal: AbortSignal.timeout(5000) })). Detecta con 'timeout' in AbortSignal.

Repaso rápido

  • POST/JSON: JSON.stringify + header Content-Type.
  • FormData: deja que fetch genere el boundary y la codificación.
  • AbortController para cancelar peticiones y montar timeouts.
  • Comprueba response.ok y captura AbortError aparte.
