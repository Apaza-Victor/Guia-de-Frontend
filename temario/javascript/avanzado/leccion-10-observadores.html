Observadores del navegador

Reacciona a lo que entra en pantalla, cambia de tamaño o muta el DOM.

¿Qué son los observadores?

En lugar de preguntar constantemente con scroll o resize + cálculos manuales (caro y frágil), los observadores avisan cuando algo sucede. Tres son los protagonistas:

ObservadorDetectaUso típico
IntersectionObservercuándo un elemento entra/sale del viewportlazy loading, animaciones al llegar
ResizeObservercambios de tamaño de un elementográficas que caben, menús adaptativos
MutationObservercambios del DOM (nodos, atributos, texto)reactividad al modificar la UI

IntersectionObserver: al llegar a la vista

Con una sóla instancia observas N elementos. El callback recibe entries; cada entry.isIntersecting dice si es visible: 

const observador = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      entry.target.classList.add('visible');
      observador.unobserve(entry.target);  // una sola vez
    }
  });
}, { threshold: 0.2 });

document.querySelectorAll('.card').forEach((el) => observador.observe(el));

Este es el motor del lazy loading de imágenes y del efecto de "revelar" tarjetas al hacer scroll.

ResizeObserver: tamaño de elementos

El evento resize de window solo sabe del viewport. Para conocer el tamaño de un elemento (que cambia con otros en su misma caja) usamos ResizeObserver: 

const observador = new ResizeObserver((entradas) => {
  entradas.forEach((entrada) => {
    console.log(entrada.contentRect.width);
  });
});
observador.observe(miPanel);

MutationObserver: cambios del DOM

Observa hijos, atributos o texto dentro de un nodo. Útil para integrar librerías que "hablan" con el DOM o para reaccionar a cambios generados por otro código: 

const observador = new MutationObserver((mutaciones) => {
  mutaciones.forEach((mut) => console.log(mut.type));
});
observador.observe(lista, {
  childList: true,  // hijos añadidos/quitados
  subtree: true,   // descendientes
  attributes: true // cambios de atributos
});
Ojo: Siempre llama a disconnect() cuando ya no necesitas observar (demasiados observers vivos cuestan memoria y CPU).

Has completado el tema JavaScript

  • Desconecta siempre los observadores que ya no usas.
