Strings y métodos

Manipula texto como un profesional: mide, transforma, busca, corta y une strings, y formatea números con toFixed.

Los strings y su longitud

Un string es una secuencia de caracteres entre comillas. Aunque se vea como un texto simple, cada carácter tiene una posición (índice) que empieza en 0. La propiedad length cuenta cuántos caracteres hay.

const nombre = "Frontend Pro";

console.log(nombre.length);   // 12 (incluye el espacio)
console.log(nombre[0]);        // "F" ← primer carácter (índice 0)
console.log(nombre[11]);       // "o" ← último carácter
console.log(nombre[nombre.length - 1]); // "o" ← siempre el último

Transformar y limpiar: toUpperCase, toLowerCase y trim

Estos métodos devuelven un string nuevo (los strings son inmutables: el original no cambia). trim() elimina espacios de los extremos, imprescindible al leer formularios.

const usario = "   Ana García  ";

console.log(usario.trim());                 // "Ana García"
console.log(usario.trim().toUpperCase());  // "ANA GARCÍA"
console.log(usario.trim().toLowerCase());  // "ana garcía"

// Encadenar métodos es habitual y legible
const email = "  USUARIO@GMAIL.COM  ";
const limpio = email.trim().toLowerCase(); // "usuario@gmail.com"
Tip: Antes de comparar textos de formularios, aplica siempre .trim().toLowerCase() para evitar errores por espacios y mayúsculas.

Buscar y verificar: includes, startsWith y replace

Para comprobar si un texto contiene, empieza o termina con una palabra, o para reemplazar fragmentos, usa estos tres métodos.

const frase = "Aprende JavaScript en Frontend Pro";

console.log(frase.includes("JavaScript")); // true
console.log(frase.includes("CSS"));        // false
console.log(frase.startsWith("Aprende")); // true
console.log(frase.endsWith("Pro"));     // true

// replace reemplaza la PRIMERA coincidencia
console.log(frase.replace("JavaScript", "CSS"));
// "Aprende CSS en Frontend Pro"

// Para todas las coincidencias usa una expresión regular /g
console.log("a-a-a".replace(/a/g, "o")); // "o-o-o"

Cortar y unir: slice, substring, split y join

slice() y substring() extraen una parte del string; split()/join() convierten entre texto y arrays.

const url = "frontend-pro.com/articulos/javascript";

// slice(inicio, finInclusive?): corta el string
console.log(url.slice(0, 15)); // "frontend-pro.c"
console.log(url.slice(-10));   // "javascript" ← índices negativos

// substring: similar, pero sin soportar índices negativos
console.log(url.substring(0, 15)); // "frontend-pro.c"

console.log("a,b,c".split(","));       // ["a", "b", "c"]
console.log(["a", "b", "c"].join("-")); // "a-b-c"

// Patrón típico: separar y volver a unir
console.log("Hola mundo JS".split(" ").join(" · "));
Diferencia clave: slice() acepta índices negativos (cuenta desde el final) y es la recomendada. substring() no los soporta.

Template literals y toFixed de Number

Las template literals embeben variables y expresiones dentro del texto. Y para los números, toFixed(n) fija el número de decimales — tan usado en precios y cálculos que precisan formateo.

// Template literals: inserta valores con ${...}
const producto = "Teclado";
const precio = 49.9;

const mensaje = `El ${producto} cuesta $${precio.toFixed(2)}`;
console.log(mensaje); // "El Teclado cuesta $49.90"

// toFixed devuelve un STRING con los decimales pedidos
console.log((10 / 3).toFixed(2));   // "3.33"
console.log(typeof (3.14159).toFixed(2)); // "string"
console.log((2).toFixed(3));        // "2.000"
