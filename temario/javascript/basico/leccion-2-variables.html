Variables: let, const y var

Almacena información en variables, entiende las diferencias entre let, const y var y domina las template literals.

Declarando variables: let, const y var

JavaScript ofrece tres formas de declarar variables. Las dos modernas son let y const; var es la forma antigua que debes evitar.

// let: permite reasignar el valor
let nombre = "Ana";
nombre = "Carlos"; // ✅ Válido

// const: NO permite reasignar. Una vez asignado, es inmutable.
const PI = 3.14159;
// PI = 3; // ❌ TypeError

// var: la forma antigua. Tiene scope de función, puede causar bugs.
var vieja = "no la uses";
¿Por qué evitar var? var tiene scope de función en vez de scope de bloque, lo que genera bugs difíciles de rastrear. Usa const por defecto y let solo cuando necesites reasignar.
Palabra claveReasignableScopeUso recomendado
constNoBloquePor defecto siempre
letSíBloqueSolo cuando cambia el valor
varSíFunción❌ Nunca (en código moderno)
Tip: El operador typeof te permite averiguar qué tipo de valor almacena una variable. Lo estudiaremos a fondo en la Lección 3: Tipos de datos.

Template literals

Las template literals (literales de plantilla) permiten insertar expresiones dentro de un string usando ${...}. Son más legibles y potentes que la concatenación con +.

const nombre = "Ana";
const edad = 28;

// Concatenación clásica (antigua)
let saludo1 = "Hola, " + nombre + " tienes " + edad + " años";

// Template literal (moderna y limpia)
let saludo2 = `Hola, ${nombre} tienes ${edad} años`;

// También permiten expresiones complejas
let mensaje = `En 5 años tendrás ${edad + 5} años`;

// Multilínea sin \n
let multi = `
  Esta es
  una línea
  multilínea
`;
CaracterísticaConcatenación +Template literal ` `
LecturaDifícil con muchas variablesClara e intuitiva
MultilíneaRequiere \nNatural con saltos de línea
ExpresionesLimitadoCualquier expresión dentro de ${}
RendimientoIgualIgual (el motor las optimiza igual)
Tip: Siempre usa template literals en lugar de concatenación. Son más legibles, menos propensas a errores y soportan expresiones JavaScript directamente.

Repaso rápido

  • Usa const por defecto; let solo cuando reasignes. Nunca var.
  • const y let tienen scope de bloque; var tiene scope de función (y bugs).
  • Las variables guardan valores de distintos tipos: number, string, boolean, null, undefined, bigint y symbol.
  • Las template literals `Hola, ${nombre}` son más limpias y poderosas que la concatenación con +.
