¿Qué es Astro y tu primer proyecto

Entiende el meta-framework que construye sitios rápidos por defecto y crea tu primer proyecto en segundos.

¿Qué es Astro?

Astro es un meta-framework para construir sitios web: toma componentes de otros frameworks (o sus propios componentes .astro), los renderiza en el servidor y genera HTML estático por defecto.

Su idea central se llama island architecture (arquitectura de islas): el sitio sale de fábrica con cero JavaScript. Solo se envía JS al navegador en las "islas" concretas que lo necesitan, y cada una se hidrata de forma independiente.

EnfoqueClásico (SPA)Astro (islas)
JavaScript al navegadorTodo el bundleSolo las islas interactivas
Primera renderizaciónEn el clienteHTML estático en el servidor
SEO y velocidadComprometidosExcelentes por defecto
En una frase: Astro te deja escribir componentes modernos y entrega al visitante solo HTML, CSS y el mínimo JS imprescindible.

Crear tu primer proyecto

Astro se crea con su CLI oficial. Abre una terminal y ejecuta:

npm create astro@latest
# ? Where should we create your new project?  ./mi-primer-astro
# ? How would you like to start your new project?  Empty
# ? Do you plan to write TypeScript?  Yes
# ? Install dependencies? (recommended)  Yes

El asistente genera el proyecto y te deja listo para escribir código. Entra en la carpeta y abre tu editor:

cd mi-primer-astro
code .
Tipos de arranque

Puedes iniciar con una plantilla base, con blog, con documentación o incluso importar un proyecto oficial. La plantilla Empty es perfecta para aprender desde cero.

Estructura de carpetas

Todo el sitio vive en dos zonas claras: el código en src/ y los archivos que llegan tal cual en public/.

mi-primer-astro/
├── public/          # Estáticos sin procesar: favicon, robots.txt, imágenes
│   └── favicon.svg
├── src/
│   ├── components/   # Componentes .astro, React, Vue... reutilizables
│   ├── layouts/       # Plantillas que envuelven varias páginas
│   └── pages/         # Cada archivo aquí genera una ruta del sitio
│       └── index.astro
├── astro.config.mjs # Configuración: integraciones, base, formato
└── package.json
Carpeta / archivoFunción
src/pagesRutas basadas en archivos: about.astro crea /about.
src/componentsPiezas reutilizables de interfaz.
src/layoutsEstructuras compartidas (head, header, footer).
publicSe copia a dist/ sin transformar.
astro.config.mjsRegistro de integraciones y opciones del build.

astro dev y astro build

Dos comandos cubren todo el flujo de trabajo: uno para desarrollar con recarga en caliente y otro para generar el sitio final.

npm run dev       # Servidor de desarrollo en http://localhost:4321
npm run build     # Genera la carpeta dist/ con el sitio estático
npm run preview   # Previsualiza el build generado en local
Tip: astro dev recarga la página al instante al guardar. Cada vez que cambies un componente verás el resultado al momento, sin reconstruir nada.

Demo: interpolación en el template

En la plantilla de un componente .astro interpelas variables con llaves. Este pequeño demo simula esa interpolación: escribe tu nombre y mira el resultado en tiempo real.

Astro interpola expresiones dentro del template. Prueba con tu nombre:

Hola, visitante — bienvenido a tu primer componente Astro.

---
const saludo = "Hola, visitante";
---
<h1>{saludo}</h1>
<!-- Resultado en el navegador: <h1>Hola, visitante</h1> -->
Recuerda: esa interpolación ocurre en la construcción: el navegador recibe el HTML ya finalizado. Para reaccionar en el cliente necesitarás una isla (lo verás en la Lección 4).

Repaso rápido

  • Astro es un meta-framework que renderiza HTML estático y solo envía JS donde hace falta (islas).
  • Un proyecto nuevo nace con npm create astro@latest.
  • src/pages crea rutas por archivo; public se copia tal cual.
  • npm run dev para desarrollar y npm run build para desplegar.
