Práctica: landing con Astro + Tailwind

Proyecto final: una landing estática de alta conversión con componentes .astro, layouts, Tailwind y una isla de interacción.

Tu proyecto final

Elige una de estas dos opciones y construye su landing con Astro. La meta: un sitio rápido, con componente modular y una isla interactiva.

Opción A: Portfolio

Landing de tu perfil como desarrollador: hero con tu nombre, sección de proyectos, habilidades y contacto. Perfecta para tu marca personal.

Opción B: SaaS

Landing de un producto: hero con CTA, 3 características, testimonios, precio y un formulario de registro. Enfoque de conversión total.

Estructura de la landing

Divide la página en componentes pequeños dentro de src/components y únelos desde src/pages/index.astro usando el layout base.

src/
├── components/
│   ├── Navbar.astro
│   ├── Hero.astro
│   ├── Features.astro
│   ├── Testimonios.astro
│   ├── Precios.astro
│   ├── Cta.astro
│   └── Footer.astro
├── layouts/
│   └── Base.astro
└── pages/
    └── index.astro
---
import Base from "../layouts/Base.astro";
import Navbar from "../components/Navbar.astro";
import Hero from "../components/Hero.astro";
import Features from "../components/Features.astro";
import Testimonios from "../components/Testimonios.astro";
import Precios from "../components/Precios.astro";
import Cta from "../components/Cta.astro";
import Footer from "../components/Footer.astro";
---

<Base titulo="Aura SaaS · Menos código, más velocidad">
  <Navbar />
  <main>
    <Hero />
    <Features />
    <Testimonios />
    <Precios />
    <Cta />
  </main>
  <Footer />
</Base>

Hero con utilidades Tailwind

Dentro del componente Hero.astro escribes las clases directamente. Con la integración @astrojs/tailwind añadida en la Lección 4, esta clase ya funciona sin CSS extra.

<section class="bg-slate-950 py-24 px-6 text-center">
  <p class="text-sm font-medium text-sky-400">Nueva versión 2.0</p>
  <h1 class="text-4xl md:text-6xl font-bold text-white mt-4">
    Menos código,
    <span class="bg-gradient-to-r from-sky-400 to-violet-400 bg-clip-text text-transparent">más velocidad</span>
  </h1>
  <p class="text-slate-300 mt-6 max-w-2xl mx-auto">
    Publica sitios ultrarápidos con Astro y estiliza con utilidades Tailwind.
  </p>
  <a href="/registro" class="inline-block bg-sky-500 px-6 py-3 rounded-lg font-semibold text-white mt-8">
    Empezar gratis
  </a>
</section>
Responsive: el prefijo md: aplica la clase solo a partir de 768px, igual que las variantes sm/lg que ya conoces de Tailwind. Un solo archivo se adapta a todas las pantallas.

La isla del formulario

La única interacción real de esta landing: un formulario que responde al enviar. Lo marcas con client:load para que Astro lo hidrate solo a él.

---
import FormularioCta from "../components/FormularioCta.astro";
---

<FormularioCta client:load />
Mini demo: botón de isla

Este bloque simula una isla: el HTML llega estático y el script después lo dota de comportamiento.

Compilar y desplegar

El flujo final es tan corto como en la Lección 1: astro build genera la carpeta dist/ lista para cualquier host de estáticos.

npm run build
# Genera dist/ con HTML, CSS, imágenes y el JS mínimo de las islas

# Verifica el resultado en local antes de desplegar
npm run preview
Resultado esperado

Un dist/ con pocos kilobytes de JavaScript total: cada isla recibe su propios pequeños scripts y nada más. Eso se nota en el Lighthouse móvil.

Checklist de entrega

  • Proyecto creado con npm create astro@latest y dependencias instaladas.
  • Integración @astrojs/tailwind registrada en astro.config.mjs.
  • Layout Base.astro con slot, head y footer compartidos.
  • Landing dividida en al menos 5 componentes reutilizables.
  • Hero con CTA y gradiente Tailwind responsive (sm/md).
  • Al menos una isla con client:load (formulario o contador).
  • npm run build termina sin errores y npm run preview la muestra.
