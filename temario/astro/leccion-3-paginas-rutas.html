Páginas, rutas y layouts

Cada archivo en src/pages es una URL: rutas en limpio, layouts que comparten estructura y slugs para contenido dinámico.

Rutas basadas en archivos

Astro usa rutas por archivo: el árbol de src/pages define las URLs del sitio sin configurar nada. Crea un archivo, guardarlo y ya tienes una página nueva.

Archivo en src/pagesURL del sitio
index.astro/
acerca.astro/acerca
blog.astro/blog
blog/2026/post.astro/blog/2026/post
404.astropágina de error 404
Tip: La estructura de carpetas importa más que los nombres: por ejemplo contacto/index.astro también genera /contacto.

Layouts para compartir estructura

Las páginas repiten head, navbar y footer. Un layout centraliza esa estructura y usa un <slot> para inyectar el contenido propio de cada página.

---
// src/layouts/Layout.astro
interface Props {
  titulo: string;
}
const { titulo } = Astro.props;
---
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="utf-8" />
    <title>{titulo}</title>
    <link rel="stylesheet" href="/estilos.css" />
  </head>
  <body>
    <nav>Menú del sitio</nav>
     <!-- el contenido de cada página entra aquí -->
    <footer>© 2026</footer>
  </body>
</html>
Slots con nombre

Además del <slot /> principal existe <slot name="titulo" />; en la página usas <h1 slot="titulo"> para rellenar partes específicas del layout.

Usar el componente Layout

Desde cualquier página importas el layout, le pasas props y envuelves el contenido. El <slot> del layout recibe todo lo que escribas entre las etiquetas.

---
// src/pages/index.astro
import Layout from "../layouts/Layout.astro";
---

<Layout titulo="Inicio">
  <h1>Bienvenido a mi sitio</h1>
  <p>Este bloque se inyecta dentro del layout.</p>
</Layout>
Beneficio: cambias el navbar o el footer en un solo archivo y todas las páginas que usan Layout se actualizan con un guardado.

Navegación entre páginas

La navegación es HTML puro: enlaces <a href="."> absolutos o relativos. Como el sitio se genera estático, cualquier ruta servida funciona sin JavaScript.

<nav>
  <a href="/">Inicio</a>
  <a href="/acerca">Acerca</a>
  <a href="/blog">Blog</a>
</nav>
Cuidado: si despliegas en una subcarpeta (por ejemplo /guia/), configura la propiedad site y base en astro.config.mjs para que las URLs absolutas apunten bien.

Slugs y rutas dinámicas

Para páginas como /blog/mi-post, creas una carpeta con corchetes [slug] y exportas getStaticPaths: Astro genera un HTML por cada valor devuelto.

---
// src/pages/blog/[slug].astro
export async function getStaticPaths() {
  const posts = [
    { slug: "hola-astro", title: "Hola Astro", date: "2026-09-10" },
    { slug: "islas-en-accion", title: "Islas en acción", date: "2026-09-15" }
  ];
  return posts.map((post) => ({ params: { slug: post.slug }, props: { post } }));
}

const { post } = Astro.props;
const { slug } = Astro.params;
---
<article>
  <h1>{post.title}</h1>
  <p class="fecha">Publicado: {post.date}</p>
  <p>Estás leyendo: /blog/{slug}</p>
</article>
Resultado del build

dist/blog/hola-astro.html y dist/blog/islas-en-accion.html: dos páginas estáticas generadas a partir de un solo archivo de plantilla. Sin servidor ni base de datos.

Repaso rápido

  • El árbol de src/pages define las URLs sin configuración.
  • Los layouts con <slot> comparten head, navbar y footer.
  • La navegación se hace con <a href> estándar.
  • Las rutas [slug] + getStaticPaths generan páginas dinámicas en HTML estático.
