Bucles

Repite tareas sin copiar y pegar: for, while, do while y el control con break/continue.

El bucle for

Cuando sabes cuántas veces repetir, for es tu herramienta. Tiene 3 partes: inicio, condición e incremento:

for (let i = 1; i <= 5; i++) {
  console.log("Vuelta número " + i);
}
// Vuelta número 1 ... Vuelta número 5

El clásico contador que suma de 1 a 100:

let suma = 0;
for (let i = 1; i <= 100; i++) {
  suma += i;
}
console.log(suma); // 5050
Tip: i++ equivale a i = i + 1. Si quieres pasos de 2 usa i += 2.

Recorrer listas con for...of

Para recorrer arreglos sin manejar índices, for...of es lo más limpio:

const frutas = ["manzana", "pera", "uva"];

for (const fruta of frutas) {
  console.log(fruta);
}

Y si necesitas el índice, entries() te lo da:

for (const [indice, fruta] of frutas.entries()) {
  console.log(indice, fruta);
}

while y do while

while repite mientras la condición sea verdadera. Úsalo cuando no sabes cuántas vueltas habrá:

let intentos = 0;
while (intentos < 3) {
  console.log("Intento " + (intentos + 1));
  intentos++;
}

do...while ejecuta al menos una vez, porque la condición se revisa al final:

let x = 10;
do {
  console.log("Esta vuelta se imprime siempre");
} while (x < 5);
Cuidado: si la condición nunca cambia, creas un bucle infinito que congela el navegador. Siempre hay algo que avance dentro del bucle.

break y continue

  • break → sale del bucle por completo.
  • continue → salta a la siguiente vuelta.
for (let i = 1; i <= 10; i++) {
  if (i === 3) continue; // se salta el 3
  if (i === 7) break;    // se detiene en el 7
  console.log(i);              // 1 2 4 5 6
}

Repaso rápido

  • for repite un número conocido de veces; for...of recorre listas.
  • while se usa con vueltas desconocidas; do...while corre al menos una vez.
  • break corta, continue salta; evita bucles infinitos.
