Variables y tipos de datos

Cajas para guardar información y los tipos de datos que JavaScript entiende de forma nativa.

¿Qué es una variable?

Una variable es una caja con nombre donde guardas un valor. En JavaScript moderno se declara con let (puede cambiar) o const (no puede cambiar):

let edad = 25;          // puede cambiar después
const nombre = "Ana";    // constante: no se reasigna

edad = 26;              // OK: let permite reasignar
nombre = "Luis";        // ERROR: const es fija
Regla de oro: usa const por defecto y cambia a let solo cuando el valor debe reasignarse. Evita var (estilo antiguo).

Ver el tipo de un dato

Con typeof puedes saber qué tipo contiene una variable:

console.log(typeof 42);        // "number"
console.log(typeof "42");      // "string"  (¡ojo! son distintas)
console.log(typeof true);      // "boolean"
Ojo: 42 y "42" se ven igual pero son tipos distintos. Mezclarlos causa los clásicos errores de principiante.
