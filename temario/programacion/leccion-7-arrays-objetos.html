Arrays y objetos

Agrupa datos en listas y en fichas con nombre: las estructuras que usan todas las apps.

Arrays: listas ordenadas

Un array guarda varios valores en orden, entre corchetes. Cada valor tiene un índice que empieza en 0:

const colores = ["rojo", "verde", "azul"];

colores[0]           // "rojo"  (índice 0)
colores.length      // 3  (cantidad de elementos)

colores.push("amarillo"); // añade al final
colores.pop();        // quita el último
Tip: Empieza a contar desde 0: el último elemento de una lista con 3 items está en el índice 2.

Objetos: fichas con nombre

Un objeto agrupa datos (propiedades) con su nombre, entre llaves:

const usuario = {
  nombre: "Ana",
  edad: 25,
  esAdmin: false
};

usuario.nombre       // "Ana" (punto)
usuario["edad"]       // 25   (corchetes)

usuario.ciudad = "Cusco"; // agrega propiedad

Los objetos también llevan funciones (métodos):

const punto = {
  x: 2,
  y: 3,
  mover: () => console.log("Moviendo...")
};
punto.mover();

Combinarlos: lista de objetos

El patrón que verás en toda aplicación real (productos, usuarios, mensajes...):

const productos = [
  { nombre: "Café", precio: 12 },
  { nombre: "Té",   precio: 8  },
  { nombre: "Pan",  precio: 5  }
];

for (const producto of productos) {
  console.log(producto.nombre + " -> S/ " + producto.precio);
}

map transforma creando una nueva lista (no modifica la original):

const soloNombres = productos.map(p => p.nombre);
// ["Café", "Té", "Pan"]

filtrar, encontrar y ordenar

const baratos = productos.filter(p => p.precio < 10);
// [{ nombre: "Té", precio: 8 }, { nombre: "Pan", precio: 5 }]

const cafecito = productos.find(p => p.nombre === "Café");

const porPrecio = [...productos].sort((a, b) => a.precio - b.precio);
Cuidado: sort modifica el array original. Usa la copia con [...productos] si no quieres alterarlo.

Repaso rápido

  • Arrays guardan listas ordenadas (índice desde 0); objetos guardan datos con nombre.
  • La combinación lista-de-objetos modela productos, usuarios y más.
  • push, map, filter y find son tus aliados cotidianos.
