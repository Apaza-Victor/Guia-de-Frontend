Funciones

Empaqueta lógica reutilizable: parámetros, return, arrow functions y el alcance de cada variable.

¿Por qué funciones?

Las funciones son bloques reutilizables: escribes la lógica una vez y la llamas cuando quieras. Mantienen tu código corto, legible y sin copias.

function saludar() {
  console.log("Hola desde una función");
}

saludar(); // se ejecuta ahora
saludar(); // y se puede volver a ejecutar
Tip: Nombra las funciones con verbos: calcularTotal, obtenerUsuario, validarFormulario.

Parámetros y return

  • Parámetros: entradas que recibe la función.
  • return: devuelve un resultado al que lo llama.
function sumar(a, b) {
  return a + b;
}

const resultado = sumar(3, 4); // 7
console.log(resultado);
function esMayor(edad, limite) {
  return edad >= limite;
}

esMayor(20, 18); // true
Ojo: Todo lo que viene después de return no se ejecuta. Si una función no usa return, devuelve undefined.

Arrow functions

La forma moderna y compacta: (parámetros) => resultado.

const sumar = (a, b) => a + b;
const doble = x => x * 2;          // 1 parámetro: sin paréntesis
const saludar = () => console.log("Hola");

Con bloque, si necesitas más de una instrucción:

const validar = (texto) => {
  const limpio = texto.trim();
  return limpio.length > 0;
};

Alcance (scope)

Una variable declarada con let/const dentro de una función solo existe allí:

function probar() {
  const interna = "solo aquí";
  console.log(interna); // OK
}

console.log(interna); // ERROR: fuera de alcance

Las declaradas fuera (nivel global) sí son visibles dentro:

const lugar = "Frontend Pro";
function mostrar() { console.log(lugar); } // OK

Repaso rápido

  • Las funciones reutilizan lógica; reciben parámetros y devuelven resultados con return.
  • Las arrow functions las escriben más cortas: (a, b) => a + b.
  • El scope local protege variables; no abuses de las globales.
