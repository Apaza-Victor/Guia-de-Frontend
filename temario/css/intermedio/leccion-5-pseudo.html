Pseudo-clases y pseudo-elementos

Estiliza estados (:hover, :focus), posiciones (:nth-child, :not, :is), elementos generados (::before, ::after) y hasta al padre con :has().

¿Qué son las pseudo-clases?

Una pseudo-clase selecciona elementos según un estado o posición que no se refleja en el HTML: ¿está el cursor encima? ¿es el primer hijo? Se escriben con un solo dos puntos y se pegan al selector: 

selector:pseudo-clase {
  propiedad: valor;
}

/* Ejemplos reales */
a:hover   { color: #2563eb; }
button:focus { outline: 2px solid #06b6d4; }
li:first-child { font-weight: 700; }
Tip: No confundas los dos puntos: las pseudo-clases usan : (estados), los pseudo-elementos usan :: (partes). CSS acepta : en ambos por compatibilidad, pero el estándar usa :: para pseudo-elementos.

Estados: :hover, :focus y :active

Son las pseudo-clases de interacción: el navegador las activa según las acciones de la persona usuaria:

Pseudo-claseCuándo aplicaUso típico
:hoverEl cursor está sobre el elementoCambiar color de enlaces, elevar tarjetas
:focusEl elemento recibe el teclado (Tab, clic)Resaltar inputs y botones accesibles
:activeEl elemento se está pulsando (clic presionado)Feedback táctil de botones
:focus-withinEl elemento o un descendiente recibe el focoResaltar todo el formulario al enfocar un campo
:visitedEl enlace ya fue visitadoDiferenciar historial (usa solo color)
 
.btn {
  transition: transform 0.2s ease;
}
.btn:hover   { transform: translateY(-2px); }
.btn:active  { transform: scale(0.96); }
.btn:focus-visible {
  outline: 3px solid rgba(6,182,212,0.5);
  outline-offset: 2px;
}
Accesibilidad: No elimines el outline del foco (outline: none): deja al menos un borde visible alternativo. El teclado necesita saber dónde está el cursor. Si quieres ocultarlo solo con ratón, usa :focus-visible.

:nth-child y sus variantes

Seleccionan elementos por su posición dentro del padre, con la fórmula an + b:

li:nth-child(2)      /* el segundo hijo */
li:nth-child(odd)    /* los impares (1, 3, 5…) */
li:nth-child(even)   /* los pares (2, 4, 6…) */
li:nth-child(3n)     /* cada 3 elementos (3, 6, 9…) */
li:nth-child(3n + 1) /* el primero de cada grupo de 3 */
li:nth-last-child(1) /* el último hijo */
SelectorMatemáticaResultado
:nth-child(odd)2n + 1Filas alternas de una tabla (sombrear)
:nth-child(3n)3nCada 3 elementos en un grid
:nth-last-child(2)Desde el finalPenúltimo elemento de una lista
:first-child / :last-childFijosQuitar el margen del primer/último item
:nth-of-type(2)Por tipo2º <p> ignorando los <div> intercalados
Truco: para 1 de cada X, escribe :nth-child(Xn + 1). De ahí salen los grids del "primer item pegado a la izquierda".

:not() y :is()

:not() excluye elementos y :is() agrupa selectores para no repetirlos:

/* Todo excepto el último item */
li:not(:last-child) {
  margin-bottom: 12px;
}

/* Sin :is() — repetición larga */
.card :hover .titulo,   .card :focus .titulo,
.banner :hover .titulo, .banner :focus .titulo { … }

/* Con :is() — agrupa y reduce */
:is(.card, .banner):hover .titulo,
:is(.card, .banner):focus .titulo {
  color: #2563eb;
}

/* Combinable: todo menos uno */
.form :not([type="hidden"]) {
  margin-bottom: 16px;
}

Pseudo-elementos: ::before y ::after

Un pseudo-elemento genera una caja extra dentro de un elemento, sin tocarlo en el HTML. Va siempre acompañado de content:

.titulo-seccion::before {
  content: "› ";                   /* texto (o "" para solo estilo) */
  color: #06b6d4;
}

.card::after {
  content: "";                    /* vacío: solo decoración */
  display: block;
  width: 40px;
  height: 3px;
  background: #2563eb;
  border-radius: 2px;
}

/* content también acepta attr() desde el HTML */
.badge::after {
  content: attr(data-estado);
}

:has() — el "selector padre"

:has() estiliza un elemento según sus descendientes. Es el truco que permite "seleccionar al padre" sin JavaScript:

/* Resalta la card que contiene una imagen */
.card:has(img) {
  border-color: #2563eb;
}

/* Cambia el padding del form si hay error visible */
.form-group:has(.error) input {
  border-color: #ea580c;
}

/* Contadores de navegación del tipo "dropdown" */
nav li:has(ul) {
  position: relative;   /* el 
  •  que contiene un submenu */
}
    • Rendimiento: :has() es potente pero costoso de evaluar. Úsalo moderado: está bien para tarjetas y formularios, evítalo en selectores muy anidados o con muchos elementos.

    Repaso rápido

    • Las pseudo-clases (:) aplican por estado o posición: :hover, :focus, :active, :nth-child.
    • Los pseudo-elementos (::) generan cajas extra: ::before y ::after siempre usan content.
    • :nth-child(an + b) selecciona posiciones con matemática: odd, even, 3n…
    • :not() excluye y :is() agrupa selectores para reducir repetición.
    • :has() estiliza el padre según sus hijos — guárdalo para casos moderados por rendimiento.
    • No borres el outline de foco sin ofrecer una alternativa visible.
