Flexbox completo

Domina el layout unidimensional: alinea, distribuye y ordena elementos con precisión.

¿Qué es Flexbox?

Flexbox (Flexible Box Layout) es un modelo de layout de CSS que distribuye espacio dentro de un contenedor a lo largo de un único eje. A diferencia de los métodos tradicionales (float, inline-block), Flexbox resuelve problemas clásicos como el centrado vertical, el diseño de barras de herramientas y la distribución equitativa de espacio.

Se activa con una única propiedad:

display: flex;

El elemento contenedor se convierte en un flex container y sus hijos directos en flex items.

Tip: Flexbox es ideal para layouts en una dirección (fila o columna). Para dos dimensiones, consulta la lección de CSS Grid.

Dirección y ejes

flex-direction define el eje principal sobre el que se distribuyen los items:

flex-direction: row;            /* → horizontal (por defecto) */
flex-direction: row-reverse;     /* ← horizontal invertido */
flex-direction: column;          /* ↓ vertical */
flex-direction: column-reverse; /* ↑ vertical invertido */
ValorEje principalEje cruzado
rowHorizontal (→)Vertical (↓)
columnVertical (↓)Horizontal (→)
row-reverseHorizontal (←)Vertical (↓)
column-reverseVertical (↑)Horizontal (→)

Alineación: justify-content y align-items

Estas dos propiedades son la columna vertebral de Flexbox:

  • justify-content — alinea los items a lo largo del eje principal.
  • align-items — alinea los items a lo largo del eje cruzado.
justify-content: flex-start | flex-end | center
               | space-between | space-around | space-evenly;

align-items: flex-start | flex-end | center
           | stretch | baseline;
ValorEfecto
flex-startAlinea al inicio del eje
flex-endAlinea al final del eje
centerCentra en ambos ejes
space-betweenEspacio igual entre items, sin espacio en extremos
space-aroundEspacio alrededor de cada item
space-evenlyEspacio idéntico entre todos los items y extremos
stretchEstira los items para llenar el eje cruzado

Wrap, gap y order

/* Envolver items en múltiples líneas */
flex-wrap: nowrap;  /* por defecto — todo en una línea */
flex-wrap: wrap;    /* los items pasan a la siguiente línea */

/* Espacio entre items */
gap: 16px;

/* Reordenar sin cambiar el DOM */
order: -1;  /* mueve el item al inicio */
order: 1;   /* mueve el item al final */

/* Alineación individual de un item en el eje cruzado */
align-self: flex-end;
Importante: gap reemplaza los antiguos márgenes negativos y margin en el contenedor. Es la forma moderna y segura de espaciar flex items.

flex-grow, flex-shrink y flex-basis

Estas propiedades controlan cómo un item crece o se contrae dentro del espacio disponible:

/* shorthand: flex: grow shrink basis */
flex: 1;          /* crece para llenar espacio */
flex: 0 0 200px;  /* ancho fijo de 200px */
flex: 2 1 auto;  /* crece el doble que sus hermanos */
PropiedadValor por defectoDescripción
flex-grow0Cuánto crece un item para llenar espacio extra (proporcional)
flex-shrink1Cuánto se contrae cuando no cabe (proporcional)
flex-basisautoTamaño inicial del item antes de crecer o contraer
Tip: Usa flex: 1 para que todos los items se distribuyan en partes iguales, o flex: 0 0 250px para un ancho fijo con flexibilidad de salto de línea.

Repaso rápido

  • display: flex activa el layout flex en el contenedor.
  • justify-content distribuye en el eje principal; align-items en el cruzado.
  • flex-wrap: wrap permite que los items salten de línea cuando no caben.
  • gap añade espacio entre items sin márgenes negativos.
  • flex-grow / flex-shrink / flex-basis controlan el tamaño proporcional.
  • order reordena items visualmente sin tocar el HTML.
  • align-self permite alinear un item individualmente en el eje cruzado.
