Head profesional: Metadatos y SEO

Convierte el <head> de tu página en una máquina de descubrimiento: SEO, Open Graph, Twitter Cards y datos estructurados.

¿Por qué importa el <head>?

Todo lo que no se ve en pantalla pero decide el futuro de tu web vive en el <head>: cómo te describe Google, cómo se ve un enlace compartido en WhatsApp o Twitter, y cómo se indexan tus imágenes.

Metadatos esenciales

<meta name="description" content="Resumen atractivo de 150-160 caracteres.">
<meta name="robots" content="index, follow">
<meta name="author" content="Apaza Victor">
<meta name="theme-color" content="#0d1b2a">
<link rel="canonical" href="https://tusitio.com/pagina">
MetaPara qué sirve
descriptionEl snippet que Google muestra bajo tu título
robotsControla indexación y seguimiento de enlaces
canonicalEvita contenido duplicado indicando la URL oficial
theme-colorColorea la barra del navegador en móvil

Open Graph y Twitter Cards

Cuando compartes tu página en WhatsApp, LinkedIn o X, se muestra una tarjeta social. Se construye con estas etiquetas:

<meta property="og:type" content="website">
<meta property="og:title" content="Guía de Frontend Pro">
<meta property="og:description" content="Aprende HTML, CSS y JavaScript.">
<meta property="og:image" content="https://tusitio.com/portada.png">
  • og:image ideal de 1200×630 px y debe ser una URL absoluta HTTPS.
  • Twitter usa las mismas etiquetas + twitter:card con valores summary_large_image.
Tip: Prueba tus tarjetas con herramientas como Sharing Debugger de Meta antes de lanzar.

Datos estructurados con JSON-LD

Los rich results (estrellas de rating, breadcrumbs, FAQ) se activan con datos estructurados. El formato más cómodo es JSON-LD dentro de un <script>:

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Course",
  "name": "Guía de Frontend",
  "provider": { "@type": "Organization", "name": "Frontend Pro" }
}
</script>
Ojo: Nunca inventes datos estructurados que el contenido no respalde: Google penaliza el marcado engañoso.

Repaso rápido

  • description, robots y canonical son la base del SEO on-page.
  • Open Graph controla cómo se ve tu página al compartirla.
  • JSON-LD con Schema.org habilita rich results sin tocar el resto del HTML.
