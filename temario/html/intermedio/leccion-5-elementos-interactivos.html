Elementos interactivos

<dialog>, <details>, popover y atributos globales que crean interfaces dinámicas solo con HTML.

¿HTML puede ser interactivo sin JS?

Creías que todo era estático. Estos elementos nativos abren, cierran y muestran contenido sin una sola línea de JavaScript, con accesibilidad incluida.

<details> y <summary>: acordeones nativos

Los acordeones clásicos se resuelven con dos etiquetas y un atributo:

<details open>
  <summary>¿Qué es HTML semántico?</summary>
  <p>Es usar etiquetas que describen el significado
     de su contenido (header, article, footer)…</p>
</details>
  • El atributo open deja el panel desplegado por defecto.
  • Se puede animar su apertura con CSS moderno (content-visibility o la pseudoclase [open]).
  • Estado accesible listo por naturaleza.

<dialog>: ventanas modales de verdad

El elemento <dialog> trae modales y diálogos con foco gestionado:

<dialog id="demoDialog">
  <form method="dialog">
    <p>¿Quieres continuar con la lección?</p>
    <button value="guardar" autofocus>Guardar</button>
    <button value="cancelar">Cancelar</button>
  </form>
</dialog>
MétodoComportamiento
dialog.show()Lo abre sin bloquear el resto de la página
dialog.showModal()Lo abre en modo modal (bloquea y enfoca correctamente)
dialog.close()Lo cierra; con Esc también

Con showModal() el ::backdrop oscurece el fondo sin más CSS que un par de líneas.

Popover: tooltips y menús sin JS

El atributo popover crea capas superpuestas nativas; popovertarget las abre desde cualquier botón:

<button popovertarget="miTip">Mostrar ayuda</button>
<div popover id="miTip">Aquí va la ayuda flotante</div>

Perfecto para tooltips, menús contextuales o notificaciones flotantes. Se combina con popovertargetaction="hide|show|toggle".

Repaso rápido

  • details/summary para acordeones nativos.
  • dialog.showModal() para modales con foco gestionado.
  • popover + popovertarget para capas flotantes sin JS.
