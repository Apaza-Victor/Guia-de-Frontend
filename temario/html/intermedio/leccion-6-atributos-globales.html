Atributos globales

Los superpoderes que comparten todas las etiquetas: data-*, lang, hidden, contenteditable, draggable y más.

¿Qué son los atributos globales?

Los atributos globales se pueden aplicar a cualquier elemento HTML. Dominarlos multiplica tu control sobre cada página.

data-*: datos personalizados

El prefijo data- crea atributos propios para guardar información y leerla desde JavaScript/CSS:

<button data-price="99" data-producto="auriculares">
  Comprar
</button>
// JavaScript accede sin fricción:
const btn = document.querySelector('[data-producto]');
console.log(btn.dataset.precio); // "99"
Tip: En CSS usa selectores como [data-theme="dark"] para temas o estados. Este mismo sitio alterna tema con ese truco.

lang, dir y translate

Dejan el idioma y la dirección de lectura bien definidos para buscadores y lectores de pantalla:

<html lang="es">
<blockquote lang="en" translate="no">Stay hungry.</blockquote>
<p dir="rtl">نص عربي</p>
  • lang en <html> es obligatorio para una buena accesibilidad.
  • translate="no" evita que el navegador traduzca marcas, códigos o nombres propios.
  • dir="rtl" invierte el flujo para idiomas árabes o hebreos.

hidden, contenteditable y draggable

AtributoQué hace
hiddenOculta el elemento (ni se muestra ni entra en el flujo)
contenteditableHace editable el contenido en el navegador, ideal para editores
draggablePermite arrastrar (base de Drag & Drop)
spellcheckActiva o desactiva la corrección ortográfica
 
<p hidden>No se verá ni se accesibilizará</p>
<div contenteditable="true" spellcheck="true">
  Edita esta nota…
</div>

tabindex y el orden del foco

Controla quién recibe el foco con teclado y en qué orden:

<button>Natural 1</button>
<button tabindex="-1">Fuera del orden</button>
<div tabindex="0">Div enfocable</div>
Ojo: Evita tabindex positivos (1, 2, 3…): rompen el orden natural para usuarios de teclado. Usa 0 o -1.

Repaso rápido

  • data-* guarda datos custom accesibles desde JS y CSS.
  • lang, dir y hidden definen idioma, dirección y visibilidad.
  • Nada de tabindex positivos: mantén el orden natural del foco.
