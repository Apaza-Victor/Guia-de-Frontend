Sección: HTML Avanzado · Lección 5 35 min

Buenas prácticas y validación

Cierra el módulo con hábitos profesionales: HTML válido, semántico, mantenible y listo para escalar.

El documento correcto

Todo empieza por un DOCTYPE y unas reglas que evitan bugs invisibles:

<!DOCTYPE html>                      <!-- HTML estándar -->
<html lang="es">
<meta charset="UTF-8">              <!-- primero en el head -->
<meta name="viewport" content="width=device-width, initial-scale=1">
  • Un solo h1 por página, title descriptivo y description.
  • Etiquetas en minúsculas, atributos entre comillas, elementos siempre cerrados.
  • Sin div-soup: preferencia landmarks y elementos semánticos.

Valida tu HTML como un profesional

Tip: Configura Prettier + HTMLHint en VS Code: el código se autoformatea al guardar y los errores saltan al vuelo.

Checklist de entrega

  • DOCTYPE + lang="es" + charset + viewport correctos.
  • Un solo main y landmarks lógicos.
  • Todas las imágenes con alt y todos los iframes con title.
  • Formularios con label conectado a cada campo.
  • Jerarquía de encabezados sin saltos y contrastes suficientes.
  • Lighthouse con puntuación 90+ en Rendimiento, SEO y Accesibilidad.

Demo interactiva

Ejecuta el validador mental: mira esta página por dentro (F12 → Elements) y comprueba el checklist en vivo.

  • DOCTYPE + lang="es" + charset + viewport

  • Formularios con label en toda la guía
  • Jerarquía de encabezados ordenada
Recuerda: El HTML válido es barato de mantener: un error en una etiqueta puede tumbar un layout entero en CSS.

Repaso rápido

  • Base correcta: DOCTYPE, charset, viewport y lang.
  • HTML semántico > divs ilimitados.
  • Valida con W3C, axe y Lighthouse antes de entregar.
