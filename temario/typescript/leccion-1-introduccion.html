TypeScript · Lección 1 45 min

Introducción y tipos básicos

Descubre qué es TypeScript, por qué aporta valor tipar tu código y anota tus primeras variables.

¿Qué es TypeScript?

TypeScript es un superset tipado de JavaScript: todo lo que funciona en JS funciona también en TypeScript, pero con la posibilidad de anotar tipos para que el editor y el compilador detecten errores antes de que el código se ejecute.

// JavaScript: el error aparece al ejecutar
let edad = 30;
edad = "muchos";  // permitido, luego lo pagas en runtime
// TypeScript: el error aparece al compilar
let edad: number = 30;
edad = "muchos";  // Error: Type 'string' is not assignable to type 'number'.
Concepto clave: al compilar, tu código TypeScript se convierte en JavaScript puro y limpio. El navegador siempre recibe JS; los tipos son solo una capa de seguridad para ti.

¿Por qué tipar?

En equipos grandes y proyectos que crecen, adivinar qué espera una función o qué devuelve un objeto cuesta horas detectando errores. Tipar convierte errores de tiempo de ejecución en errores de tiempo de compilación.

  • Autocompletado real: el editor te sugiere propiedades válidas de cada variable.
  • Documentación viva: el tipo describe lo que la función espera y devuelve.
  • Refactor seguro: al renombrar, el compilador avisa de cada uso roto.
Cuidado: en JS puro un error como usuario.correo.toLowerCase() solo explota en la consola cuando el usuario ya está en la página. TypeScript lo detiene en tu terminal, a cero coste para el visitante.

Tu primer proyecto con tsc

TypeScript se instala con npm y su compilador se llama tsc. El primer paso genera el archivo de configuración del proyecto:

# crea tsconfig.json con las opciones recomendadas
$ npx tsc --init

# compila todos los archivos .ts una vez
$ npx tsc

# compila y se queda vigilando los cambios
$ npx tsc --watch
Cómo funciona el flujo

Escribes app.ts, el compilador tsc valida los tipos y genera app.js. Ese JavaScript generado es el que carga tu página. Puedes borrar los tipos y el JS sigue siendo idéntico en comportamiento.

Anotaciones

La anotación va después del nombre con dos puntos y antes del valor. Es opcional: si no la escribes, TypeScript infiere el tipo a partir del valor inicial.

// Anotación explícita: tú decides el tipo
let edad: number = 28;

// Inferencia: TypeScript deduce que es string
let ciudad = "Lima";
// ciudad = 42;  Error: string no admite number
Tip: para variables simples, deja que TypeScript infiera. Usa anotaciones explícitas cuando el valor inicial no deje claro el tipo (por ejemplo, una variable que luego tendrá otro valor).

Repaso rápido

  • TypeScript es un superset tipado: el navegador recibe JS, tu editor valida tipos.
  • npx tsc --init crea tsconfig.json y npx tsc compila.
  • Primitivos: number, string y boolean con anotaciones como let edad: number.
  • Si no anotas, TypeScript infiere el tipo desde el valor inicial.
