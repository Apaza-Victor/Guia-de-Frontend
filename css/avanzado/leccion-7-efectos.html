Efectos modernos: glassmorphism y neumorphism

Vidrio esmerilado, botones blandos y gradientes vivos: el repertorio estético de las interfaces actuales.

¿Qué es el glassmorphism?

El glassmorphism ("efecto cristal") simula un panel de vidrio esmerilado sobre un fondo colorido. Sus ingredientes: un fondo translúcido (baja opacidad), un borde claro (1px blanquecino) y backdrop-filter con blur() y algo de saturate() para que coloree lo que hay detrás. 

.tarjeta-vidrio {
  background: rgba(255, 255, 255, 0.12);      /* traslúcido */
  border: 1px solid rgba(255, 255, 255, 0.22);
  backdrop-filter: blur(14px) saturate(160%);
  -webkit-backdrop-filter: blur(14px) saturate(160%);
  border-radius: 1rem;
  box-shadow: 0 8px 24px rgba(2, 6, 23, 0.35);
}
PiezaTrucoFunción visual
Fondorgba(255,255,255,.1)Base etérea del cristal
Borde1px claro con poca opacidadDescribe el "canto" del vidrio
blur(Npx)Desenfoque del fondo que pasa detrásEl efecto esmerilado
saturate(%)Sube la viveza de los coloresEvita que se vea gris/con agua
box-shadowSombra suave y cercanaDespega el panel del fondo
Tip: Repite -webkit-backdrop-filter: los navegadores WebKit (Safari y Chrome antiguos) necesitan el prefijo. Y recuerda que backdrop-filter solo se nota si hay algo detrás: usa fondos coloridos.

Neumorphism: sombras suaves en relieve

El neumorphism ("neumorfismo") juega con dos sombras opuestas: una oscura abajo a la derecha y una clara arriba a la izquierda. Simula un material blando hundido o sobresaliendo de su fondo. 

/* Fondo y objeto deben compartir el mismo color base */
.boton-blando {
  background: #eceef4;                     /* mismo tono que el fondo */
  border-radius: 1rem;
  box-shadow:
    9px 9px 22px rgba(174, 181, 199, 0.7),   /* sombra "abajo" */
    -9px -9px 22px rgba(255, 255, 255, 0.95); /* luz "arriba" */
}

/* :active invierte las direcciones → el botón se "hunde" */
.boton-blando:active {
  box-shadow:
    inset 9px 9px 22px rgba(174, 181, 199, 0.7),
    inset -9px -9px 22px rgba(255, 255, 255, 0.95);
}
Ojo: Usa el neumorphism con moderación: sobre fondos oscuros o con mucha densidad deja poco contraste. Es un efecto "de superficie" que combina mejor en pequeños controles que en bloques de texto grande.

Gradientes avanzados y filtros

Un gradiente puede llevar varios stops, indicar dirección y combinarse con la propiedad filter: hue-rotate() para "barajar" la paleta sin reescribir colores. La función filter también ofrece brightness(), grayscale() y invert(), entre otras. 

/* Gradiente con varios stops y dirección oblicua */
background: linear-gradient(135deg, #1e3a8a, #2563eb 40%, #ea580c 70%, #0e7490);

/* Rotación de fase: cambia todo el rango cromático */
.fondo-vivo { filter: hue-rotate(90deg); }

/* Filtros combinados: escala de grises que se "enciende" al hover */
.foto { filter: grayscale(1) brightness(0.95); }
.foto:hover { filter: grayscale(0) brightness(1.05); }
FunciónEfectoTruco rápido
hue-rotate(deg)Gira el tono de todos los coloresUn "tema" de color sin editar stops
blur(px)Desenfoca el elementoFondo de modal "soft"
grayscale(n)Desatura a escala de grisesEstado inactivo o filtro en hover

Repaso rápido

  • Glassmorphism = fondo traslúcido + borde claro + backdrop-filter: blur() saturate().
  • Neumorphism = dos sombras opuestas (oscura + clara) sobre un fondo del mismo tono; inset para "hundir".
  • filter ofrece hue-rotate(), grayscale(), brightness()…" sobre cualquier elemento.
  • Usa estos efectos para destacar, no como fondo por defecto: el contraste y la legibilidad mandan.
