Keyframes y animaciones

Pasa de las transiciones a las @keyframes: animaciones en bucle, con etapas, steps() y librerías como AOS y GSAP.

¿Qué es una animación CSS?

Las animaciones CSS describen keyframes: una secuencia de estados intermedios que el navegador calcula automáticamente en el tiempo. A diferencia de transition, no necesitan un cambio de estado para iniciarse: pueden repetirse (infinite), ir y volver, o reproducirse al cargar la página. 

/* 1. Definir los keyframes */
@keyframes aparecer {
  0%   { opacity: 0; transform: translateY(20px); }
  100% { opacity: 1; transform: translateY(0); }
}

/* 2. Aplicarla a un elemento */
.hero-titulo {
  animation: aparecer 1s ease-out both;
}

Los keyframes se declaran con porcentajes (0% → 100%) o con los atajos from y to. Cada cuadro indica los valores que tomarán las propiedades.

El shorthand animation y sus propiedades

/* Orden típico: name duration timing-function delay iteration direction fill-mode */
.cargador {
  animation: girar 0.8s linear 0s infinite normal;
}

/* Equivalente con sub-propiedades por separado */
.cargador {
  animation-name: girar;
  animation-duration: 0.8s;
  animation-timing-function: linear;
  animation-delay: 0s;
  animation-iteration-count: infinite;
  animation-direction: normal;
}
PropiedadQué controlaValores clave
animation-nameQué @keyframes se usaNombre definido por ti
animation-durationDuración de un ciclo2s, 500ms
animation-iteration-countCuántos ciclos3, infinite
animation-directionSentido de reproducciónnormal, reverse, alternate
animation-timing-functionCurva dentro de cada cicloease, linear, steps(6)
animation-fill-modeEstado antes/despuésnone, forwards, both

steps() y timing por fotogramas

Mientras cubic-bezier interpola de forma continua, steps(n) avanza a saltos discretos: ideal para animaciones de sprites o contadores "de números". Con animation-timing-function: steps(m) entre cada keyframe rompes la suavidad en m escalones. 

/* Efecto de números: avanza en 10 saltos bruscos */
@keyframes contar {
  from { content: "0"; }
  to   { content: "100"; }
}
.contador {
  animation: contar 3s steps(10) both;
}
FunciónComportamientoCuándo usarla
ease / linearInterpolación continuaMovimiento orgánico y suave
steps(n)n saltos discretosSprites, slot machines, contadores
steps(n, jump-end)Salto al final de cada escalónAfinar el momento del "clic"

Librerías: AOS y GSAP

Para animaciones de scroll y escenas más complejas, las librerías aceleran muchísimo el desarrollo:

  • AOS (Animate On Scroll) activa animaciones al entrar en pantalla con solo un atributo: data-aos="fade-up". Ya lo usas en esta guía: cada sección aparece con AOS.
  • GSAP es una librería de animación profesional basada en JavaScript. Anima cualquier propiedad con curvas muy expresivas y no depende de los keyframes del CSS. 
<!-- AOS: un atributo y listo —>
<div data-aos="fade-up" data-aos-delay="200">contenido</div>

// GSAP: poder total desde JS
gsap.to(".logo", {
  y: -20,
  rotation: 360,
  duration: 1,
  ease: "elastic.out(1, 0.4)",
  repeat: 2, yoyo: true
});
Tip: Los dos enfoques conviven: CSS para lo simple y reproducible (pulse, hover), GSAP para lo complejo (líneas de tiempo, encadenados, elements scrubbing con scroll). Elige según la complejidad de la escena.

Demo interactiva: CSS y GSAP a la vez

La pelota salta por keyframes de CSS (bucle infinito). Pulsa el botón y GSAP añadirá su propia rotación, desplazamiento y escala a la misma pelota: ambos motores animan el mismo elemento simultáneamente. El botón "latido" usa también una animación CSS infinita.

El rebote vertical es @keyframes saltar (CSS); el giro y el desplazamiento lateral vienen de gsap.to(). Idéntica pelota, dos motores.

Repaso rápido

  • Define con @keyframes + porcentajes y aplica con animation (shorthand).
  • Controla repetición (infinite), dirección (alternate) y forma de avance (steps()).
  • Usa animation-fill-mode: both para evitar saltos antes y después de la animación.
  • AOS para scroll, GSAP para escenas complejas: conviven sin conflictos con las animaciones CSS.
