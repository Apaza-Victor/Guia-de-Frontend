Transformaciones y cubos 3D

Mueve, gira, escala e inclina elementos con transform y dales profundidad real con perspectiva y cubos en CSS 3D.

Fundamentos de la lección

La propiedad transform es la herramienta de movimiento del CSS: permite desplazar, rotar, escalar e inclinar cualquier elemento sin sacarlo del flujo del documento. En CSS Avanzado la llevamos al límite combinándola con perspectiva y preserve-3d para construir escenas tridimensionales reales — como el cubo de la demo.

La propiedad transform

transform modifica el sistema de coordenadas del elemento donde se aplica. A diferencia de margin o top, no ocupa espacio nuevo ni provoca recálculos de layout: el elemento se transforma visualmente y el resto de la página ni se entera. Se pueden combinar varias funciones separadas por espacios y se aplican de derecha a izquierda. 

transform: translate(24px, -8px)   /* mover en X e Y */
           scale(1.1)            /* agrandar o encoger */
           rotate(45deg)          /* girar en grados */
           skew(10deg, 5deg);    /* inclinar oblicuamente */
FunciónSintaxisEjemplo de uso
translate()translate(x, y)Desplazar una tarjeta al hacer hover
scale()scale(factor)Zoom de imágenes o botones
rotate()rotate(deg)Girar iconos o badges
skew()skew(x, y)Efectos "distorsionados" o de flecha

También existen versiones por eje: translateX(), translateY(), scaleX(), scaleY(), rotateX(), rotateY() o rotateZ(). Las funciones de rotación 3D como rotateX() y rotateY() solo lucen tridimensionales si su contenedor tiene perspectiva (lo verás en la sección 5).

Tip: transform se anima por GPU. Si vas a animar algo, "transform + opacity" es la combinación más barata y suave que existe en CSS.

translate, rotate, scale y skew en detalle

Cada función tiene sus particularidades. En translate() puedes usar cualquier unidad (px, rem, %); el porcentaje se calcula sobre el tamaño del propio elemento. En scale() un factor menor que 1 encoge y mayor que 1 agranda. rotate() acepta grados (deg) o vueltas (turn), y skew() inclina los ejes sobre los que se dibuja el elemento. 

/* translate: los % son sobre el propio elemento */
.avatar { transform: translate(-50%, -50%); } /* centra un absoluto */

/* scale + rotate combinados sobre un icono */
.icono:hover {
  transform: scale(1.25) rotate(8deg);
}

/* skew: inclina la geometría, no el texto si lo compensas */
.etiqueta { transform: skew(-8deg); }
.etiqueta span { display: inline-block; transform: skew(8deg); } /* contrainclina el texto */

rotate(deg)Gira alrededor del origenrotate(-90deg)

transform-origin: el punto pivote

Por defecto toda transformación se produce desde el centro del elemento. La propiedad transform-origin cambia ese punto pivote: puedes hacer que una puerta gire por su bisagra (lateral), que una carta gire desde una esquina o que un zoom crezca desde la parte superior. 

/* Valores por palabras clave, porcentajes o medidas */
.puerta   { transform-origin: left center; }     /* bisagra a la izquierda */
.carta   { transform-origin: bottom right; }  /* gira por la esquina */
.card    { transform-origin: 50% 0%; }       /* todo en números */

/* Útil: reverse de un elemento que "sale" desde arriba */
.desplegable { transform-origin: top center; transform: scaleY(0); }
.desplegable.abierto { transform: scaleY(1); }
Tip: en 3D, transform-origin puede recibir un tercer valor Z (p. ej. center center 40px): mueve el punto pivote hacia ti o hacia el fondo de la escena.

Perspectiva: el tercer eje

Para que rotateY(), rotateX() o translateZ() luzcan tridimensionales, el contenedor padre necesita una perspectiva: perspective: valor simula la distancia entre el observador y la escena. Cuanto menor el número, más dramático y "de cerca" se ve el efecto; valores entre 600px y 1200px son los más naturales. 

/* Contenedor padre: da profundidad a la escena */
.escena {
  perspective: 800px;
  perspective-origin: 50% 50%;
}

/* Hijo: rota en el eje Y con transición suave */
.carta {
  transform: rotateY(0deg);
  transition: transform 0.8s ease;
}
.carta:hover { transform: rotateY(45deg); }
PropiedadSe declara enQué controla
perspectiveEl padreLa "distancia al ojo" de toda la escena
perspective-originEl padreDesde dónde se mira (como la cámara)
perspective()El propio hijoPerspectiva individual dentro de transform
Ojo: perspective sobre el padre aplica a todos los hijos directos con su propia escena compartida. Si quieres que cada hijo tenga su propio punto de fuga, usa la función perspective() dentro del transform de cada uno.

transform-style: preserve-3d y backface-visibility

Por defecto, el CSS "aplana" las transformaciones 3D de los hijos (transform-style: flat). Para construir objetos con caras — como un cubo — el padre debe conservar el espacio 3D con transform-style: preserve-3d. Y con backface-visibility: hidden ocultas la cara trasera de cada plano, evitando que se vean las caras "de dentro hacia fuera". 

.cubo-wrap { transform-style: preserve-3d; }

.cara {
  backface-visibility: hidden;
  -webkit-backface-visibility: hidden; /* Safari / Chrome antiguos */
}

/* Cara "trasera" de un flip (ver lección 2) */
.cara-trasera { transform: rotateY(180deg); }
Tip: preserve-3d se rompe si el padre (o cualquier ancestro intermedio) usa overflow distinto de visible, filter u opacity con valor medio. Mantén esos ancestros "puros" para que la profundidad se conserve.

Ejemplo completo: un cubo en CSS puro

Un cubo son 6 planos (.cara) girados y desplazados 80px sobre un cubo de 160px (width / height / 2 = 80px de translateZ). La escena aporta la perspectiva y preserve-3d mantiene unidas las caras en el espacio. 

/* Contenedor con perspectiva y espacio 3D conservado */
.escena {
  perspective: 700px;
  perspective-origin: 50% 50%;
}
.cubo {
  position: relative;
  width: 160px; height: 160px;
  transform-style: preserve-3d;
}
.cubo .cara {
  position: absolute;
  inset: 0;
  backface-visibility: hidden;
}

/* 6 caras: siempre se "empujan" 80px hacia su lado */
.cubo .frontal    { transform: translateZ(80px); }
.cubo .trasera    { transform: rotateY(180deg) translateZ(80px); }
.cubo .derecha    { transform: rotateY(90deg) translateZ(80px); }
.cubo .izquierda  { transform: rotateY(-90deg) translateZ(80px); }
.cubo .superior   { transform: rotateX(90deg) translateZ(80px); }
.cubo .inferior   { transform: rotateX(-90deg) translateZ(80px); }

Leyendo la cara trasera: primero rotateY(180deg) voltea el plano y luego translateZ(80px) lo empuja —recordando que las transformaciones se aplican de derecha a izquierda, el empuje ocurre en el sistema ya girado, saliendo por la parte de atrás. Así se ensamblan todas las caras sin solaparse.

Repaso rápido

  • transform acepta translate, rotate, scale y skew, combinables y aplicados de derecha a izquierda.
  • transform-origin cambia el punto pivote de la transformación (bisagras, esquinas, centrado).
  • La perspectiva se declara en el padre (perspective, perspective-origin) y es la que da profundidad a las rotaciones 3D.
  • transform-style: preserve-3d + backface-visibility: hidden son la clave para construir cubos y escenas 3D reales.
