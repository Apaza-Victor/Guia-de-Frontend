Transiciones

Anima cambios de estado con transition: property, duration, timing-function, delay y curvas cubic-bezier.

¿Qué es una transición?

Una transición interpola suavemente el cambio entre dos estados de una propiedad CSS. Sin transición, al cambiar el estilo (hover, clase, JS) el navegador "salta"; con ella, el valor se anima progresivamente. Es ideal para micro-interacciones discretas y sutiles. 

/* Sin transición: el color cambia de golpe */
.boton       { background: #2563eb; }
.boton:hover { background: #0ea5e9; }

/* Con transición: 0.3s de interpolación suave */
.boton {
  background: #2563eb;
  transition: background 0.3s ease;
}

La transición se declara en el estado base del elemento; cuando la propiedad cambia (por hover, una clase o JS), el navegador interpola entre el valor inicial y el final durante la duración indicada.

Timing functions y cubic-bezier

La timing function define cómo avanza la interpolación en el tiempo. Las palabras clave (linear, ease, ease-in, ease-out, ease-in-out) son atajos de curvas Bézier cúbicas que puedes escribir a mano con cubic-bezier(x1, y1, x2, y2). 

/* Curva "bounce-ish": rápida al inicio, exagerada al final */
.card {
  transform: translateY(0);
  transition: transform 0.5s cubic-bezier(0.22, 1.4, 0.36, 1);
}
.card:hover {
  transform: translateY(-10px);
}
FunciónComportamientoEquivalente cubic-bezier
linearVelocidad constante0.00, 0.00, 1.00, 1.00
easeSuave al inicio y al final0.25, 0.10, 0.25, 1.00
ease-inLento → rápido0.42, 0.00, 1.00, 1.00
ease-outRápido → lento0.00, 0.00, 0.58, 1.00
ease-in-outLento → rápido → lento0.42, 0.00, 0.58, 1.00
Tip: Anima preferentemente transform y opacity. Son las propiedades más baratas para el navegador (se aceleran por GPU), mientras que width, margin o top disparan recálculos de layout más costosos.

Qué se puede (y no se puede) transicionar

No todas las propiedades son interpolables de la misma manera. Las numéricas y de color (dimensiones, posiciones, fondos, filter) se animan sin problema; otras como display saltan de estado, por eso conviene animar opacity o transform y alternar display con visibility. 

/* Transicionar múltiples propiedades a la vez */
.modal {
  opacity: 0;
  visibility: hidden;
  transition: opacity 0.4s ease, visibility 0.4s;
}
.modal.abierto {
  opacity: 1;
  visibility: visible;
}
Recordatorio: Aunque transition se combina naturalmente con transform en hover, transition no sirve para animaciones en bucle o con varias etapas: para eso existen las @keyframes, que verás en la lección 4.

Repaso rápido

  • transition interpola entre dos estados cuando una propiedad cambia (hover, clase o JS).
  • Controla la curva con cubic-bezier(x1, y1, x2, y2) o con las palabras clave predefinidas.
  • Anima transform y opacity y la página se mantendrá a 60 fps sin esfuerzo.
  • Para bucles y animaciones con etapas, usa @keyframes (lección 4), no transition.
