Variables y custom properties

Centraliza tus valores, crea temas dinámicos y personaliza Bootstrap con variables CSS nativas.

¿Qué son las custom properties?

Las custom properties (o "variables de CSS") permiten guardar un valor con nombre y reutilizarlo en todo el documento. Son la evolución natural de repetir a mano colores, espaciados o fuentes. Se definen con --nombre y se consumen con la función var(). 

/* Definición: la convención manda declararlas en :root */
:root {
  --color-primario: #2563eb;
  --radio: 0.75rem;
  --duracion: 0.3s;
}

/* Consumo: var() sustituye el valor donde se necesite */
.boton {
  background: var(--color-primario);
  border-radius: var(--radio);
  transition: transform var(--duracion);
}

A diferencia de variables de preprocesadores como Sass, las custom properties son dinámicas: se resuelven en tiempo de renderizado, se heredan y se pueden cambiar con JavaScript sin recompilar nada.

Scope y herencia de variables

El valor de una custom property se aplica al elemento donde se define y a todos sus descendientes. Si declaras una variable en :root estará disponible en todo el documento; si la declaras en un componente, solo dentro de ese subárbol. 

/* Variable global */
:root   { --radio: 0.5rem; }

/* Override local: .panel y sus hijos ven 1rem */
.panel { --radio: 1rem; }

.panel-hijo {
  border-radius: var(--radio); /* 1rem */
}
Tip: Crea un "sistema de tokens" en :root con nombres semánticos (--color-peligro, --espacio-md) en lugar de nombres descriptivos del valor (--rojo-500, --16px). Así cambiar de tema es aislar el cambio en un solo lugar.
Ojo: Las custom properties funcionan en todas las propiedades CSS, pero var() no se puede usar dentro de media queries como nombre de consulta (sí dentro de los valores). Para condicionar valores, redefine la variable dentro del @media.

Sobreescribir con media queries y atributos

Como las variables se resuelven en tiempo de ejecución, puedes redefinirlas según el contexto: un @media, una clase de utilidad o un atributo en el <html>. Este último truco es el motor de casi todos los sistemas de temas dark/light. 

:root { --fondo: #fff; --texto: #0f172a; }

/* Tema oscuro activado por el atributo data-theme */
:root[data-theme="dark"] {
  --fondo: #0f172a;
  --texto: #e2e8f0;
}

/* Desde JS: document.documentElement.setAttribute('data-theme', 'dark') */

Cómo se personaliza Bootstrap con variables

Bootstrap 5 usa su propio conjunto de variables CSS con prefijo --bs-. Sobrescribirlas en tu style.css (o en un bloque propio) cambia colores, radios y sombras sin tocar el CSS del framework. 

/* Sobrescritura de tokens de Bootstrap 5 */
:root {
  --bs-primary: #2563eb;
  --bs-primary-rgb: 124, 58, 237;
  --bs-border-radius: 1rem;
  --bs-body-bg: #ffffff;
}

/* Cambios condicionales por breakpoint sin recurrencias */
@media (min-width: 992px) {
  :root { --bs-border-radius: 1.5rem; }
}

Tip: Para personalizar colores de forma sostenible, define tus propios tokens (--fp-color-primario) y luego asigna --bs-primary: var(--fp-color-primario). Un solo cambio propaga todo.

Repaso rápido

  • Las custom properties se declaran con --nombre y se leen con var(--nombre, fallback).
  • Definidas en :root son globales; en un selector, su alcance es local y heredable.
  • Con :root[data-theme="dark"] + setAttribute() creas temas swap-instantáneo con un solo atributo.
  • Bootstrap 5 se personaliza sobrescribiendo sus variables --bs-* en :root.
