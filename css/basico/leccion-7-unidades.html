Unidades de medida

Domina px, em, rem, %, vw/vh, vmin/vmax y la función clamp() para crear diseños fluidos que respiran en cualquier pantalla.

Fundamentos de la lección

Las unidades se dividen en absolutas (tamaño fijo) y relativas (calculadas respecto a otra medida). Un diseño fluido mezcla ambas: tamaños relativos para lo que debe crecer y px para detalles finos.

px rem vw / vh

px y %: fijo vs proporcional

El píxel (px) es la única unidad absoluta de uso común: 1px no cambia según el contexto. El porcentaje (%) se calcula contra el contenedor padre: para width, contra el ancho del padre; para font-size, contra su tamaño de fuente. 

.tarjeta {
  width: 400px;      /* fija: no escala en pantallas pequeñas */
  border-radius: 8px;
}

.lateral {
  width: 50%;       /* la mitad del contenedor, siempre */
  padding: 2%;      /* proporcional, nunca parte del ancho total */
}
Tip: Para elementos que deben adaptarse, empieza por % o em/rem. Reserva el px para bordes, sombras y dimensiones de detalles que no deberían cambiar.

em vs rem: la diferencia exacta

El em se calcula respecto a la fuente del padre más cercano, así que su valor se multiplica con cada nivel de anidamiento. El rem ignora a los padres y siempre se calcula respecto a la raíz <html>. Ejemplo con fuente raíz de 16px: 

/* html { font-size: 16px; } */
<div style="font-size: 20px;">
  <p>Con em</p>   <!-- 1em = 20px (padre) -->
  <p>Con rem</p>  <!-- 1rem = 16px (raíz) -->
</div>
Contextoem → resultadorem → resultado
Fuente raíz 16px, padre 20px1em = 20px1rem = 16px
Doble anidamiento (padre 20px, luego +25px)1em se multiplica1rem siempre 16px
Consejo práctico: Usa rem para tipografía y márgenes globales (predecible y fácil de escalar cambiando html). Reserva el em para lo que debe crecer junto a su propio texto, como el padding de un botón.

Unidades de viewport: vw, vh, vmin, vmax

El viewport es el área visible de la ventana. Estas unidades se calculan contra él y nunca contra un padre:

UnidadRelativa aUso típico
vw1% del ancho del viewportTipografía fluida, secciones a lo ancho
vh1% del alto del viewportHero a pantalla completa: min-height: 100vh
vmin1% de la dimensión más pequeñaElementos cuadrados que no se desbordan
vmax1% de la dimensión más grandeDetalles que deben destacar en el modo horizontal
 
.hero {
  min-height: 100vh;          /* ocupa toda la pantalla */
  font-size: 6vw;             /* crece y decrece con la ventana */
}

.cuadro {
  width: 90vmin;              /* nunca mayor que el lado corto */
  height: 90vmin;
}
Cuidado: Un font-size únicamente en vw puede volverse ilegible en móviles o desbordarse en pantallas gigantes. La solución es clamp(), que verás a continuación.

clamp(): tipografía fluida con límites

clamp() recibe tres valores —mínimo, preferido, máximo— y elige el del medio cuando el preferido sale de rango. Es perfecto para tamaños fluidos: crecen con el viewport pero se congelan entre dos extremos. 

.titulo-hero {
  font-size: clamp(1.5rem, 4vw + 1rem, 4rem);
  /* nunca menor que 1.5rem ni mayor que 4rem */
}

.contenedor {
  width: clamp(280px, 100% - 2rem, 1200px);
}
Dato: Combina vw con un valor fijo dentro del cálculo (como 4vw + 1rem) para que el texto nunca se petrifique: en pantallas pequeñas el 1rem garantiza legibilidad mínima.

Repaso rápido

  • px es absoluta; %, em, rem y las de viewport son relativas.
  • em depende del padre; rem depende de la raíz: para tipografía global usa rem.
  • vw/vh responden al viewport; vmin/vmax al lado corto/largo.
  • % se calcula contra el contenedor padre (ancho para width, fuente para font-size).
  • clamp(mín, preferido, máx) crea tamaños fluidos con límites seguros.
