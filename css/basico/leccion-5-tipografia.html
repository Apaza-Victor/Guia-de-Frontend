Tipografía y colores

Dale personalidad a tu texto y domina los modelos de color del navegador.

Propiedades de tipografía

La tipografía es la base visual de cualquier interfaz. Estas son las propiedades esenciales:

body {
  font-family: "Inter", system-ui, sans-serif;
  font-size: 1rem;
  font-weight: 400;
  line-height: 1.6;
  letter-spacing: 0.01em;
}

.titulo {
  text-align: center;
  text-decoration: none;
}
PropiedadQué controlaValores comunes
font-familyLa fuente tipográfica"Poppins", sans-serif
font-sizeEl tamaño del texto16px, 1rem, 1.5rem
font-weightEl grosor (400 normal, 700 negrita)400, 600, 700
line-heightAltura de línea e interlineado1.6, 1.2
letter-spacingEspaciado entre caracteresnormal, 0.05em
text-alignAlineación del bloque de textoleft, center, right
text-decorationSubrayado, tachado o ningunanone, underline
Tip: El line-height sin unidad (como 1.6) se calcula de forma relativa al tamaño de fuente y se hereda correctamente en texto anidado. Es la práctica recomendada.

Google Fonts: Inter y Poppins

Google Fonts es un servicio gratuito que sirve tipografías web. Esta guía usa Inter para el cuerpo y Poppins para los encabezados: 

<!-- Paso 1: importar en el <head> del HTML -->
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&family=Poppins:wght@600;700;800&display=swap" rel="stylesheet">

/* Paso 2: aplicar en CSS */
body {
  font-family: "Inter", sans-serif;
}
h1, h2, h3, h4, h5, h6 {
  font-family: "Poppins", sans-serif;
}
Nota: Cuando uses varias fuentes, prioriza el uso de dos familias como máximo para mantener una identidad visual coherente. Una para títulos y otra para el cuerpo de texto.

Colores: HEX, RGB y HSL

CSS ofrece tres modelos principales para definir colores, cada uno con sus ventajas:

/* HEX: valores hexadecimales #RRGGBB — el más común en diseño */
.hex {
  color: #2563eb;       /* violeta */
  background-color: #0f172a; /* azul noche */
}

/* RGB / RGBA: mezcla de rojo, verde y azul + canal alfa (opacidad del color) */
.rgb {
  color: rgb(37, 99, 235);
  background-color: rgba(37, 99, 235, 0.2);
}

/* HSL: matiz (0-360º), saturación (%) y luminosidad (%) — intuitivo para paletas */
.hsl {
  color: hsl(239, 84%, 67%);
}
ModeloSintaxisCuándo usarlo
HEX#RRGGBBDiseño gráfico y paletas copiadas de herramientas
RGBrgb(r, g, b)Cálculo programático de colores
HSLhsl(h, s%, l%)Ajustar tono o luminosidad de forma intuitiva
Tip: Si un valor excede 50% de luminosidad en HSL, es un color claro; por debajo, un color oscuro. Varía solo el último parámetro para crear toda una paleta de un mismo color.

Opacity y transparencia

opacity ajusta la transparencia de todo el elemento (fondo, texto y bordes). Va de 0 (invisible) a 1 (opaco). No confundir con rgba(), que solo afecta al color sobre el que se aplica. 

.boton-deshabilitado {
  opacity: 0.5;          /* todo el botón se vuelve semitransparente */
  cursor: not-allowed;
}

/* Contraste: usa rgba para fondos translúcidos sin cambiar la opacidad del texto */
.tarjeta {
  background-color: rgba(37, 99, 235, 0.15);
}

Repaso rápido

  • Tipografía: font-family, font-size, font-weight, line-height y letter-spacing.
  • Enlaza Google Fonts con <link> y usa font-family para aplicarla.
  • Colores: #hex, rgb() y hsl(); añade a (alfa) para transparencia del color.
  • opacity transparenta todo el elemento; rgb(..., a) solo el color.
  • Elige dos fuentes máximo: una para títulos y otra para el cuerpo.
