Modelo de caja

Todo en CSS es una caja: aprende a controlar su contenido, relleno, borde y margen.

¿De qué está hecha una caja?

Cada elemento en una página web se representa como una caja rectangular. El modelo de caja describe sus cuatro capas desde dentro hacia fuera:

  1. Content (contenido): el texto o imagen real del elemento.
  2. Padding (relleno): espacio interno entre el contenido y el borde. Afecta al fondo visible.
  3. Border (borde): línea que rodea al padding.
  4. Margin (margen): espacio externo que separa la caja de sus vecinos. Es transparente.

Padding, border y margin

Cada una de estas propiedades acepta de 1 a 4 valores, siempre en el orden arriba, derecha, abajo, izquierda (sentido horario).

.caja {
  padding: 10px 20px 30px 40px; /* arriba | derecha | abajo | izquierda */
  border: 3px solid #2563eb;       /* ancho estilo color */
  margin: 0 auto 1.5rem;          /* arriba | lados | abajo */
}
/* Cada lado por separado */
.caja {
  padding-top: 10px;
  margin-bottom: 1.5rem;
  border-left: 4px solid #06b6d4;
}

/* Los dos márgenes verticales colapsan: gana el mayor — usa margin: 0 auto para centrar */
.centrado {
  width: 300px;
  margin: 0 auto;
}
PropiedadQué controla¿Pintado con fondo?
paddingEspacio internoSí
borderLínea exteriorSí (el color del borde)
marginEspacio externoNo (transparente)
Tip: Los márgenes verticales de elementos adyacentes colapsan: en lugar de sumarse, se usa el mayor de los dos. Los padding y border, por el contrario, siempre se suman.

box-sizing: border-box vs content-box

La propiedad box-sizing decide cómo se calcula el ancho/alto total del elemento.

  • content-box (valor por defecto): el width se aplica solo al contenido; padding y border se añaden al tamaño total.
  • border-box: el width ya incluye content + padding + border. El tamaño declarado es el tamaño final.
/* Reseteo global: casi todos los frameworks lo usan */
*, *::before, *::after {
  box-sizing: border-box;
}

.ejemplo {
  width: 200px;
  padding: 25px;
  border: 5px solid #2563eb;
}
box-sizingAncho total del ejemplo
content-box200 + 25 + 25 + 5 + 5 = 260px
border-boxFijo en 200px (el contenido se comprime a 140px)

border-radius y outline

/* Esquinas redondeadas */
.pill {
  border-radius: 999px;  /* cápsula perfecta */
}

.circulo {
  width: 80px;
  height: 80px;
  border-radius: 50%; /* círculo */
}

/* Outline: contorno FUERA del borde, no ocupa espacio y no afecta al layout */
.focus-ring:focus {
  outline: 3px solid #06b6d4;
  outline-offset: 2px;
}
Diferencia clave: outline no está dentro del modelo de caja: no suma tamaño ni puede redondearse con border-radius. Se usa sobre todo para indicar el foco de teclado sin deformar el layout.

Cajas en línea vs bloque

La propiedad display cambia el comportamiento básico de una caja:

displayComportamientoEjemplos
blockOcupa todo el ancho disponible y fuerza un salto de línea<div>, <p>, <h1>
inlineFluye junto al texto, ignoran width/height y margin vertical<span>, <a>, <strong>
inline-blockMezcla: fluye en línea pero respeta width, height y márgenesBotones, etiquetas
 
.nav a {
  display: inline-block;
  padding: 8px 16px;
  margin: 0 4px;
}

Repaso rápido

  • La caja se compone de content → padding → border → margin.
  • Con box-sizing: border-box, el width declarado es el tamaño final (recomendado).
  • border-radius redondea esquinas; outline es un contorno externo que no ocupa espacio.
  • block ocupa la línea completa; inline fluye con el texto; inline-block combina ambos.
