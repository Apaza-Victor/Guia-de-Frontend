Selectores

Elige elementos con precisión: etiqueta, clase, id, atributo, combinadores y pseudo-clases para apuntar exactamente a lo que quieres estilizar.

¿Qué es un selector?

Un selector es el patrón que usa CSS para decidir sobre qué elementos aplicar cada regla. Es la primera parte de cualquier regla CSS y determina su alcance. 

/* Sintaxis de una regla CSS */
selector {
  property: value;
}

Cuanto más preciso sea tu selector, más control tendrás sobre tu diseño. Veamos los tipos principales.

Selectores de etiqueta, clase, id y atributo

Etiqueta (elemento)

Selecciona todas las etiquetas de un tipo concreto. Tienen la especificidad más baja: 1 punto.

p {
  color: #334155;
}
h1, h2, h3 {
  font-family: "Poppins", sans-serif;
}

Clase (.nombre)

Selecciona todos los elementos con una clase determinada. Es el selector más usado: especificidad 10.

<!-- HTML -->
<button class="btn-primario">Click</button>

/* CSS */
.btn-primario {
  background-color: #2563eb;
  color: #ffffff;
}

ID (#nombre)

Selecciona un único elemento por su atributo id, que debe ser único en la página. Especificidad 100.

<section id="hero">...</section>

#hero {
  min-height: 100vh;
}
Cuidado: Un id debe aparecer una sola vez por página. Para estilos reutilizables usa clases, no ids.

Atributo [atributo]

Selecciona elementos según su atributo HTML, con o sin valor concreto. Especificidad 10.

/* Elementos con el atributo, cualquiera que sea su valor */
[disabled] {
  opacity: 0.5;
}

/* Elementos cuyo href comienza por https:// */
a[href^="https://"] {
  color: #06b6d4;
}

Combinadores

Los combinadores unen varios selectores para focalizar relaciones entre elementos del documento.

/* Descendiente (espacio): TODOS los <span> dentro de .card */
.card span {
  font-weight: 600;
}

/* Hijo directo (>): solo los <li> que son hijos DIRECTOS de ul */
ul > li {
  margin-bottom: 8px;
}

/* Adyacente (+): solo el primer <p> que sigue inmediatamente a un h2 */
h2 + p {
  font-size: 1.1rem;
}

Pseudo-clases básicas

Las pseudo-clases seleccionan elementos según su estado o posición, no según su nombre o atributos. Se escriben con dos puntos :nombre. 

/* Estado de hover: cuando el ratón pasa por encima */
.btn:hover {
  transform: translateY(-2px);
  box-shadow: 0 8px 24px rgba(37, 99, 235, 0.4);
}

/* Primer hijo: el primer <li> de cada lista */
li:first-child {
  font-weight: 700;
}

/* Último hijo */
li:last-child {
  margin-bottom: 0;
}

Especificidad: cómo se calcula el peso

Cuando varias reglas apuntan al mismo elemento, el navegador calcula la especificidad sumando puntos: cada id vale 100, cada clase / atributo / pseudo-clase vale 10 y cada etiqueta / pseudo-elemento vale 1.

!important

La declaración !important rompe el cálculo normal y da prioridad absoluta a esa regla, sin importar la especificidad (salvo otro !important más específico). 

.titulo {
  color: #2563eb !important;
}

/* Aunque #hero tenga más especificidad, esta regla gana */
Advertencia: Evita !important en proyectos grandes. Dificulta el mantenimiento y hace que el CSS sea impredecible. Úsalo solo como último recurso o para sobreescribir estilos de librerías de terceros.
Continúa: en la lección 3 — Cascada y herencia verás la notación (0,0,1), la herencia de propiedades y el orden exacto en que el navegador elige la regla ganadora.

Repaso rápido

  • Etiqueta = 1 punto, clase/atributo = 10, id = 100, inline = 1000.
  • Combinadores: espacio (descendiente), > (hijo), + (adyacente), ~ (hermanos).
  • Pseudo-clases como :hover y :first-child seleccionan por estado o posición.
  • !important gana a todo, pero úsalo con moderación.
