Introducción a CSS

Qué es CSS, cómo se construye una regla, las tres formas de aplicarlo a tu HTML y cómo la cascada decide qué estilo gana.

Fundamentos de la lección

CSS (Cascading Style Sheets, Hojas de Estilo en Cascada) es el lenguaje encargado de la presentación de una web. Junto con HTML y JavaScript forma la tríada del frontend: HTML estructura el contenido, CSS lo hace atractivo y JavaScript lo hace interactivo. Aquí entenderás cómo CSS se conecta con tu HTML y por qué la palabra "cascada" describe con precisión cómo se resuelven los estilos.

Regla CSS CSS externo Cascada

¿Qué es CSS?

CSS es el lenguaje que se usa para presentar y decorar documentos HTML. Mientras HTML define la estructura, CSS controla colores, tipografías, espaciados, layout y animaciones.

Una analogía: si HTML son los cimientos y paredes de una casa, CSS es la pintura, los muebles y la decoración. Separar contenido de presentación permite cambiar el aspecto visual de un sitio completo editando un solo archivo.

Tip: CSS no es un lenguaje de programación, sino un lenguaje de declaración de estilos. No tiene bucles ni condicionales: solo reglas.

Las 3 formas de aplicar CSS

Existen tres métodos para vincular estilos CSS con tu HTML, cada uno con ventajas y desventajas distintas.

1. CSS Inline (en línea)

Se escribe directamente en el atributo style de una etiqueta HTML.

<h1 style="color: #2563eb; font-size: 2rem;">
  Título con estilo inline
</h1>
VentajasDesventajas
Útil para pruebas rápidasMezcla contenido con presentación
Sobreescribe cualquier otra reglaNo es reutilizable
No requiere archivos externosDifícil de mantener a escala

2. CSS Interno (en el <head>)

Se define dentro de una etiqueta <style> en el <head> del documento.

<head>
  <style>
    h1 {
      color: #2563eb;
      font-size: 2rem;
    }
  </style>
</head>
VentajasDesventajas
Agrupa reglas para toda la páginaSolo aplica a un solo archivo HTML
No necesita archivos externosNo es reutilizable entre páginas
Fácil de empezar en proyectos pequeñosEl HTML crece y se vuelve desordenado

3. CSS Externo (el recomendado)

Se escribe en un archivo .css separado y se vincula con <link>.

<!-- En el <head> del HTML -->
<link rel="stylesheet" href="estilos.css">
VentajasDesventajas
Reutilizable en múltiples páginasRequiere crear un archivo extra
Separación limpia de responsabilidadesNecesita una petición HTTP adicional (mitigable con caché)
El navegador almacena el archivo en caché—
Recomendación: usa siempre CSS externo en proyectos reales. Es el estándar de la industria.

Anatomía de una regla

Toda regla CSS tiene dos partes: un selector que elige los elementos y un bloque de declaraciones que describe el estilo. Cada declaración es una pareja propiedad: valor;.

h1 {                     /* selector */
  color: #2563eb;      /* propiedad: valor */
  font-size: 2.5rem;
  letter-spacing: 1px;
}
ParteDescripciónEjemplo
selectorIndica a qué elementos se aplicah1, .boton, #logo
bloqueAbre y cierra las declaraciones{ … }
propiedadEl aspecto que queremos cambiarcolor, margin
valorEl nuevo estado de la propiedad#2563eb, 1rem

La cascada en acción

El nombre "Cascading Style Sheets" no es casual: las reglas se resuelven mediante un sistema de prioridad. Cuando dos reglas aplican al mismo elemento, el navegador sigue este orden:

  1. Inline → mayor prioridad (excepto !important).
  2. Interno / Externo → mismo nivel; gana el que aparezca después en el código.
  3. Estilos del navegador → menor prioridad (defaults).

Repaso rápido

  • CSS es el lenguaje de presentación de la web: colores, layout, tipografía y más.
  • Hay 3 formas de aplicarlo: inline, interno y externo (recomendado).
  • Una regla = selector { propiedad: valor; }.
  • La cascada resuelve conflictos: inline gana sobre interno/externo; entre estos, gana el último en el código.
