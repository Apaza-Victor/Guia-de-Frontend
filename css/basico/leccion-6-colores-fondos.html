Colores, gradientes y fondos

Decora tus elementos con fondos de color e imágenes, y crea gradientes lineales y radiales sin una sola imagen.

Propiedades de fondo

CSS permite pintar los fondos de los elementos con colores, imágenes y gradientes:

.hero {
  background-color: #0f172a;
  background-image: url("fondos/hero.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

/* Atajo: color + imagen + posición + tamaño si va junto */
.resumen {
  background: url("logo.svg") no-repeat center / contain;
}
PropiedadDescripciónEjemplo
background-colorColor de relleno base#2563eb
background-imageImagen o gradiente de fondourl("img.png")
background-sizeDimensiona la imagen: cover rellena, contain ajusta completacover, 50%
background-positionDónde se ancla la imagencenter, top left, 50% 50%
background-repeatSi la imagen se repiteno-repeat, repeat-x
Tip: Siempre define un background-color además de la imagen: si esta no carga, el color actúa como respaldo visual.

Paleta de respaldo en acción

Los colores de las miniaturas se combinan en background: gradiente + color base.

indigo + cyan
noche + rosa
gradiente vívido

Gradientes lineal y radial

Los gradientes se generan con CSS puro, sin imágenes. La función lineal transita de un punto a otro; la radial, desde un centro hacia afuera.

/* Lineal: dirección + paradas de color */
.lineal {
  background: linear-gradient(135deg, #2563eb, #0ea5e9);
}

/* Radial: desde el centro hacia los bordes */
.radial {
  background: radial-gradient(circle, #06b6d4, #0f172a 70%);
}

/* Con más de dos paradas y posiciones concretas */
.multi {
  background: linear-gradient(90deg, #111827, #2563eb 50%, #f59e0b);
}

Variables CSS: estilos reutilizables

Para mantener paletas coherentes, define tus colores como variables CSS en :root y reutilízalas con var(). Cambiar la paleta del sitio se vuelve cuestión de editar un solo lugar. 

/* CSS personalizado en esta guía, listo para reutilizar */
:root {
  --color-primario: #2563eb;
  --color-acento: #06b6d4;
  --fuente-titulos: "Poppins", sans-serif;
}

.bandera {
  background: var(--color-primario);
  font-family: var(--fuente-titulos);
}
Dato: Los ejemplos anteriores —gradientes, variables CSS y unidades fluidas— son exactamente el tipo de técnicas que esta guía usa en su propia hoja de estilos personalizada.

De las medidas se encarga la lección 7

Detrás de todo buen fondo hay medidas fluidas: unidades como rem, vw, vh o % deciden si tu diseño respira en móvil y escritorio. Aquí las resumimos y en la lección 7 — Unidades de medida entraremos en el detalle completo, incluyendo vmin, vmax y clamp().

UnidadRelativa aUso típico
pxPíxel físico (absoluta)Bordes, sombras y detalles finos
emEl tamaño de fuente del elemento padrePadding y espacios locales al contenido
remEl tamaño de fuente de la raíz (<html>)Tipografía global
%El tamaño del contenedor padreAnchuras y alturas proporcionales
vh / vwEl alto / ancho de la ventana (viewport)Secciones a pantalla completa y héroes
Consejo práctico: Usa rem para tipografía y márgenes globales (fácil de escalar y predecible), y reserva el em para propiedades que deben crecer junto al texto del propio elemento, como el padding de un botón.

Repaso rápido

  • Fondos: background-color, background-image, background-size: cover y background-position.
  • Siempre define un background-color de respaldo junto a cualquier imagen o gradiente.
  • Gradientes con linear-gradient() y radial-gradient(), sin necesidad de imágenes.
  • Con variables CSS en :root reutilizas colores con var(--color).
  • Las unidades fluidas (rem, %, vh, vw) se dominan en la lección 7.
