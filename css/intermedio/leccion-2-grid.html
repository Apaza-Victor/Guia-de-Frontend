CSS Grid completo

El sistema de layout bidimensional: controla filas, columnas y áreas nombradas con precisión total.

¿Qué es CSS Grid?

CSS Grid Layout es un sistema de layout bidimensional: puede controlar tanto filas como columnas simultáneamente. A diferencia de Flexbox (un eje), Grid diseña la rejilla completa de una página. 

display: grid;

Los hijos directos del contenedor se convierten en grid items y se colocan en celdas de la rejilla.

Tip: Grid y Flexbox no compiten: Grid diseña la estructura macro (layout de página) y Flexbox alinea componentes internos.

Definiendo columnas y filas

/* Columnas fijas */
grid-template-columns: 200px 1fr 200px;

/* Repetir 3 columnas iguales */
grid-template-columns: repeat(3, 1fr);

/* Columnas que se adaptan al contenido */
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

/* Filas */
grid-template-rows: auto 1fr auto;

/* Espacio entre celdas */
gap: 16px;
FunciónEjemploResultado
repeat()repeat(4, 1fr)4 columnas de ancho igual
minmax()minmax(200px, 1fr)Mínimo 200px, máximo 1fr
auto-fitauto-fit, minmax(280px, 1fr)Crea tantas columnas como quepan
auto-fillauto-fill, minmax(280px, 1fr)Similar pero reserva espacio vacío
Diferencia clave: auto-fit colapsa las columnas vacías y estira las existentes. auto-fill mantiene el espacio reservado aunque esté vacío.

Grid-template-areas: layout con nombre

Una de las funcionalidades más poderosas de Grid es nombrar áreas para crear layouts legibles:

display: grid;
grid-template-areas:
  "header  header  header"
  "nav     main    aside"
  "footer  footer  footer";
grid-template-columns: 200px 1fr 200px;
grid-template-rows: auto 1fr auto;
gap: 12px;

/* Asignar áreas a cada elemento */
.header  { grid-area: header;  }
.nav     { grid-area: nav;     }
.main    { grid-area: main;    }
.aside   { grid-area: aside;   }
.footer  { grid-area: footer;  }
ÁreaPosición en la rejillaElemento típico
headerFila superior, 3 columnasCabecera / Navbar
navFila media, columna izquierdaNavegación lateral
mainFila media, columna centralContenido principal
asideFila media, columna derechaBarra lateral
footerFila inferior, 3 columnasPie de página

Alineación en Grid

Grid hereda justify-items y align-items de Flexbox, pero añade control por eje:

/* Alinear todos los items dentro de sus celdas */
justify-items: center;   /* eje horizontal */
align-items: center;     /* eje vertical */

/* Alinear toda la rejilla dentro de su contenedor */
justify-content: center;
align-content: center;

/* Alinear un item individual */
justify-self: end;
align-self: start;

Repaso rápido

  • display: grid activa el layout bidimensional.
  • grid-template-columns / rows define la estructura de la rejilla.
  • repeat(auto-fit, minmax(…, 1fr)) crea rejillas responsivas sin media queries.
  • grid-template-areas permite nombrar zonas para layouts legibles.
  • grid-area asigna un elemento a su zona nombrada.
  • justify-items / align-items alinean items dentro de sus celdas.
  • gap funciona igual que en Flexbox: espacio entre celdas sin márgenes negativos.
