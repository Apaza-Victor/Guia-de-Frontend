Posicionamiento y z-index

Domina cómo se sitúan los elementos en la página: relative, absolute, fixed, sticky y la superposición de capas.

Los 5 valores de position

La propiedad position determina cómo se sitúa un elemento respecto a su entorno:

ValorComportamientoSe desplaza con…
staticFlujo normal del documento (valor por defecto)No se desplaza
relativeSe desplaza desde su posición original, pero el espacio que ocupaba se reservatop / right / bottom / left
absoluteSe extrae del flujo normal y se posiciona respecto a su ancestro posicionado más cercanotop / right / bottom / left
fixedSe extrae del flujo y se fija a la ventana del navegadortop / right / bottom / left + scroll
stickySe comporta como relative hasta que cruza un umbral; luego se vuelve fixedtop / bottom + scroll
Concepto clave: Un hijo absolute se posiciona respecto al ancestro más cercano que tenga position: relative | absolute | fixed | sticky. Si no existe ningún ancestro posicionado, se posiciona respecto al <html>.

Contextos de posición: ancla de hijos absolute

Para que un hijo absolute se posicione dentro de su contenedor, el contenedor debe tener position: relative:

/* El padre es el "ancla" del hijo absolute */
.card {
  position: relative;  /* ancla */
}
.card__badge {
  position: absolute;
  top: -8px;
  right: -8px;
}
Tip: position: relative sin top/right/bottom/left no mueve el elemento — solo establece el contexto de posicionamiento para sus hijos.

z-index y stacking context

z-index controla la superposición de elementos posicionados. Un valor mayor significa que el elemento está "más arriba":

.layer-1 { z-index: 1;  }  /* detrás */
.layer-2 { z-index: 2;  }  /* encima de layer-1 */
.layer-3 { z-index: 3;  }  /* la más arriba */
Advertencia: z-index solo funciona en elementos con position distinto de static. Además, puede ser "atrapado" por un stacking context padre: si el padre tiene z-index o ciertas propiedades como opacity < 1, los hijos no pueden salirse de ese contexto.

overflow

overflow controla qué sucede cuando el contenido de un elemento excede sus límites:

overflow: visible;  /* se desborda (default) */
overflow: hidden;   /* se recorta */
overflow: auto;     /* scrollbar solo si es necesario */
overflow: scroll;   /* siempre muestra scrollbar */
ValorUso típico
visibleEl contenido se desborda fuera del contenedor
hiddenRecorta el contenido que se sale
autoAñade scroll solo cuando hace falta (el más usado)
scrollSiempre muestra barra de scroll, aunque no haga falta
clipSimilar a hidden pero más estricto (no permite scroll programático)

Repaso rápido

  • static es el valor por defecto; no se desplaza.
  • relative desplaza el elemento y establece contexto de posición para hijos.
  • absolute se posiciona respecto al ancestro posicionado más cercano.
  • fixed se fija a la ventana del navegador (no se mueve con el scroll).
  • sticky combina relative + fixed: se pega cuando cruza un umbral.
  • z-index solo funciona en elementos posicionados (no static).
  • overflow controla el desbordamiento del contenido (usa auto para scroll).
