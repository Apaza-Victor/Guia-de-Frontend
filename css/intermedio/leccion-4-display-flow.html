Display, flujo y centrado

Entiende cómo fluyen los elementos (block, inline, inline-block), domina el float clásico, el overflow y las técnicas de centrado horizontal y vertical.

Display y el flujo del documento

La propiedad display define cómo se comporta un elemento respecto a sus hermanos y a su contenedor. Controla si el elemento ocupa toda la línea, si convive en la misma línea con otros, o si incluso genera su propio sistema de layout. 

display: block;        /* ocupa toda la línea (div, p, h1) */
display: inline;       /* fluye dentro de la línea (span, a) */
display: inline-block; /* inline pero con width/height */
display: none;        /* elimina el elemento de la página */
Tip: Todos los elementos tienen un display por defecto: los <div>, <p> y encabezados son block; los <span>, <a> y <strong> son inline.

Block, inline e inline-block

Cada valor cambia el comportamiento en tres frentes: ocupación de línea, medidas y márgenes/padding:

Valor¿Nueva línea?width / heightmargin vertical
blockSí — ocupa todo el ancho del padreSí, se respetanSí
inlineNo — fluye en la líneaNo, se ignoranNo (solo margin horizontal)
inline-blockNo — fluye en la líneaSí, se respetanSí
 
/* La clave del layout clásico: inline-block */
.boton-enlace {
  display: inline-block;
  padding: 10px 16px;  /* un  inline ignora esto */
}
.tarjeta {
  display: inline-block;
  width: 250px;   vertical-align: top;
}
Cuidado con los espacios: Los elementos inline-block separados por saltos de línea en el HTML muestran un espacio blanco de aproximadamente 4px entre ellos. Elimínalo cerrando etiquetas consecutivas o usando display: flex con gap.

display: none vs visibility: hidden

Ambas "ocultan" un elemento, pero con consecuencias distintas sobre el flujo del documento:

.oculto-flujo  { display: none; }        /* sale del flujo, no deja espacio */
.oculto-visible { visibility: hidden; } /* invisible pero ocupa su sitio */
TécnicaEspacio reservadoInteracciónUso típico
display: noneNoImposibleMenús móviles, pestañas
visibility: hiddenSíImposibleTexto "invisible" que mantiene el layout
opacity: 0SíPosibleTooltips y overlays animados
display: none + @mediaNoImposibleMostrar/ocultar por breakpoint

Float clásico y clear

Antes de Flexbox y Grid, float era el método para colocar elementos lado a lado. Hoy se usa sobre todo para imágenes y texto, como en revistas:

.imagen-flotante {
  float: left;      /* el texto fluye a su derecha */
  margin-right: 16px;
}

/* Detener el flujo alrededor del float */
.fila:after {
  content: "";
  display: block;
  clear: both;
}

Demo: texto rodeando un elemento con float

float: left
Este párrafo usa un elemento con float: left. El texto "fluye" alrededor de la caja naranja como si estuviera leyendo una revista. La propiedad overflow: hidden en el contenedor actúa como clearfix moderno: asegura que la caja envuelva al elemento flotado. Sin ese detalle, el float se escaparía del contenedor y el layout se rompería.
Recomendación: No uses float para layouts de columnas (botones "Siguiente / Anterior", galerías…). Para eso están flex y grid. El float queda para maquetación tipo texto-imagen.

Overflow: qué pasa cuando el contenido no cabe

overflow decide la estrategia cuando el contenido excede las dimensiones del elemento:

overflow: visible; /* se sale (default) */
overflow: hidden;  /* se recorta */
overflow: auto;    /* scroll solo si hace falta */
overflow: scroll;  /* scrollbar siempre */
overflow-x: auto;   /* también por ejes (y-o) */
ValorCuándo usarlo
visibleTooltips y dropdowns que sobresalen del contenedor
hiddenRedondear imágenes, ocultar desbordes de thumbnails
autoPaneles con contenido variable (el más común)
scrollGalerías de horario fijo donde siempre hay scroll
Truco: overflow: hidden en un contenedor también crea un contexto de formato que contiene a sus hijos float — un clearfix sin generar pseudo-elementos.

Centrado horizontal: margin: auto

Un elemento block con ancho definido se centra con margin: 0 auto. El navegador reparte por igual el espacio sobrante a cada lado:

/* Horizontal: requiere un ancho menor al del padre */
.contenido {
  width: min(640px, 100%);
  margin: 0 auto;    /* centrar block */
}

/* Texto e inline: con text-align en el padre */
.centro-texto {
  text-align: center;
}
Qué quieres centrarDónde lo ponesPropiedad
Un bloque (div, sección)En el propio elementomargin: 0 auto
Texto o elementos inlineEn el elemento padretext-align: center
Una imagenEn el contenedormargin: 0 auto + display: block

Centrado vertical: flex y grid

El centrado vertical "perfecto" llegó con flex: contenedor con align-items + justify-content, ambos center, centran al hijo en los dos ejes a la vez:

/* Vertical + horizontal con Flexbox (recomendado) */
.padre {
  display: flex;
  align-items: center;    /* vertical */
  justify-content: center; /* horizontal */
}

/* Alternativa con Grid (1 línea) */
.padre {
  display: grid;
  place-items: center; /* alinea en ambos ejes */
}

Demo: centrado en dos ejes

Centrado con flex — ¡exacto!

El hijo queda exactamente al centro del contenedor, sin importar su tamaño.

Dato: Centrar verticalmente una línea de texto también se puede con line-height igual a la altura del contenedor, pero solo funciona con una sola línea: los botones, por ejemplo. Para cualquier otra cosa, usa flex o grid.

Repaso rápido

  • block ocupa toda la línea; inline no respeta ancho ni margin vertical; inline-block combina ambas cosas.
  • display: none elimina el elemento del flujo; visibility: hidden lo deja invisible pero ocupando sitio.
  • float sigue útil para texto que rodea imágenes; los layouts de columnas se hacen con flex/grid.
  • overflow: auto añade scroll solo cuando es necesario; hidden recorta y actúa de clearfix.
  • Centrar un bloque: margin: 0 auto + ancho menor al del padre.
  • Centrar texto/inline: text-align: center en el padre.
  • Centrar en dos ejes: flex con align-items + justify-content: center, o grid con place-items: center.
