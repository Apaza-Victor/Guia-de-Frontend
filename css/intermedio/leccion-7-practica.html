Práctica: layout completo

Detrás de escena: cómo se construye una página con hero, cards y footer usando Flexbox y Grid combinados.

El layout de esta guía: detrás de escena

Esta misma guía web que estás leyendo usa Flexbox y Grid combinados. La navbar usa display: flex, el contenido se distribuye en un container centrado, y las rejillas de tarjetas usan grid-template-columns: repeat(auto-fit, minmax(...)). En esta lección practicaremos construyendo un mini-layout similar.

Enfoque: No escribes un layout completo de golpe. Primero defines la estructura (Grid para la página), luego alineas los componentes internos (Flexbox para navbar, hero, footer).

Paso 1: La estructura HTML

Toda página comparte esta estructura base: nav, hero, contenido y footer:

<body>
  <nav class="navbar">...</nav>
  <header class="hero">...</header>
  <section class="cards-grid">...</section>
  <footer>...</footer>
</body>

El body se comporta como un flex container en columna para que el footer siempre quede abajo:

body {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}
main {
  flex: 1;  /* ocupa todo el espacio disponible */
}

Paso 2: Navbar con Flexbox

La barra de navegación es el caso de uso más clásico de Flexbox: logo a la izquierda, enlaces a la derecha, todo centrado verticalmente:

.navbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 12px 24px;
  background: #16162a;
}
PropiedadPor qué se usa
display: flexColoca logo y enlaces en fila
justify-content: space-betweenEmpuja el logo a la izquierda y los links a la derecha
align-items: centerCentra verticalmente logo y enlaces

Paso 3: Hero con Flexbox

El hero es una sección centrada con título, descripción y botón de llamada a la acción:

.hero {
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  text-align: center;
  padding: 60px 24px;
  gap: 16px;
}

Usamos flex-direction: column porque el contenido del hero apila verticalmente título - párrafo - botón.

Paso 4: Cards con CSS Grid

Las tarjetas son el momento perfecto para Grid: necesitamos múltiples columnas iguales que se adapten al ancho disponible:

.cards-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
  padding: 24px;
}

.card {
  background: #16162a;
  border: 1px solid #333;
  border-radius: 10px;
  padding: 20px;
  transition: transform 0.3s, border-color 0.3s;
}

.card:hover {
  border-color: #2563eb;
  transform: translateY(-3px);
}
PropiedadFunción en el layout
display: gridActiva el layout bidimensional para las cards
auto-fitCrea tantas columnas como quepan en el contenedor
minmax(220px, 1fr)Cada columna mide entre 220px y el espacio disponible
gap: 16pxEspacio entre cards sin márgenes negativos

Paso 5: Footer con Flexbox

El footer es otro caso de Flexbox: logo y copyright a un lado, iconos al otro:

.footer {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 16px 24px;
  background: #16162a;
  border-top: 1px solid #333;
}

¿Y esta guía?

Esta misma página usa exactamente estos patrones:

FLEX - Navbar

La barra de navegación superior usa display: flex con justify-content: space-between para separar el logo de los enlaces.

FLEX - Hero header

El .lesson-header apila breadcrumbs, badges, título y progress-tracker con Flexbox en columna.

GRID - Cards

Las tarjetas de demo usan grid-template-columns: repeat(auto-fit, minmax(...)) para layouts responsivos.

FLEX - Footer

El pie de página usa Flex para alinear logo e iconos con justify-content: space-between.

Construye layouts profesionales

Flexbox para componentes, Grid para la estructura. Combinarlos y el resultado es escalable y mantenible.

Flexbox
Componentes en una dimensión: nav, hero, footer, botones.
CSS Grid
Estructura bidimensional: rejillas, layouts de página, columnas.
Responsive
Media queries + unidades fluidas para adaptar a cualquier pantalla.
Posicionamiento
Badges, tooltips, sticky headers y overlays con z-index.

Consejos para layouts reales

HerramientaCuándo usarla
FlexboxComponentes internos: nav, hero, footer, botones, formularios, toolbar
GridEstructura de página: rejillas de cards, layouts con header/sidebar/main/footer
Grid + Flex juntosGrid para la estructura macro, Flex para alinear dentro de cada celda
Media queriesCuando auto-fit/minmax() y clamp() no son suficientes
Unidades fluidasSiempre: rem para texto, clamp() para tamaños variables
Regla de oro: No uses Flexbox para el layout completo de una página. Flexbox es unidimensional; Grid es el que maneja filas Y columnas a la vez. Combínalos, no los enfrentes.

Repaso rápido

  • Flexbox es ideal para componentes: nav, hero, footer, botones.
  • Grid es ideal para la estructura de página: rejillas de cards, layouts complejos.
  • repeat(auto-fit, minmax(220px, 1fr)) crea rejillas responsivas automáticamente.
  • justify-content: space-between es el patrón más usado en navbar y footer.
  • flex: 1 en main empuja el footer al fondo de la página.
  • clamp() crea tamaños fluidos sin media queries para textos responsivos.
  • Esta guía misma es un ejemplo de Grid + Flex trabajando juntos.
