Responsive design y media queries

Haz que tu diseño se adapte a cualquier pantalla con media queries, unidades fluidas e imágenes responsivas.

Mobile-first vs Desktop-first

Existen dos filosofías para escribir CSS responsivo:

EnfoqueCómo se escribeVentaja
Mobile-first Los estilos base son para pantallas pequeñas. Se usan @media (min-width: …) para ampliar. Código más ligero, mejor rendimiento en móviles, enfoque de Bootstrap
Desktop-first Los estilos base son para pantallas grandes. Se usan @media (max-width: …) para reducir. Más intuitivo si piensas en escritorio primero
Recomendación: Usa mobile-first. Es el estándar de la industria y el enfoque que usa Bootstrap. Comienzas con lo esencial y añades complejidad solo cuando la pantalla lo permite.

Breakpoints comunes

Los breakpoints son los puntos donde el diseño cambia. Estos son los estándar de Bootstrap 5:

BreakpointAnchoDispositivo típico
xs0 – 575pxMóviles pequeños
sm≥ 576pxMóviles grandes / landscape
md≥ 768pxTablets
lg≥ 992pxPortátiles / desktops pequeños
xl≥ 1200pxDesktops grandes
xxl≥ 1400pxPantallas extra grandes

Sintaxis de @media

/* Mobile-first: estilos base para todos */
.container {
  padding: 12px;
  grid-template-columns: 1fr;
}

/* Tablets y más */
@media (min-width: 768px) {
  .container {
    padding: 24px;
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Desktop */
@media (min-width: 992px) {
  .container {
    padding: 40px;
    grid-template-columns: repeat(4, 1fr);
  }
}
/* Desktop-first: estilos base para escritorio */
.container {
  grid-template-columns: repeat(4, 1fr);
}

/* Reducir a 2 columnas en tablets */
@media (max-width: 991px) {
  .container {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Una columna en móvil */
@media (max-width: 767px) {
  .container {
    grid-template-columns: 1fr;
  }
}
Regla de oro: Con mobile-first usa min-width (crece). Con desktop-first usa max-width (reduce). Nunca mezcles ambos enfoques en el mismo proyecto.

Unidades fluidas

Las unidades relativas se adaptan al contexto sin necesidad de media queries:

UnidadRelativa a…Uso típico
%Ancho del contenedor padreLayouts de columnas
emFont-size del elemento actualPadding, margin, tamaños internos
remFont-size del root (<html>)Tamaños de texto consistentes
vw / vh1% del ancho / alto de la ventanaElementos a pantalla completa
clamp()Mínimo, preferido, máximoTexto/fluido sin media queries
 
/* clamp(min, preferred, max) — sin media queries */
h1 {
  font-size: clamp(1.5rem, 4vw, 3rem);
}

/* Ancho fluido: mínimo 200px, máximo 80% */
.card {
  width: clamp(200px, 80%, 900px);
  margin: 0 auto;
}

Imágenes responsivas

Las imágenes deben adaptarse al contenedor sin romper el layout:

/* 1. Ancho máximo al 100% */
img {
  max-width: 100%;
  height: auto;
}

/* 2. Elemento picture con srcset para resoluciones */
<picture>
  <source media="(min-width: 992px)" srcset="hero-lg.jpg">
  <source media="(min-width: 576px)" srcset="hero-md.jpg">
  <img src="hero-sm.jpg" alt="Hero" class="img-fluid">
</picture>
Bootstrap: La clase .img-fluid de Bootstrap añade max-width: 100%; height: auto; automáticamente.

Imagen responsiva

max-width: 100%; height: auto;
Esta caja se adapta al contenedor — como lo haría una imagen real

Repaso rápido

  • Mobile-first usa min-width; desktop-first usa max-width.
  • Los breakpoints estándar de Bootstrap son: 576, 768, 992, 1200, 1400 px.
  • clamp() crea tamaños fluidos sin necesidad de media queries.
  • img { max-width:100%; height:auto; } es la base de imágenes responsivas.
  • em se relaciona con el padre; rem con el root — usa rem para consistencia.
  • Las unidades vw/vh son útiles para layouts a pantalla completa.
